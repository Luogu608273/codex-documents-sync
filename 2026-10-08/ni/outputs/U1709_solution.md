# U1709 合并（merge）

来源：用户提供的 U1709.pdf。题面要求 `merge.in` / `merge.out`，时限 1000 ms，内存 512 MiB。

## 题意与范围

从 N 个数开始，每次用 K-x-y 替换任意两个数，直到只剩一个数，求最大结果。Q 个 K 的询问彼此独立。

2 ≤ N ≤ 150000，Q ≤ 150000，A[i],K ≤ 1000000000；答案绝对值不超过 200000000000000。

## 小范围：子集 DP

用 low[S]、high[S] 分别表示集合 S 能合并出的最小和最大结果。枚举非空真子集 T，U=S\T：

`high[S] = max(K-low[T]-low[U])`

`low[S] = min(K-high[T]-high[U])`。

最后一次合并的两棵子树互不影响，因此可独立选取两侧最值。只存最大值会错，因为合并时有负号。

每次询问 O(3^N)，空间 O(2^N)。单元素集合直接等于该元素的值。

## 把合并顺序转化为符号

任何合并过程对应一棵满二叉树，叶子是原数，内部节点是 K-x-y。令 z=x-K/3，运算就变成 z=-z_left-z_right。

因此最终结果是：

`K/3 + Σ s[i]·(A[i]-K/3)`，

其中 s[i] 为 +1 或 -1，等于叶子深度奇偶性决定的符号。

假设正号数是 p，负号数是 N-p，则结果为：

`Σ正号 A - Σ负号 A + ((N+1-2p)/3)·K`。

这里的 K/3 仅用于数学推导；实现完全使用整数。

## 哪些正号个数可以实现

恰好是 `0≤p≤N` 且 `p ≡ 2-N (mod 3)` 的所有整数。

必要性：原表达式中的 K 系数是整数，所以 N+1-2p 必须被 3 整除。

充分性可对 N 归纳。N=2 时 p=0，可实现。对 N≥3，在根的一侧放单个叶子，另一侧放 N-1 叶子的树。如果另一侧有 p' 个正号，根翻转其符号后，全树有 p=N-1-p' 个正号。由归纳可实现所有符合余数条件、且 p≤N-1 的候选。唯一可能未覆盖的候选是 p=N，它只在 N≡1 mod 3 时出现；此时 N≥4，把根两侧分别取 2 和 N-2 个叶子，这两侧都能实现全负号，翻转后全树就是全正号。

叶子的原数可以任意排列，因此对固定 p，应给最大的 p 个 A 正号。

## 排序与三元组

把 A 按不增序排列，记前缀和 S[p]，总和 S[N]。令 r 是 2-N 在 [0,2] 内的余数。

候选 p 依次为 `r,r+3,r+6,...`，其结果：

`G(p,K)=2S[p]-S[N]+((N+1-2p)/3)K`。

相邻候选之差为：

`G(p+3,K)-G(p,K)=2·(A[p+1]+A[p+2]+A[p+3]-K)`。

把从 r+1 开始的元素每三个一组，记组和 B[0],B[1],...。由于 A 已排序，B 单调不增。于是前几组能使结果增加，后面的组只会使结果减少。

设 h 为组和 ≥K 的组数，最优 p 可取 r+3h。组和等于 K 时前后结果相同，取任何一侧都正确。

对每个询问在 B 中二分第一个小于 K 的位置，再代入 G，即为完整解法。

## 特殊性质的优化

K 单调不降时，h 单调不增，从所有组开始，依次删除组和小于当前 K 的尾组，总指针移动 O(N)，总询问 O(Q)。

所有 A 都为 a 时，组和均为 3a：K≤3a 则取最多正号，否则取最少正号 r。U1709_partial_68.cpp 包含该分支。

## 正确性与复杂度

合并树给出了所有合法符号个数；归纳证明每个候选可实现。固定正号数时排序选择最大的元素最优。三元组差值单调，因此二分找到的候选是所有候选中的最大值。

完整解法时间 O(N log N+Q log N)，空间 O(N)。乘法必须先转成 `long long`，尤其注意 K 的系数可能为负。代码中的除以 3 是整除，不受负数截断影响。
