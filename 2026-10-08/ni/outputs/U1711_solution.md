# U1711 铺砖（tile）

来源：用户提供的 U1711.pdf。题面要求 `tile.in` / `tile.out`，时限 1000 ms，内存 512 MiB。

## 题意与范围

简单正交多边形的最小横坐标为 0、最大横坐标为 M。用边长 K、轴对齐、顶点为整数的正方形无重叠地铺满多边形中 x<t 的部分，地砖不能伸到外部或 x>t。求最大可行整数 t，允许 t=0。

N≤200000，K、M、顶点坐标均不超过 1000000000。

**可行性不随 t 单调。** 例如宽 5、高 4、K=2 的矩形中，0、2、4 可行，1、3、5 不可行，不能对答案直接二分。

## 横向切片决定地砖的横坐标余数

固定一个不经过多边形水平边或地砖边界的 y。多边形在这条水平线上是若干互不相交的区间。对其中一个从 l 开始的区间，地砖覆盖线段的长度均为 K，不能重叠、不能有空隙，所以地砖的竖边横坐标被强制为：

`l, l+K, l+2K, ...`。

称 p=l mod K 为这个水平区间的“相位”。新水平区间从横坐标 X 开始时，相位必须是 X mod K；在 X 结束时，必须满足 X mod K=p。

扫过某个 X 后，对每个 y 维护：

- 多边形外：相位 -1；
- 多边形内：当前水平区间左端点模 K 的相位 p。

相位不同的相邻 y 段不可能属于同一块砖：因为同一块砖的横坐标起点对其内部每条水平线都相同。

## 竖向的条件：同相位连续段高度整除 K

把当前 y 轴上相同相位、彼此连续的部分合成极大区间。对于每个活跃区间 [a,b)、相位 p，其高度必须满足 `(b-a) mod K=0`。

必要性：选定某个竖直切片，穿过该同相位段的每块砖高度为 K；砖不能跨越不同相位段，也不能跨越多边形外部，故必须能把 [a,b) 分成若干长度 K 的区间。

充分性可用扫描过程证明：

1. 在新相位段开始时，它的横坐标为 X，砖的横向起点被固定为 X。
2. 在段内自下而上每 K 高度放一块砖，然后每隔 K 向右重复。
3. 相位不同的相邻段分别铺设。
4. 在多边形竖边处，删除的部分只有相位等于 X mod K 才能结束，此时相关砖恰好到达边界。
5. 插入的新部分也恰好从 X 开始，具有同一个 X mod K。受这次边界变化影响的旧段与新段，都在这个 X 处到达砖的竖边，因此可以重新自下而上分组；不会切开尚未结束的砖。

同一 X 的全部竖边事件处理完后，只要所有极大同相位段的高度都整除 K，就可以继续铺设。应当统一检查这一组事件的最终状态，不能用中间状态判断失败。

## 两种无法继续的事件

- 某段在 X 离开多边形，但该段相位不是 X mod K。其最后一列砖会伸到 X 右侧，多边形不允许，无法铺到更右。
- 同一 X 的事件处理完后，某个同相位段高度不是 K 的倍数。这个段无法完整竖向分组，也不能铺到更右。

一旦出现以上情况，任何 t>X 都不可能可行；返回之前记录到的最大可行截断位置即可。

## 怎样记录可行截断位置

在相邻事件横坐标之间，活跃相位与各段高度都不变。

若当前有两种或更多相位，则不可能在一条共同竖直线 t 结束全部砖，因为 t mod K 无法同时等于不同相位。

若所有活跃段只有一个相位 p，那么在当前无事件区间内：

`t mod K=p`

恰好是可行截断位置。扫描到下一事件 X 前，最大候选为：

`t = X - ((X-p) mod K)`，

这里取 [0,K-1] 的非负余数。还必须要求候选不小于上一次事件横坐标 last；否则候选落在旧状态中，不能使用当前相位判定。

例如 K=4，下方矩形为 [0,6]×[0,4]，上方矩形为 [1,5]×[4,8]。在 x=1 到 5 之间存在两种相位；上方在 5 结束后，下方剩下相位 0。不能据此把 4 误判为可行，因为 4 位于前一个混合相位区间。实际上本例答案为 0。

若没有活跃段，可以记录 X；在题面的连通简单多边形中，内部扫描通常只在起点或终点出现空状态。

每组事件前先记录旧状态直到 X 的可行截断位置，再更新区间并检查能否继续。

## 如何识别插入与删除

用有向面积判断多边形方向。逆时针顶点序列中：

- 向下的竖边，其左侧是多边形内部，即 X 右侧，表示插入；
- 向上的竖边，其左侧是多边形内部，即 X 左侧，表示删除。

顺时针时相反。面积累加使用 `__int128`：每项最多约 10^18，总项数达 200000，`long long` 不能安全容纳累加结果。

只需要处理竖直边，将事件按 x 排序；水平边的影响已经包含在相邻竖边事件中。

## O(N²) 部分分实现

离散化所有顶点 y。相邻不同 y 之间的一段内部不会发生多边形边界变化，数组记录其相位。每个事件更新相应数组区间；每个 x 扫描全部数组，合并同相位段、检查真实坐标高度，并判断相位是否唯一。

时间 O(N²)，空间 O(N)。离散化只改变索引，绝不能把离散化段数当作实际高度。

## O(N log N) 完整实现

用有序映射 `y左端点 → 相位` 维护 y 轴的极大同相位段，最大 y 处保留永久哨兵。处理 [l,r) 时：

1. 在 l、r 处分裂区间。
2. 检查待删除段的相位，或检查待插入段原来位于外部。
3. 替换这一区间的相位。
4. 与左右同相位段合并。

额外维护：

- 高度不能被 K 整除的活跃段数量 bad；
- 每种活跃相位对应的区间数量 count。

每次分裂、替换、合并只增删相关区间的贡献。`bad=0` 表示高度条件成立；count 只有一种键时就有共同相位。

一个事件至多新建常数个区间，扫描经过的旧区间会在该事件中被删除，因此总遍历次数 O(N)，配合有序映射的操作，总时间 O(N log N)、空间 O(N)。

## 正确性与边界

横向切片强制决定了所有砖的相位；同相位连续段高度条件与边界退出条件必要，并通过上述扫描铺设构造保证充分。每个无事件区间的所有可能截断位置都被共同相位公式覆盖。遇到首次无法继续的事件后，更右答案不可能存在，所以记录的最大值就是最优答案。

K=1 时直接输出 M。矩形样例高 4 可被 2 整除，最大合法横坐标为 4。顺时针、逆时针和相邻共线顶点均由事件处理支持。
