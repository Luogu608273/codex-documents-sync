# U1708 守望（watch）

来源：用户提供的 U1708.pdf。题面要求 `watch.in` / `watch.out`，时限 1000 ms，内存 512 MiB。

## 题意与范围

在严格递增的坐标 A[1..n] 中选出非空守卫集合，使每个未被选中的人到最近守卫的距离位于 [L,R]，最小化守卫数。守卫本人不受限制。

n ≤ 200000，1 ≤ L ≤ R ≤ 500000000，坐标位于 [-500000000,500000000]。

枚举版本复杂度 O(2^n n²)，空间 O(n)。守卫集合非空；验证的是“最近距离”，不能仅判断存在一名距离合适的守卫。

## 第一步：小于 L 的相邻间隔必须合并

如果两人的距离小于 L，一个是守卫、另一个是平民，则该平民到最近守卫的距离小于 L，必然不合法。因此，对于所有满足 A[i+1]-A[i]<L 的相邻对，两人的身份必须相同。

把这些相邻对连接起来，得到若干连续块。第 j 块的首尾下标为 l[j]、r[j]，代价为 len[j]=r[j]-l[j]+1。一个块要么全部是守卫，要么全部是平民。

不同块之间的任意两点距离都至少是 L，因此选块后，距离下限自动满足。剩下只需要保证每个平民离守卫不超过 R。

## 第二步：只记录最后一个守卫块

设 dp[j] 表示：第 j 块全部选为守卫，且它左侧所有人已经合法时，最少守卫数。

考虑第 j 块作为右侧守卫块。记 p[j] 为最后一个满足

`A[p[j]] < A[l[j]] - R`

的原始点下标；没有这样的点则记为 0。注意使用严格小于，距离等于 R 是合法的。

从第 p[j]+1 个人开始，到第 j 块之前的人，都已经能由第 j 块覆盖。如果 p[j]>0，则第 j 块覆盖不到的最右侧原始点是 A[p[j]]。

若上一个守卫块是 i<j，它最右端的守卫在 A[r[i]]。连接 i、j 两个守卫块是否合法，恰好取决于：

`A[r[i]] >= A[p[j]] - R`。

证明分两种情况：

- p[j]≤r[i]：第 j 块覆盖不到的点全部在已经处理好的前缀内，条件自动成立。
- p[j]>r[i]：两守卫块之间，第 j 块覆盖不到的点都不超过 A[p[j]]。它们由第 i 块覆盖，当且仅当最右一个点与 A[r[i]] 的距离不超过 R。

于是：

`dp[j] = len[j] + min(dp[i])`，

其中 i<j 且满足上面的坐标条件。如果 p[j]=0，还可以直接以第 j 块为第一个守卫块，对应前驱代价 0。

最后，只有满足 `A[r[j]] >= A[n]-R` 的最后守卫块，才能覆盖右侧全部平民。答案是这些 dp[j] 的最小值。

直接枚举前驱就是 O(n²) 的 40 分版本。

## 第三步：单调队列

随着 j 增加，A[l[j]] 单调增加，p[j] 与下界 `A[p[j]]-R` 都单调不降。因此候选前驱一直是已处理块的一个后缀。

维护一个按下标递增、按 dp 值严格递增的队列：

1. 从队首删除右端坐标小于当前下界的块。
2. 队首给出合法前驱的最小 dp。
3. 得到 dp[j] 后，从队尾删除 dp 不小于 dp[j] 的块，再加入 j。

被队尾删除的旧块，dp 不优于 j，右端坐标也不大于 j。今后旧块可用时 j 也可用，所以旧块不会再优于 j。

合法队列不会在 p[j]>0 时为空：紧邻 j 的前一个块总能作为前驱；它即使被队尾删除，也存在一个更靠右且更优的替代块。

## 正确性总结

身份一致分块是必要条件，也完整消除了距离下限限制。转移条件精确判断两个连续守卫块之间的所有平民是否合法；首块与尾块的条件分别处理两端。动态规划枚举了所有守卫块序列，单调队列仅删除不会最优的候选，因此得到最少守卫数。
