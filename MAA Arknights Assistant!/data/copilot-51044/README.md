# GO-EX-7 突袭：结城理补强版

导入 `GO-EX-7-raid-makoto.json`，在 GO-EX-7 突袭的编队选择页使用。原作业：[prts://51044](https://prts.plus/?op=51044)，原 JSON 作者为小卡拉帕鲁灰。此文件为本地修改版，未改动线上原作业。

## 部署与适配

| 干员 | 技能、练度 | 模组 | MAA 坐标、朝向 |
| --- | --- | --- | --- |
| 维什戴尔（需借用） | 精二90，3技能专三 | X三级 | (3,4) 右 |
| 逻各斯 | 精二60，1技能专三 | Δ三级 | (9,4) 左 |
| 克洛丝 | 精一55，1技能7级 | 无 | (2,4) 上 |
| 塞雷娅 | 精二1，1技能专三 | 不使用 | (2,6) 右 |
| 结城理 | 精二60，3技能专三，好了就用 | Y三级 | (7,4) 下 |

保留原四人的部署顺序，结城理最后加入，避免额外费用推迟原防线成型。原“盾”替代组改为自有塞雷娅固定槽位，部署动作也同步改名；借用缺口仅维什戴尔一人。自动编队时开启缺一人借助战，关闭额外补信赖；技能和模组类型已写入 requirements。模组三级须手动核对，当前核心不校验模组等级。

结城理的替身范围是曼哈顿距离不超过2的菱形，(7,4)可覆盖右侧纵向通路(7,2)至(7,6)、逻各斯(9,4)，以及突袭运输艇初始点(6,5)。三技能攻击替身可对空，受致命伤可转换成治疗替身，支援逻各斯。这里只配置常规好了就用，不额外强制点按第二次切换治疗。实际自动技能识别与战斗效果待实测。

地图尺寸11×8，MAA坐标左上角为(0,0)。游戏原始关卡数据的行坐标从下往上，需要转换为 `y=7-row`。结城理位于可部署地面格，与原阵容不冲突。原始路线8/9/10/12等均经过右侧(7,3)；新位置覆盖这些路线的关键转折。关卡部署上限8，5名干员外再按最多3个魂灵之影作保守预算也不超限。

## 已核对与限制

- 一图流数据于北京时间2026-10-20 15:20获取，共228条；四名自有干员的等级、技能专精、指定模组已逐项复核。
- 原作者对逻各斯的要求是精二90。本版改为当前精二60，再加入结城理补强；60级是个人适配门槛，不是经过实战验证的最低练度。
- 突袭附加条件是增加大容量物资运输艇并改变部分初始位置；原始数据还包含敌人攻击、防御、生命各1.2倍的突袭符文。
- 已通过JSON结构、部署格、朝向、干员引用、替身范围、单助战缺口的静态校验，证据为 `validation.json`、`adaptation.json`。
- 核心加载校验未完成：当前 Python 启动器仅列出3.8，未找到旧说明中的3.12；安装目录自带Python接口使用了3.10及以上的类型注解，3.8无法导入。未修改Python、MAA或模拟器环境，也未进入核心任务添加阶段。
- 未连接游戏，未运行作战，不保证突袭已解决。因上次失败位置未知，右侧补强是基于地图、敌人路线与逻各斯练度差距作出的判断。
