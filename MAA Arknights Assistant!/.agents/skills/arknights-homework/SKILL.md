# 明日方舟作业查找与干员匹配

## 站点与项目数据

- `https://prts.wiki/` 是资料 Wiki，用于确认关卡、机制、干员资料。
- `https://prts.plus/` 是 PRTS Plus 作业站，提供 MAA JSON 作业、作业搜索及一图流干员匹配。不要把两站混称为同一个网站。
- `https://ark.yituliu.cn/tools/operator-zoot-matcher` 是一图流的“干员－作业匹配器”，同样读取 PRTS Plus 后端作业。
- 本项目干员快照在项目根目录 `data/operators-*.json`，其中 `.raw.json` 为完整响应，其余为干员数组。以实际读取和用户指定版本为准；有多个日期时优先最近快照。2026-10-10 的快照有 225 条干员／形态记录，这只是该次快照的数量。
- 一图流只读密钥只用于一图流的 `Authorization` 请求头。不要写进 skill、导出文件或示例。使用现有快照即可完成筛选时，无需重新请求密钥。

## 查找流程

1. 确定关卡、普通／突袭／其他模式，以及是否允许助战。若用户未限定助战，可同时给出自有阵容和单助战方案，并明确区分；不要自动执行 MAA。
2. 先核实关卡 ID。作业 API 的 `levelKeyword` 应填写内部 ID，例如 `main_01-07`。实测直接填 `1-7` 会返回无关作业。读取关卡列表再映射，不凭编号拼 ID。
3. 使用下列网页或 API 路径获取候选。逐条核对关卡与难度、作者说明、最低 MAA 版本及是否需要手动操作；热度和标题不能代替核对。
4. 根据用户实际持有干员比较固定槽位 `opers` 和替代组 `groups`。组内通常选一人；同一人不能同时占两个槽位，助战总共只能补一人。先核对持有，再核对精英化、等级、指定技能专精和模组。
5. 优先展示条件已核实的少量结果。每项给出作业标题、可点击链接、阵容／助战缺口和关键说明；需要培养或条件不明时明确指出。没有合适结果时说明查过的范围，再调整搜索条件。

## 网页快速筛选

PRTS Plus 原生支持一图流只读密钥，也支持本地 JSON 导入；本项目优先使用已有 JSON：

1. 在作业站的“匹配干员”设置中选择本地导入，导入本项目快照；完整响应和纯数组两种结构都受支持。
2. 核对导入数量，打开匹配开关；根据需要选择 `ready`、`borrow`、`train`、`blocked` 对应的筛选按钮。默认还包含需培养类，不能把默认显示的全部结果说成可直接抄。本项目当前快照中的阿米娅近卫／医疗 ID 不在 PRTS Plus 当前目录中，按源码预计只导入 223 条；涉及阿米娅的作业必须按参考文档另行复核，不能说已完整匹配 225 条。
3. 用关卡选择器选关；筛选结果还要读作业说明。网页只在已加载分页里匹配，列表为空不代表数据库没有合适作业。

一图流匹配器还支持 Box、评分、标题和关卡精确匹配。已核实其数据源是当前浏览器的森空岛导入缓存、已登录一图流账号的练度调查、手动名单；不要声称该页已验证支持直接导入一图流 API 密钥或本地 API JSON。只导入名字时，练度视为未知。需要已有 API JSON 直接匹配时使用 PRTS Plus 原生入口。

需要网页自动化时，先读取当前可用的浏览器技能／工具说明，再观察实际控件；不要直接往站点存储写猜测的数据结构。

## API 检索与本地复核

先读 [接口和匹配规则](references/api-and-matching.md)。公开作业查询、详情、关卡表均已验证无需一图流密钥。未找到独立的服务端干员匹配接口；当前已核实的匹配在前端执行。

可从项目根目录运行只使用 Python 标准库的助手：

```powershell
python .agents/skills/arknights-homework/scripts/query_jobs.py --stage 1-7 --pages 2 --output data/prts-1-7.json
```

助手只读取公开接口、保存查询结果，不进行干员匹配，也不执行作业。它会映射关卡、检查响应、解析作业内容并报告分页覆盖；输出中的难度仍需复核。如编号歧义，使用 `--stage-id` 指定已查证的内部 ID，或用 `--category` 缩小活动范围。

API 模式匹配时，用参考文档中的官方干员目录把一图流 `id` 转成名字与稀有度；核对未知 ID 和重名形态，不丢弃后继续宣称完整匹配。保留一图流原始编号规则。网页的匹配结论是初筛，不保证实战成功，也未覆盖作者正文中的全部条件。

## 验证范围

接口调用、原生导入格式及匹配逻辑于 2026-10-10 通过线上只读请求和官方前端源码核实。参考文档列出源链接与已知限制。未来返回结构或结果不符时停止使用该结果，报告差异并重新核实；不要自动换关卡或把失败响应当空结果。
