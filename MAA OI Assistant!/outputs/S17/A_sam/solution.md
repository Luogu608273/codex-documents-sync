# A. 后缀自动机

题目：[U2294](https://www.mxoj.net/problem/U2294)。

## 题意与范围

给定小写字符串 S。每次询问 S[l..r] 中，出现次数最多的非空子串出现多少次，重叠出现分别计数。n,q≤10^6。文件名为 sam.in / sam.out，时限 2 秒，内存 512 MiB。

## 关键结论与证明

答案等于区间内出现最多的**单个字符**的出现次数。

设非空子串 X 的首字符为 c。X 在位置 p 出现，必然意味着 c 在 p 出现。不同的 X 出现位置对应不同的 c 出现位置，因此 X 的出现次数不超过 c 的出现次数。反过来，字符本身也是合法子串，因此字符出现次数的最大值既是所有子串出现次数的上界，也一定能取到。

## 算法

定义 pre[c][i] 为 S[1..i] 中字符 c 的出现次数，pre[c][0]=0。

每次询问计算

\[
\max_{0\le c<26}(pre[c][r]-pre[c][l-1]).
\]

前缀计数由 pre[c][i]=pre[c][i-1]+[S_i=c] 转移。单个字符、l=1 和 r=n 均直接按同一个公式处理。

预处理 O(26n)，每次询问 O(26)，总时间 O(26(n+q))；空间 O(26n)，计数数组约 104 MB。所有计数≤n，int 足够。

## 部分分

`partial.cpp` 每次直接扫描区间，用 26 个桶统计字符，时间 O(n+q+Σ(r-l+1))，空间 O(n+26)。

适用于测试点 1～8（n,q≤5000），以及 13～16（询问长度之和≤2×10^6），按题面编号对应 60 分。此处的分数是按子任务条件推导的覆盖范围，未经在线评测确认。
