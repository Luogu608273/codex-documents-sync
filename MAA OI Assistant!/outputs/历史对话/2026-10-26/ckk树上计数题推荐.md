这个形式就很舒服了。

## 1. 为什么点分治能避免树形背包？

先看当前点分治处理的一棵虚树连通块 $T$。

找它的重心 $r$。

我们这一轮**只统计所有包含 $r$ 的合法连通块**。

然后删掉 $r$，树裂成：

$$T_1,T_2,\dots,T_s.$$

任何**不包含 $r$** 的连通块，因为它本身连通，所以一定完整落在某一个 $T_i$ 中。

因此：

* 包含 $r$ 的，现在统计；
* 不包含 $r$ 的，递归到某个 $T_i$。

于是每个连通块恰好在某一层第一次碰到分治重心时被统计一次。

这就是点分治的唯一性。

# 2. 固定“必须包含 $r$”以后发生了什么？

把当前分治块重新以 $r$ 为根。

例如：

        /   \
       a     b
      / \     \
     c   d     e
```

现在我们只统计：

$$r\in S,\qquad S\text{ 连通}.$$

考虑某个点 $u$。

### 如果选 $u$

那它到 $r$ 路径上的祖先必须全部选。

否则断开。

### 如果不选 $u$

那么 $u$ 的整个子树都不能再出现选中的虚树点。

因为任何后代 $v$ 到 $r$ 的唯一路径都经过 $u$。

所以出现了超级漂亮的性质：

$$\boxed{ u\text{ 被选} \quad\text{or}\quad subtree(u)\text{ 整块跳过} }$$

这就是为什么不再需要“儿子之间做卷积”。

# 3. DFS 序

对以 $r$ 为根的当前虚树做 DFS。

记录：

$$dfn_u,\qquad out_u.$$

例如：

```
          r(1)
        /      \
      a(2)      b(5)
     /   \        \
   c(3) d(4)      e(6)
```

那么：

$$subtree(a)=[2,4].$$

我们沿 DFS 序做 DP。

定义

$$F_i[x][y][z]$$

表示：

> 已经处理到 DFS 序位置 $i$，当前已经选择的三种颜色数量为 $(x,y,z)$，并且选择出来的部分和 $r$ 连通的方案数。

状态数

$$D=(n_a+1)(n_b+1)(n_c+1).$$

# 4. 处理一个点 $u$

假设

$$dfn_u=i.$$

从前一个状态

$$F_{i-1}[x][y][z]$$

出发。

## 情况 A：不选 $u$

因为必须保持和 $r$ 连通：

$$u\text{ 不选} \Longrightarrow subtree(u)\text{ 全部不能选}.$$

所以不是转移到 $i$，而是**直接跳过整个 DFS 区间**：

$$\boxed{ F_{out_u}[x][y][z] \mathrel{+}= F_{i-1}[x][y][z]\cdot B_{p,u} }$$

这里 $B_{p,u}$ 是虚边 $p\to u$ 上：

> 从父亲方向可以延伸一段，但不真正碰到 $u$

的方案数。

---

## 情况 B：选 $u$

那么父亲到 $u$ 的整条压缩路径必须打通。

设这个方案数为

$$A_{p,u}.$$

另外 $u$ 周围那些不属于当前虚树骨架的普通支叉，也可以任意选合法连通块，设其贡献为

$$W_u.$$

那么

$$\boxed{ F_i[x+\delta_a(u)] [y+\delta_b(u)] [z+\delta_c(u)] \mathrel{+}= F_{i-1}[x][y][z] A_{p,u}W_u }$$

其中

$$\delta_a(u)=[c_u=a]$$

其余类似。

所以每个 DP 状态只有**两条转移**：

$$\boxed{\text{选 }u}$$

或者

$$\boxed{\text{跳过 }subtree(u)}$$

没有任何两个三维 DP 数组做卷积。

这就是最后那个 Aha。

# 5. 那之前的 $(s,ls,rs,sum)$ 怎么进来？

假设虚边：

$$p\longleftrightarrow u$$

对应原树上一整条路径。

倍增求出：

$$(s,ls,rs,sum).$$

如果方向是原树祖先 $\to$ 后代，那么：

### 选 $u$

必须整条路径打通：

$$A_{p,u}=s.$$

### 不选 $u$

可以：

* 一步都不走；
* 从 $p$ 方向走一段，但停在 $u$ 之前。

所以按标准实现里 ls **不包含空选择**的定义：

$$\boxed{B_{p,u}=1+ls}$$

反方向则用

$$1+rs.$$

这正是公开实现里的两个转移：

$$f[out_u]\mathrel{+}=f[i-1](ls+1)$$

以及

$$f[i]\mathrel{+}=f[i-1]\cdot s\cdot W_u.$$

标准代码对应位置就是这一段。[博客园](https://www.cnblogs.com/chasedeath/p/12724356.html)

所以我们前面讨论过的定义问题可以统一掉：

> 如果你把 $L$ 定义为已经包含“什么都不走”，就是 $L$；
> 
> 标准代码的 ls 不包含空方案，因此写 $ls+1$。

# 6. 一轮 Calc(r)

逻辑就是：

```
calc(r):
    以 r 为根 DFS 当前分治块
    求 dfn[u], out[u]

    F 清空
    强制选 r
    F[1][delta(r)] = W[r]

    按 DFS 序 i = 2..K:
        u = seq[i]

        for 所有 (x,y,z):
            // 不选 u
            F[out[u]][x][y][z]
                += F[i-1][x][y][z] * stop(parent,u)

            // 选 u
            F[i][x+da][y+db][z+dc]
                += F[i-1][x][y][z]
                   * full(parent,u)
                   * W[u]

    ans += F[K][na][nb][nc]
```

这里看起来有点诡异：

$$F[out_u]$$

可能比当前位置远很多。

但这正是 DFS 序子树连续性的用途。

一个“不选 $u$”把一整段状态啪地甩到区间末尾，后面的所有后代直接不存在了。很利落。

# 7. 然后怎么点分？

Calc(r) 做完后：

```
       r
     / | \
   T1  T2 T3
```

标记：

$$vis_r=1.$$

然后分别对每个剩余连通块：

1. 求大小；
2. 找重心；
3. 递归。

伪代码：

```
void divide(int rt) {
    calc(rt);

    vis[rt] = 1;

    for (每个 rt 删掉后的连通块 C) {
        int c = get_centroid(C);
        divide(c);
    }
}
```

找重心就是最普通的：

$$\max \left( |T|-siz_u,\; \max_{v\in son(u)}siz_v \right)$$

最小的 $u$。

$$\boxed{ \begin{array}{c} \text{处理跨中点的对象}\\ \downarrow\\ \text{左右递归} \end{array}} \qquad\leftrightarrow\qquad \boxed{ \begin{array}{c} \text{处理包含重心的连通块}\\ \downarrow\\ \text{删除重心后各连通块递归} \end{array}}$$

区别主要有两个。

第一，P7124 的分割中心是 DFS 序区间的

$$mid=\frac{l+r}{2},$$

而这里不能随便取某个“中点”，要取**树的重心**，这样递归深度才保证

$$O(\log n).$$

第二，你说的“从叶子到根改成根到叶子”大体没错，不过更准确地说，不是传统的 top-down tree DP，而是：

> **钦定重心必须选以后，把树根定在重心，通过 DFS 序把树形选择变成序列 DP。**

此时处理 $u$：

$$\text{选 }u\Rightarrow\text{继续处理下一个 DFS 点},$$$$\text{不选 }u\Rightarrow\text{直接跳过整个 }subtree(u).$$

也就是

$$i\to i+1$$

或者

$$i\to out_u+1.$$

所以你现在可以把整道题的最后一层思路记成一句很漂亮的话：

$$\boxed{ \text{点分治钦定中心} + \text{“包含中心”使连通性变成祖先闭包} + \text{DFS 序把祖先闭包变成选点/跳子树 DP} }$$

这和 P7124 那种“**先解决跨分治中心的对象，剩下递归**”确实是同一种分治哲学。[洛谷](https://www.luogu.com.cn/problem/P7124?utm_source=chatgpt.com)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#define rep(i, a, b) for (int i = (a); i <= (b); ++i)
#define per(i, a, b) for (int i = (a); i >= (b); --i)

const int N = 1e5 + 10;
const int K = 18;
const int mod = 1e9 + 7;

struct Nd {
    ll s, l, r, t;
};

Nd mg(const Nd &a, const Nd &b)
{
    Nd c;
    c.s = a.s * b.s % mod;
    c.l = (a.l + a.s * b.l) % mod;
    c.r = (b.s * a.r + b.r) % mod;
    c.t = (a.t + b.t + a.r * b.l) % mod;
    return c;
}

int n, q, co[N], fa[N][K + 1], dep[N], dfn[N], out[N], tim;
vector<int> e[N], ps[N], vt[N];
ll dn[N], sm[N], up[N], al[N], idn[N], iup[N];
Nd jp[N][K + 1], sg[N];
int nx[N];

ll qp(ll a, ll b)
{
    ll r = 1;
    for (; b; b >>= 1, a = a * a % mod)
        if (b & 1) r = r * a % mod;
    return r;
}

void dfs1(int u, int f)
{
    dfn[u] = ++tim;
    dep[u] = dep[f] + 1;
    fa[u][0] = f;

    rep(i, 1, K)
        fa[u][i] = fa[fa[u][i - 1]][i - 1];

    dn[u] = 1;

    for (int v : e[u])
        if (v != f) {
            dfs1(v, u);
            dn[u] = dn[u] * (dn[v] + 1) % mod;
            sm[u] = (sm[u] + sm[v] + dn[v]) % mod;
        }

    out[u] = tim;
}

void dfs2(int u, int f)
{
    if (f) {
        ll z = dn[f] * qp(dn[u] + 1, mod - 2) % mod;
        ll t = (z + sm[f] - sm[u] - dn[u]) % mod;

        if (t < 0)
            t += mod;

        jp[u][0] = {z, z, z, t};

        rep(i, 1, K)
            if (fa[u][i])
                jp[u][i] = mg(jp[fa[u][i - 1]][i - 1], jp[u][i - 1]);
    }

    up[u] = f ? al[f] * qp(dn[u] + 1, mod - 2) % mod : 1;
    al[u] = up[u] * dn[u] % mod;

    for (int v : e[u])
        if (v != f)
            dfs2(v, u);

    idn[u] = qp(dn[u] + 1, mod - 2);
    iup[u] = qp(up[u], mod - 2);
}

bool anc(int u, int v)
{
    return dfn[u] <= dfn[v] && out[v] <= out[u];
}

int lca(int u, int v)
{
    if (anc(u, v))
        return u;

    if (anc(v, u))
        return v;

    per(i, K, 0)
        if (fa[u][i] && !anc(fa[u][i], v))
            u = fa[u][i];

    return fa[u][0];
}

int upc(int u, int f)
{
    per(i, K, 0)
        if (dep[fa[u][i]] > dep[f])
            u = fa[u][i];

    return u;
}

Nd que(int u, int f)
{
    Nd r{1, 0, 0, 0};

    per(i, K, 0)
        if (dep[fa[u][i]] > dep[f]) {
            r = mg(jp[u][i], r);
            u = fa[u][i];
        }

    return r;
}

vector<int> vs;

void bvt(vector<int> a)
{
    a.push_back(1);

    sort(a.begin(), a.end(), [&](int x, int y) {
        return dfn[x] < dfn[y];
    });

    a.erase(unique(a.begin(), a.end()), a.end());

    int z = a.size();

    rep(i, 1, z - 1)
        a.push_back(lca(a[i - 1], a[i]));

    sort(a.begin(), a.end(), [&](int x, int y) {
        return dfn[x] < dfn[y];
    });

    a.erase(unique(a.begin(), a.end()), a.end());

    vs = a;

    for (int u : vs)
        vt[u].clear();

    vector<int> st;

    for (int u : vs) {
        while (!st.empty() && !anc(st.back(), u))
            st.pop_back();

        if (!st.empty())
            vt[st.back()].push_back(u);

        st.push_back(u);
    }
}

int A, B, C, CA, CB, CC;
ll ans;

int vis[N], par[N], sz[N], od[40], ed[N], cnt;
int sa, sb, sc;

int f[40][6][6][6];

void dvt(int u)
{
    vis[u] = 0;

    if (CA == 0 && CB == 0 && CC == 0) {
        ans += sm[u];

        if (ans >= mod)
            ans -= mod;
    }

    for (int v : vt[u]) {
        nx[v] = upc(v, u);
        sg[v] = que(v, u);

        if (CA == 0 && CB == 0 && CC == 0) {
            ans = (ans - sm[nx[v]] - dn[nx[v]]) % mod;

            if (ans < 0)
                ans += mod;
        }
    }

    for (int v : vt[u]) {
        dvt(v);

        if (CA == 0 && CB == 0 && CC == 0) {
            ans += sg[v].t;

            if (ans >= mod)
                ans -= mod;
        }

        vt[v].push_back(u);
    }
}

void gsz(int u, int p)
{
    sz[u] = 1;

    for (int v : vt[u])
        if (v != p && !vis[v]) {
            gsz(v, u);
            sz[u] += sz[v];
        }
}

int rt, bst;

void grt(int u, int p, int tot)
{
    int mx = tot - sz[u];

    for (int v : vt[u])
        if (v != p && !vis[v]) {
            grt(v, u, tot);
            mx = max(mx, sz[v]);
        }

    if (mx < bst)
        bst = mx, rt = u;
}

void dfs3(int u, int p)
{
    par[u] = p;
    sz[u] = 1;

    sa += co[u] == A;
    sb += co[u] == B;
    sc += co[u] == C;

    od[++cnt] = u;

    for (int v : vt[u])
        if (v != p && !vis[v]) {
            dfs3(v, u);
            sz[u] += sz[v];
        }

    ed[u] = cnt;
}

ll get(int u)
{
    ll x = al[u];

    for (int v : vt[u]) {
        if (dep[v] < dep[u])
            x = x * iup[u] % mod;
        else
            x = x * idn[nx[v]] % mod;

        if (vis[v]) {
            if (dep[v] < dep[u])
                x = x * (sg[u].r + 1) % mod;
            else
                x = x * (sg[v].l + 1) % mod;
        }
    }

    return x;
}

void cal(int rt)
{
    if (sa < CA || sb < CB || sc < CC)
        return;

    rep(i, 1, cnt)
        rep(a, 0, CA)
            rep(b, 0, CB)
                rep(c, 0, CC)
                    f[i][a][b][c] = 0;

    int x = co[rt] == A;
    int y = co[rt] == B;
    int z = co[rt] == C;

    if (x <= CA && y <= CB && z <= CC)
        f[1][x][y][z] = get(rt);

    rep(i, 2, cnt) {
        int u = od[i], p = par[u];

        ll w = get(u);
        Nd t;
        ll stp;

        if (dep[p] < dep[u])
            t = sg[u], stp = t.l + 1;
        else
            t = sg[p], stp = t.r + 1;

        if (stp >= mod)
            stp -= mod;

        int da = co[u] == A;
        int db = co[u] == B;
        int dc = co[u] == C;

        rep(a, 0, CA)
            rep(b, 0, CB)
                rep(c, 0, CC) {
                    int cur = f[i - 1][a][b][c];

                    if (!cur)
                        continue;

                    f[ed[u]][a][b][c] =
                        (f[ed[u]][a][b][c] + (ll)cur * stp) % mod;

                    if (a + da <= CA &&
                        b + db <= CB &&
                        c + dc <= CC)
                        f[i][a + da][b + db][c + dc] =
                            (f[i][a + da][b + db][c + dc]
                            + (ll)cur * t.s % mod * w) % mod;
                }
    }

    ans += f[cnt][CA][CB][CC];

    if (ans >= mod)
        ans -= mod;
}

void dvd(int s)
{
    gsz(s, 0);

    bst = 1e9;
    rt = 0;

    grt(s, 0, sz[s]);

    int u = rt;

    sa = sb = sc = cnt = 0;

    dfs3(u, 0);
    cal(u);

    vis[u] = 1;

    vector<int> ls;

    for (int v : vt[u])
        if (!vis[v])
            ls.push_back(v);

    for (int v : ls)
        dvd(v);
}

void solve()
{
    cin >> A >> CA >> B >> CB >> C >> CC;

    if (CA > (int)ps[A].size() ||
        CB > (int)ps[B].size() ||
        CC > (int)ps[C].size()) {
        cout << 0 << endl;
        return;
    }

    vector<int> a;

    for (int u : ps[A])
        a.push_back(u);

    for (int u : ps[B])
        a.push_back(u);

    for (int u : ps[C])
        a.push_back(u);

    bvt(a);

    ans = 0;

    dvt(1);
    dvd(1);

    cout << ans % mod << endl;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    cin >> n >> q;

    rep(i, 1, n) {
        cin >> co[i];
        ps[co[i]].push_back(i);
    }

    rep(i, 2, n) {
        int u, v;
        cin >> u >> v;

        e[u].push_back(v);
        e[v].push_back(u);
    }

    dfs1(1, 0);
    dfs2(1, 0);

    while (q--)
        solve();

    return 0;
}

#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
using ll = long long;
const ll V = 500, N = 505, P = 998244353;
int n, head[N], siz[N], son[N];
ll fac[N], dp[N][N], f[N], g[N][N], h[N][N], t[N], ans[N][N];
struct
{
    int v, next;
} e[N << 1];

void add(int u, int v)
{
    static int cnt = 0;
    e[++cnt] = {v, head[u]};
    head[u] = cnt;
}

ll qpow(ll a, ll b)
{
    ll res = 1;
    while (b)
    {
        if (b & 1)
            res = res * a % P;
        a = a * a % P;
        b >>= 1;
    }
    return res;
}

void dfs1(int u, int fa)
{
    siz[u] = f[u] = 1;
    son[u] = 0;

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;

        dfs1(v, u);

        ++son[u];
        siz[u] += siz[v];
        f[u] = f[u] * f[v] % P;
    }

    f[u] = f[u] * fac[son[u]] % P;
}

void dfs2(int u, int fa)
{
    for (int i = 1; i <= n; ++i)
        ans[u][i] = dp[u][i] * f[u] % P;

    int cnt = son[u], sum = siz[u] - 1;

    for (int i = 0; i <= cnt; ++i)
        for (int j = 0; j <= sum; ++j)
            g[i][j] = 0;

    g[0][0] = 1;

    int ct = 0, ss = 0;
    ll tot = 1;

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;

        ++ct;
        tot = tot * f[v] % P;

        for (int j = ct; j >= 1; --j)
        {
            for (int k = ss + siz[v]; k >= siz[v]; --k)
            {
                g[j][k] += g[j - 1][k - siz[v]];
                if (g[j][k] >= P)
                    g[j][k] -= P;
            }
        }

        ss += siz[v];
    }

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;

        for (int j = 0; j < cnt; ++j)
        {
            for (int k = 0; k <= sum; ++k)
            {
                h[j][k] = g[j][k];

                if (j && k >= siz[v])
                {
                    h[j][k] -= h[j - 1][k - siz[v]];
                    if (h[j][k] < 0)
                        h[j][k] += P;
                }
            }
        }

        int lim = sum - siz[v];

        for (int k = 0; k <= lim; ++k)
            t[k] = 0;

        for (int j = 0; j < cnt; ++j)
        {
            for (int k = 0; k <= lim; ++k)
            {
                t[k] += h[j][k] * fac[j] % P * fac[cnt - j - 1] % P;
                if (t[k] >= P)
                    t[k] -= P;
            }
        }

        ll mul = tot * qpow(f[v], P - 2) % P;

        for (int k = 0; k <= lim; ++k)
            t[k] = t[k] * mul % P;

        for (int j = 1; j <= n; ++j)
        {
            if (!dp[u][j])
                continue;

            for (int k = 0; k <= lim && j + k + 1 <= n; ++k)
                (dp[v][j + k + 1] += dp[u][j] * t[k]) %= P;
        }
    }

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;
        dfs2(v, u);
    }
}

    for (int i = 1; i <= V; ++i)
        fac[i] = fac[i - 1] * i % P;
}

        add(u, v);

**ChatGPT:**

可以，而且其实**更自然**。

因为求 $g_u[p][s]$ 只依赖于：

$$siz_v,\quad v\in son(u)$$

而这些在 dfs1(v,u) 返回后就全知道了。

所以在 dfs1(u) 里：

1. 先递归所有儿子，求出$$siz_v,\ f_v$$
2. 再在 $u$ 这里做$$g_u[p][s]$$
3. 甚至可以继续对每个儿子 $v$ 求出排除它后的 $h$，进一步直接求出$$t_{u,v}[s]$$
4. 把这个 $t$ 存下来。

然后 dfs2 就非常干净，只负责：

$$dp_u[i] \rightarrow dp_v[i+s+1].$$

也就是

$$dp_v[i+s+1] \mathrel{+}= dp_u[i]\cdot t_{u,v}[s].$$

---

但有一个关键点：

如果你只是把 g 写成现在这种**全局二维临时数组**

```
ll g[N][N];
```

放进 dfs1 算，那么算完 $u$ 后，回到父亲又会把它覆盖。

而 dfs2 以后还要用 $u$ 的信息。

所以有两种方案：

### 方案一：dfs1 直接预处理完每条边的 t

我更推荐这个。

比如定义：

```
ll tr[N][N];
```

令

```
tr[v][s]
```

表示父亲 u -> v 这条边：

> $v$ 前面的兄弟子树大小和为 $s$ 时，对应的排列方案数。

那么 dfs1 里：

$$g_u\to h_{u\setminus v}\to tr_v$$

全部做完。

总存储量只有

$$O(n^2),$$

因为每条父子边存一条长度 $O(n)$ 的数组。

然后 dfs2：

```
for (int v : son[u])
    for (int i = 1; i <= n; ++i)
        for (int s = 0; i + s + 1 <= n; ++s)
            dp[v][i + s + 1] += dp[u][i] * tr[v][s];
```

很舒服。

### 方案二：存每个 $u$ 的完整 $g_u[p][s]$

那就是

$$O(n^3)$$

空间，不行。

---

所以你这个想法应该再推进一步：

$$\boxed{ dfs1:\ siz,f,g,h\rightarrow tr }$$$$\boxed{ dfs2:\ dp\text{ 沿 }tr\text{ 往下传} }$$

这样代码结构反而比我上一版更清晰。

而且 g,h 都可以继续只用一份全局临时数组，因为它们在 dfs1(u) 内算完 tr 后就可以扔掉。

但 dp 本身是父亲往儿子传，不能和 dfs1 的后序过程彻底揉成一次遍历，否则儿子第一次递归时父亲的 dp 还没算出来。所以最顺的结构就是：

C++

```
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
using ll = long long;

const int V = 500, N = 505, P = 998244353;

int n, head[N], siz[N], son[N];
ll fac[N], f[N], dp[N][N], tr[N][N], ans[N][N];

struct
{
    int v, next;
} e[N << 1];

void add(int u, int v)
{
    static int cnt = 0;
    e[++cnt] = {v, head[u]};
    head[u] = cnt;
}

void dfs1(int u, int fa)
{
    siz[u] = f[u] = 1;
    son[u] = 0;

    static ll g[N][N], h[N][N];

    vector<int> ch;

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;
        dfs1(v, u);
        ch.push_back(v);
        ++son[u];
        siz[u] += siz[v];
        f[u] = f[u] * f[v] % P;
    }

    f[u] = f[u] * fac[son[u]] % P;

    int m = son[u], sum = siz[u] - 1;

    for (int i = 0; i <= m; ++i)
        for (int j = 0; j <= sum; ++j)
            g[i][j] = 0;

    g[0][0] = 1;

    int cnt = 0, ss = 0;

    for (int v : ch)
    {
        ++cnt;

        for (int i = cnt; i >= 1; --i)
            for (int j = ss + siz[v]; j >= siz[v]; --j)
            {
                g[i][j] += g[i - 1][j - siz[v]];
                if (g[i][j] >= P)
                    g[i][j] -= P;
            }

        ss += siz[v];
    }

    ll mul = 1;
    for (int v : ch)
        mul = mul * f[v] % P;

    for (int v : ch)
    {
        int lim = sum - siz[v];

        for (int i = 0; i < m; ++i)
            for (int j = 0; j <= lim; ++j)
                h[i][j] = 0;

        h[0][0] = 1;

        for (int i = 0; i < m; ++i)
        {
            for (int j = 0; j <= lim; ++j)
            {
                h[i][j] = g[i][j];

                if (i && j >= siz[v])
                {
                    h[i][j] -= h[i - 1][j - siz[v]];
                    if (h[i][j] < 0)
                        h[i][j] += P;
                }
            }
        }

        for (int s = 0; s <= lim; ++s)
        {
            tr[v][s] = 0;

            for (int k = 0; k < m; ++k)
            {
                tr[v][s] += h[k][s] * fac[k] % P * fac[m - 1 - k] % P;
                if (tr[v][s] >= P)
                    tr[v][s] -= P;
            }
        }

        ll iv = 1;
        for (int w : ch)
            if (w != v)
                iv = iv * f[w] % P;

        for (int s = 0; s <= lim; ++s)
            tr[v][s] = tr[v][s] * iv % P;
    }
}

void dfs2(int u, int fa)
{
    for (int i = 1; i <= n; ++i)
        ans[u][i] = dp[u][i] * f[u] % P;

    for (int i = head[u], v; i; i = e[i].next)
    {
        if ((v = e[i].v) == fa)
            continue;

        int lim = siz[u] - siz[v] - 1;

        for (int j = 1; j <= n; ++j)
        {
            if (!dp[u][j])
                continue;

            for (int s = 0; s <= lim && j + s + 1 <= n; ++s)
                (dp[v][j + s + 1] += dp[u][j] * tr[v][s]) %= P;
        }

        dfs2(v, u);
    }
}

void init()
{
    fac[0] = 1;
    for (int i = 1; i <= V; ++i)
        fac[i] = fac[i - 1] * i % P;
}

void solve()
{
    cin >> n;

    for (int i = 1, u, v; i < n; ++i)
    {
        cin >> u >> v;
        add(u, v);
        add(v, u);
    }

    dfs1(1, 0);

    dp[1][1] = 1;
    dfs2(1, 0);

    for (int i = 1; i <= n; ++i)
    {
        for (int j = 1; j <= n; ++j)
            cout << ans[i][j] << " \n"[j == n];
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int _ = 1;
    init();

    while (_--)
        solve();

    return 0;
}

C++

```
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define rep(i,a,b) for(int i=(a);i<=(b);i++)
#define per(i,a,b) for(int i=(b);i>=(a);i--)
const int N=1e5+5,K=18,P=1e9+7;

struct D{
	int s,l,r,t;
}jp[N][K+1],sg[N];

D mg(D a,D b){
	return {
		a.s*b.s%P,
		(a.l+a.s*b.l)%P,
		(b.s*a.r+b.r)%P,
		(a.t+b.t+a.r*b.l)%P
	};
}

int n,q,c[N],fa[N][K+1],dep[N],dfn[N],out[N],ti;
int f[N],sm[N],up[N],al[N],iv[N],iu[N];
int sz[N],vis[N],pa[N],ed[N],od[40],nx[N],ct;
int A,B,C,X,Y,Z,sa,sb,sc,rt,bs,ans;
int dp[40][6][6][6];
vector<int> e[N],ps[N],ve[N],vs;

int qp(int a,int b){
	int r=1;
	for(;b;b>>=1,a=a*a%P) if(b&1) r=r*a%P;
	return r;
}

void dfs1(int u,int p){
	dfn[u]=++ti,dep[u]=dep[p]+1,fa[u][0]=p,f[u]=1;
	rep(i,1,K) fa[u][i]=fa[fa[u][i-1]][i-1];
	for(int v:e[u]) if(v!=p){
		dfs1(v,u);
		f[u]=f[u]*(f[v]+1)%P;
		sm[u]=(sm[u]+sm[v]+f[v])%P;
	}
	out[u]=ti;
}

void dfs2(int u,int p){
	if(p){
		int z=f[p]*qp(f[u]+1,P-2)%P;
		int t=(z+sm[p]-sm[u]-f[u]+P)%P;
		jp[u][0]={z,z,z,t};
		rep(i,1,K) if(fa[u][i])
			jp[u][i]=mg(jp[fa[u][i-1]][i-1],jp[u][i-1]);
	}
	up[u]=p?al[p]*qp(f[u]+1,P-2)%P:1;
	al[u]=up[u]*f[u]%P;
	for(int v:e[u]) if(v!=p) dfs2(v,u);
	iv[u]=qp(f[u]+1,P-2);
	iu[u]=qp(up[u],P-2);
}

bool anc(int x,int y){
	return dfn[x]<=dfn[y]&&out[y]<=out[x];
}

int lca(int x,int y){
	if(anc(x,y)) return x;
	if(anc(y,x)) return y;
	per(i,0,K) if(fa[x][i]&&!anc(fa[x][i],y)) x=fa[x][i];
	return fa[x][0];
}

int getc(int x,int y){
	per(i,0,K) if(dep[fa[x][i]]>dep[y]) x=fa[x][i];
	return x;
}

D que(int x,int y){
	D r={1,0,0,0};
	per(i,0,K) if(dep[fa[x][i]]>dep[y])
		r=mg(jp[x][i],r),x=fa[x][i];
	return r;
}

void build(vector<int> a){
	a.push_back(1);
	sort(a.begin(),a.end(),[](int x,int y){return dfn[x]<dfn[y];});
	a.erase(unique(a.begin(),a.end()),a.end());
	int m=a.size();
	rep(i,1,m-1) a.push_back(lca(a[i-1],a[i]));
	sort(a.begin(),a.end(),[](int x,int y){return dfn[x]<dfn[y];});
	a.erase(unique(a.begin(),a.end()),a.end());
	vs=a;
	for(int u:vs) ve[u].clear();

	vector<int> st;
	for(int u:vs){
		while(st.size()&&!anc(st.back(),u)) st.pop_back();
		if(st.size()) ve[st.back()].push_back(u);
		st.push_back(u);
	}
}

void prep(int u){
	vis[u]=0;
	if(!X&&!Y&&!Z) ans=(ans+sm[u])%P;
	for(int v:ve[u]){
		nx[v]=getc(v,u),sg[v]=que(v,u);
		if(!X&&!Y&&!Z)
			ans=(ans-sm[nx[v]]-f[nx[v]]+2*P)%P;
	}
	for(int v:ve[u]){
		prep(v);
		if(!X&&!Y&&!Z) ans=(ans+sg[v].t)%P;
		ve[v].push_back(u);
	}
}

void gs(int u,int p){
	sz[u]=1;
	for(int v:ve[u]) if(v!=p&&!vis[v])
		gs(v,u),sz[u]+=sz[v];
}

void gr(int u,int p,int s){
	int mx=s-sz[u];
	for(int v:ve[u]) if(v!=p&&!vis[v])
		gr(v,u,s),mx=max(mx,sz[v]);
	if(mx<bs) bs=mx,rt=u;
}

void ord(int u,int p){
	pa[u]=p,sz[u]=1;
	sa+=c[u]==A,sb+=c[u]==B,sc+=c[u]==C;
	od[++ct]=u;
	for(int v:ve[u]) if(v!=p&&!vis[v])
		ord(v,u),sz[u]+=sz[v];
	ed[u]=ct;
}

int val(int u){
	int x=al[u];
	for(int v:ve[u]){
		if(dep[v]<dep[u]) x=x*iu[u]%P;
		else x=x*iv[nx[v]]%P;
		if(vis[v]){
			if(dep[v]<dep[u]) x=x*(sg[u].r+1)%P;
			else x=x*(sg[v].l+1)%P;
		}
	}
	return x;
}

void calc(int r){
	if(sa<X||sb<Y||sc<Z) return;
	rep(i,1,ct) rep(a,0,X) rep(b,0,Y) rep(c,0,Z) dp[i][a][b][c]=0;

	int a=c[r]==A,b=c[r]==B,d=c[r]==C;
	if(a<=X&&b<=Y&&d<=Z) dp[1][a][b][d]=val(r);

	rep(i,2,ct){
		int u=od[i],p=pa[u];
		D z=dep[p]<dep[u]?sg[u]:sg[p];
		int st=dep[p]<dep[u]?z.l+1:z.r+1;
		if(st>=P) st-=P;
		int w=val(u),da=c[u]==A,db=c[u]==B,dc=c[u]==C;

		rep(a,0,X) rep(b,0,Y) rep(d,0,Z){
			int cur=dp[i-1][a][b][d];
			if(!cur) continue;
			dp[ed[u]][a][b][d]=(dp[ed[u]][a][b][d]+cur*st)%P;
			if(a+da<=X&&b+db<=Y&&d+dc<=Z)
				dp[i][a+da][b+db][d+dc]
				=(dp[i][a+da][b+db][d+dc]+cur*z.s%P*w)%P;
		}
	}
	ans=(ans+dp[ct][X][Y][Z])%P;
}

void dvd(int s){
	gs(s,0),bs=1e9,gr(s,0,sz[s]);
	int u=rt;
	sa=sb=sc=ct=0,ord(u,0),calc(u);
	vis[u]=1;
	for(int v:ve[u]) if(!vis[v]) dvd(v);
}

void solve(){
	cin>>A>>X>>B>>Y>>C>>Z;
	if(X>ps[A].size()||Y>ps[B].size()||Z>ps[C].size()){
		cout<<0<<'\n'; return;
	}
	vector<int> a;
	for(int u:ps[A]) a.push_back(u);
	for(int u:ps[B]) a.push_back(u);
	for(int u:ps[C]) a.push_back(u);

	build(a),ans=0;
	prep(1);
	dvd(1);
	cout<<ans%P<<'\n';
}

signed main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	cin>>n>>q;
	rep(i,1,n) cin>>c[i],ps[c[i]].push_back(i);
	rep(i,2,n){
		int u,v; cin>>u>>v;
		e[u].push_back(v),e[v].push_back(u);
	}
	dfs1(1,0),dfs2(1,0);
	while(q--) solve();
	return 0;
}

**You:**

处理链的四个信息的时候旁边那些没有关键点的链是怎么算进去的

**ChatGPT:**

对，**旁边那些没有关键点的支链 / 支树，不是单独塞进虚树的，而是在预处理每一段链的时候直接压成乘法系数了。**

你可以把虚边对应的原树路径想成：

```
u
|
x ---- A
|      └── 一大坨没有关键点的支树
y ---- B
|
v
```

真正虚边骨架只有

$$u-x-y-v$$

但 $x,y$ 旁边的 $A,B$ 当然不能丢，因为一个连通块经过 $x$ 时，可以顺便往 $A$ 里面伸进去任意一个**包含 $A$ 根节点**的连通块。

---

先预处理

$$f_u=\#\{\text{完全位于 }subtree(u)\text{，且包含 }u\text{ 的连通块}\}.$$

那么标准树 DP 就是

$$\boxed{ f_u=\prod_{v\in son(u)}(f_v+1) }$$

因为对每个儿子 $v$：

* 不往这个方向走：$1$
* 往里面走：必须选一个包含 $v$ 的连通块，共 $f_v$ 种。

---

现在考虑链上一条有向边

$$p\to u$$

其中 $u$ 是 $p$ 在主链上的下一个点。

我们要把 $p$ 旁边**除了 $u$ 方向之外的所有支树**揉成一个数。

设

$$z_{p\to u} = \prod_{\substack{v\in son(p)\\v\ne u}} (f_v+1).$$

这就是：

> 连通块已经包含 $p$，但不往主链的 $u$ 方向走时，旁边那些支树一共有多少种接法。

由于

$$f_p=\prod_{v\in son(p)}(f_v+1),$$

$$\boxed{ z_{p\to u} = \frac{f_p}{f_u+1} }$$

模意义下就是乘逆元。

你之前代码里的：

```

就是这个。

举个具体的：

```
        a
        |
        p
      / | \
     A  B  u
           |
         主链继续
```

假设

$$f_A=3,\qquad f_B=5.$$

那么如果主链连通块经过 $p$，对于 $A$：

$$1+3=4$$

$$1+5=6.$$

所以旁枝总贡献：

$$z=4\times6=24.$$

这 24 种情况全部被压进链上“经过 $p$”这个骨架状态里。

所以链 DP 看起来只是在处理：

```
u -- x -- y -- v
```

实际上每个 $x,y$ 都携带一个权：

$$z_x,z_y.$$

---

而四元组中的

$$S,L,R,T$$

已经不是单纯的“链上有几个区间”，而是**带着这些支树权值的计数**。

比如整段都贯通：

$$S=z_1z_2\cdots z_k.$$

因为每一个骨架点都被选，所以它旁边的所有无关键支树都可以独立选择。

左连续 $L$ 也是类似：

$$z_1 + z_1z_2 + z_1z_2z_3 +\cdots$$

另外还有一类你可能马上会问：

> 如果一个连通块**完全藏在旁边支树里，连链上的 $p$ 都没选**，怎么算？

这就是四元组里的

$$T$$

为什么不能只由 $S,L,R$ 推出来。

预处理

$$sm_u$$

表示：

> 完全位于 $subtree(u)$，但**不包含 $u$** 的连通块数量。

有

$$sm_u = \sum_{v\in son(u)}(sm_v+f_v).$$

因此对于链边 $p\to u$，把 $u$ 方向切掉后，这一“层”内部所有连通块数量就是

$$\boxed{ t = z + sm_p-sm_u-f_u }$$

其中：

* $z$：包含 $p$ 的；
* $sm_p-sm_u-f_u$：完全藏在其他旁枝里的。

所以初始化一个链片段时：

$$\boxed{ (S,L,R,T)=(z,z,z,t) }$$

然后再用

$$(S,L,R,T)_A\oplus(S,L,R,T)_B$$

不断合并。

所以一句话概括：

$$\boxed{ \text{主链之外的无关键支树} \rightarrow (f_v+1)\text{ 乘法权} \rightarrow \text{揉进每个链节点的 }z,t \rightarrow \text{再进入 }(S,L,R,T) }$$

也就是说，虚树看似把那些点删了，实际上它们全变成了**虚边上的权值**。这就是这题压缩最妙的地方。

        -----u----- 虚树邻居
             |
           普通支树
          /       \
        普通      普通
```

那么虚树方向全被剥掉，只留下普通支树随便选。

这就是 val(u) 的基础。

## 那后面的 if(vis[v]) 是什么？

这里是点分治导致的。

假设当前正在递归处理一个点分治连通块：

```
       已经被删掉的重心 v
              |
       .....虚边.....
              |
              u
             / \
        当前分治块内部
```

vis[v]=1 表示 $v$ 已经在上一层点分治被作为重心处理掉了。

那么当前这一轮统计的连通块**绝对不能包含 $v$**。

否则这个连通块早就在上一层“包含 $v$”时统计过了。

但是！

它仍然可以从 $u$ 朝 $v$ 的方向走一截：

```
v -- a -- b -- c -- u
         [b--c--u]
```

只要不到达 $v$，就是合法的。

所以刚才我们把这个方向整个除掉之后，对于 vis[v] 的方向，还要补回：

> 从 $u$ 出发沿虚边走一段，但在碰到 $v$ 之前停下。

---

### 如果 $v$ 在 $u$ 上方

```
v
|
...虚边...
|
u
```

从 $u$ 看是虚边的**右端往左走**，所以使用：

$$sg[u].r.$$

再加上“一步都不走”的方案：

$$sg[u].r+1.$$

所以：

```
x=x*(sg[u].r+1)%P;
```

---

### 如果 $v$ 在 $u$ 下方

```
u
|
...虚边...
|
v
```

从 $u$ 看是虚边的**左端往右走**，所以：

$$sg[v].l+1.$$

代码：

```
x=x*(sg[v].l+1)%P;
```

---

所以整个 val(u) 可以压成一句公式。

先有：

$$al_u$$

表示全方向随便长。

对每个**当前虚树邻居**，先把对应方向除掉：

$$\div \text{该方向原本的完整贡献}.$$

如果这个邻居已经被点分治删掉：

$$\times \text{“可以沿虚边走一截但不能碰到它”的贡献}.$$

最终：

$$\boxed{ val(u) = \text{强制选 }u\text{ 后，不与当前虚树 DP 冲突的所有局部扩展方案} }$$

---

最关键的是区分两类虚树邻居：

### !vis[v]

还在当前点分治块里。

这个方向**完全交给 DFS 序 DP 决定**，所以删掉以后什么都不补。

### vis[v]

已经是过去某层的分治重心。

不能再碰到 $v$，但可以往那边的虚边内部伸一截，所以：

$$\boxed{\text{删完整方向，再补“不到端点”的前缀/后缀}}$$

这就是 val 里那个看起来有点诡异的第二个 if(vis[v]) 的本质。

## 1. od / pa / ed 是什么

前面 ord(r,0) 已经把当前点分治连通块**重新以 $r$ 为根**做了一次 DFS。

比如：

```
        r
      /   \
     a     b
    / \
   c   d
```

可能有：

```
od = [r,a,c,d,b]
       1 2 3 4 5
```

同时：

$$pa[u]=\text{当前这棵“以重心为根”的树里的父亲}$$

以及：

$$ed[u]=u\text{ 的子树在 DFS 序中的最后一个位置}.$$

例如：

$$ed[a]=4.$$

注意这里的 pa 跟原树的 fa **不是一个东西**。

点分治重心可能在原树中间，所以当前 DFS 的一条父子边可能朝原树上走，也可能朝原树下走。

---

# 2. dp[i][a][b][c] 到底表示什么

可以理解成：

$$\boxed{ dp[i][a][b][c] }$$

表示：

> 当前已经把 DFS 序处理到位置 $i$，选出来的部分一定包含重心 $r$、保持连通，并且三种目标颜色出现次数分别为 $a,b,c$ 的方案数。

这里有一个特别重要的性质：

因为我们强制选择了 $r$，所以对于当前根树中的任意点 $u$：

$$u\text{ 被选} \Longrightarrow pa[u]\text{ 被选}.$$

反过来：

$$u\text{ 不选} \Longrightarrow subtree(u)\text{ 一个点都不能选}.$$

否则下面某个点没法和 $r$ 连起来。

所以每遇到一个 $u$，只有两种动作：

$$\boxed{\text{选 }u}$$

或者

$$\boxed{\text{不选 }u\text{，直接跳过整个 }subtree(u)}$$

这就是 calc 的全部灵魂。

---

# 3. 为什么先判断

```
if(sa<X||sb<Y||sc<Z) return;
```

sa,sb,sc 是当前点分治连通块中三种关键颜色节点的数量。

如果连整个当前块里都只有：

$$sa<X$$

那显然这一轮不可能凑够 $X$ 个颜色 $A$。

直接不算。

因为所有目标颜色节点都已经被放进虚树，所以虚边内部不会偷偷藏着目标颜色节点。

---

# 4. 初始化为什么是 val(r)

```
int a=c[r]==A,b=c[r]==B,d=c[r]==C;

dp[1][a][b][d]=val(r);
```

这一轮规定：

$$\boxed{r\text{ 必须选}}$$

所以颜色计数先加上 $r$：

$$([c_r=A],[c_r=B],[c_r=C]).$$

然后乘：

$$val(r).$$

刚才讲过，val(r) 就是：

> 选了 $r$ 后，那些不属于当前虚树骨架的普通方向一共有多少种接法。

所以初始化就是：

$$\boxed{ \text{选中心 }r \times \text{中心周围普通支树随便长} }$$

---

# 5. 处理 u=od[i]

```
int u=od[i],p=pa[u];
```

因为 $u\neq r$，它一定有当前点分治根树中的父亲 $p$。

现在考虑虚树边：

$$p-u.$$

但由于当前根是重心 $r$，这条边相对于**原树根 1**可能有两个方向。

---

# 6. 为什么这样取 z

```
D z=dep[p]<dep[u]?sg[u]:sg[p];
```

我们之前规定：

如果原虚树上有祖先 $x$ 和后代 $y$ 的边，那么这条虚边的信息存：

$$sg[y].$$

也就是存在原树更深的那个端点上。

所以：

### 如果

$$dep[p]<dep[u],$$

说明原树中：

$$p\to u$$

那么虚边信息就是：

$$sg[u].$$

### 否则

原树中其实是：

$$u\to p,$$

所以虚边信息存：

$$sg[p].$$

因此：

```
D z=dep[p]<dep[u]?sg[u]:sg[p];
```

只是为了找到这条无向虚边对应的四元组。

---

# 7. st 是什么意思

```
int st=dep[p]<dep[u]?z.l+1:z.r+1;
```

这是**不选 $u$** 时的贡献。

此时 $p$ 已经被选。

我们可以：

### 情况 1

虚边内部什么都不走：

```
[p] -- o -- o -- u
```

贡献：

$$1.$$

### 情况 2

从 $p$ 往 $u$ 方向走一截，但不能碰到 $u$：

```
[p -- o -- o] -- u
```

如果方向和原树一致：

$$p\to u,$$

那就是虚边的左连续状态：

$$z.l.$$

所以：

$$st=z.l+1.$$

如果当前点分治树的方向反过来了：

```
u -- ... -- p
```

我们是从虚边的右端 $p$ 往左走，所以用：

$$z.r+1.$$

因此：

$$\boxed{ st=\text{从父亲 }p\text{ 朝 }u\text{ 走一截，但绝不碰 }u\text{ 的方案数} }$$

---

# 8. 不选 $u$ 的转移

```
dp[ed[u]][a][b][d]
	+=cur*st;
```

这是最漂亮的一步。

如果不选 $u$，那么因为整个最终集合必须和 $r$ 连通：

```
        p  已选
        |
        u  不选
       / \
      x   y
```

那么 $x,y$ 以及整个 $u$ 子树：

$$\boxed{\text{全部不可能选}}$$

所以不用一个个处理。

直接从 DFS 序的：

$$i-1$$

跳到：

$$ed[u].$$

即：

$$\boxed{ dp[ed_u][a][b][c] \mathrel{+}= dp[i-1][a][b][c]\cdot st }$$

为什么是 ed[u] 而不是 ed[u]+1？

因为我们的 dp[k] 表示“已经处理完前 $k$ 个 DFS 序节点”。

跳过整个 $u$ 子树后，恰好处理到了：

$$ed[u].$$

以后循环走到：

$$i=ed[u]+1$$

时，会读取：

```
dp[i-1]
```

也就是刚才的：

```
dp[ed[u]]
```

严丝合缝。

---

# 9. 选 $u$ 为什么乘 z.s

如果 $u$ 被选，而且 $p$ 已经被选，那么为了保持连通：

```
[p] -- o -- o -- [u]
```

中间整条虚边的内部骨架都必须被选。

所以虚边内部必须是“四元组的整段贯通状态”：

$$\boxed{z.s}$$

它不仅包含中间骨架点，还已经把那些骨架点旁边的普通支树选择一起计数了。

---

# 10. 为什么还乘 w=val(u)

```
int w=val(u);
```

选了 $u$ 以后，$u$ 周围那些**不属于当前虚树方向**的普通支树也可以自由扩展。

这些方案就是：

$$val(u).$$

因此选 $u$ 的局部贡献为：

$$\boxed{z.s\cdot val(u)}$$

一个负责：

* $p$ 与 $u$ 中间的压缩虚边；

另一个负责：

* $u$ 自己旁边剩下的普通方向。

不会重复。

---

# 11. 颜色怎么加

```
int da=c[u]==A;
int db=c[u]==B;
int dc=c[u]==C;
```

如果 $u$ 的颜色是 $A$，那么选择 $u$ 后：

$$a\to a+1.$$

所以：

```
dp[i][a+da][b+db][d+dc]
	+=cur*z.s*w;
```

即：

$$\boxed{ dp[i][a+\delta_A][b+\delta_B][c+\delta_C] \mathrel{+}= dp[i-1][a][b][c]\cdot z.s\cdot val(u) }$$

这里更新到 dp[i]，因为：

> 我选了 $u$，所以只是正常处理完 DFS 序第 $i$ 个节点。

下一步接着考虑第 $i+1$ 个。

---

# 12. 所以每个节点就是两条边

可以把整个 calc 看成一个 DAG DP。

对 DFS 序第 $i$ 个点 $u$：

### 选

$$i-1\to i$$

贡献：

$$z.s\cdot val(u)$$

并加颜色。

### 不选

$$i-1\to ed[u]$$

贡献：

$$st$$

颜色不变。

就是：

```
             选 u
       i-1 ---------> i
        |
        |
        | 不选 u
        v
      ed[u]
```

所以它已经完全不像传统树形背包了，而是一个**DFS 序上的跳跃 DP**。

---

# 13. 为什么最后取

```
dp[ct][X][Y][Z]
```

ct 是当前点分治连通块的虚树节点数。

所以：

$$dp[ct][X][Y][Z]$$

就是：

> 整个当前分治块都已经处理完，包含重心 $r$，三种颜色数量恰好为 $X,Y,Z$ 的方案数。

于是：

```
ans+=dp[ct][X][Y][Z];
```

---

## 最后把 calc 压成四行意义

$$\boxed{ \text{钦定 }r\text{ 被选} }$$

对 DFS 序每个 $u\neq r$：

$$\boxed{ \begin{cases} \text{不选 }u: & dp_{ed_u}\mathrel{+}=dp_{i-1}\cdot(\text{虚边走一截})\\[4pt] \text{选 }u: & dp_i\mathrel{+}=dp_{i-1}\cdot(\text{整条虚边})\cdot val(u) \end{cases}}$$

其中不选 $u$ 就能直接跳掉整个子树，是因为：

$$\boxed{\text{包含重心的连通块在当前根树上一定祖先闭包}}$$

这个性质就是点分治把原来 $S^2$ 树形背包压成 $S$ 序列 DP 的根本原因。

	if (fa[u][0])
	{
		ll val = f[fa[u][0]] * iv % P;
		st[u][0] = {val, val, val,
			(val + sum[fa[u][0]] - sum[u] - f[u] + (P << 1)) % P};

		for (int i = 1; i <= __lg(n); ++i)
			if (fa[u][i])
				st[u][i] = st[fa[u][i - 1]][i - 1] + st[u][i - 1];
	}

	fi[u] = iv;
	g[u] = fa[u][0] ? h[fa[u][0]] * iv % P : 1;
	gi[u] = qpow(g[u], P - 2);
	h[u] = f[u] * g[u] % P;

	for (int i = head1[u], v; i; i = e1[i].next)
	{
		if ((v = e1[i].v) == fa[u][0])
			continue;
		dfs2(v);
	}
}
```

这样每个点从 4 次快速幂降成 2 次。

**ChatGPT:**

对，**C++14 没有规定赋值表达式一定“先算右边，再算左边”**。

你这句：

```
ch[v] = getc(v = e2[i].v, u);
```

在 C++14 里，= 左右两个操作数的求值顺序没有被规定。于是可能发生：

```
先算 ch[v]          // 读取 v
再算 v = e2[i].v    // 修改 v
```

也可能反过来。

更关键的是，C++14 中这两个操作还是 **unsequenced** 的。同一个完整表达式里：

* 左边读取 v
* 右边修改 v

没有先后关系，因此直接是 **Undefined Behavior**，不是单纯“顺序未指定但任选一个都合法”。

所以不是：

> O2 把本来应该右边优先的东西改成左边优先。

而是：

> **C++14 从一开始就没承诺右边优先。**

-O0 下碰巧按照你想的顺序跑，也只是运气；-O2 遇到 UB 后会做更激进的优化，所以症状可能更离谱。

---

有意思的是，**C++17 改了这个规则**。

从 C++17 开始，对于：

```
lhs = rhs;
```

规定：

$$\boxed{\text{rhs 的求值先于 lhs}}$$

所以在 C++17 及以后：

```
ch[v] = getc(v = e2[i].v, u);
```

这里会先执行

```
v = e2[i].v;
```

然后才计算

```
ch[v]
```

这句就变成有定义了。

所以可以记成：

$$\boxed{ \text{C++14：这句 UB} \qquad \text{C++17：右边先算，合法} }$$

不过竞赛代码里我还是强烈建议拆：

```
v = e2[i].v;
ch[v] = getc(v, u);
```

这种求值顺序地雷属于“今天 AC，明天换编译器召唤恶灵”那一类。
