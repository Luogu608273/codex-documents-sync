# P7214 [JOISC 2020] 治療計画

## 题目背景

JOI 村庄的村民们最近发生了 COVILLAGE-19 疫情！

## 题目描述

JOI 村庄有 $N$ 个房屋，编号为 $1$ 到 $N$，每个房屋住有一个村民，第 $i$ 个房屋居住编号为村民 $i$。

现在，这 $N$ 个房屋里的村民全部感染 COVILLAGE-19 病毒，有 $M$ 个治疗方案被提出，第 $i$ 个治疗方案描述为，在第 $T_i$ 天的晚上，编号在 $[L_i,R_i]$ 区间内的村民被治愈。

COVILLAGE-19 病毒还会继续传播，在某天早上，如果村民 $i$ 被感染，那么村民 $i+1$ 和村民 $i-1$ 也会被感染，因为病毒威力巨大，所以被治愈的村民有可能再次被感染。

您是 JOI 国的总理，您要选择一些方案使得 JOI 村庄所有村民全部被治愈，一天可以进行很多方案。

第 $i$ 个方案要花费 $C_i$，求最小花费。

Solution: 
先把这玩意儿放在平面上看一看。

一个治疗计划 $(t_i,l_i,r_i)$，对应的是平面上的一条线段 $((l_i,t_i), (r_i,t_i))$，以这条线段为斜边做一个等腰直角三角形，就是能治疗的二维范围。

![](https://cdn.luogu.com.cn/upload/image_hosting/v9dzruyl.png)

我们对这些割边一样的东西连边，每个三角形就是一个点，令 $dis_i$ 表示在 $t_i$ 时刻能治疗好前缀为 $r_i$ 所有人的最小代价，跑出来的最短路就是答案，但是连边是 $n^2$ 的。观察到连边的条件是 $|t_i-t_j|\le r_i-l_j+1$，排序 $t$ 可以把绝对值拆开。

![](https://cdn.luogu.com.cn/upload/image_hosting/eci6rgpi.png)

而且红色路径不一定连续，对于出现上面那种相离但是连边的情况，能保证 $i$ 和左侧一定联通，$j$ 和右侧一定联通，说明 $i$ 的“着陆点”一定是在 $j$ 与右侧联通的路径上的。如下图，一红一蓝的点对应上面路径的“着陆点”，即使相离也是合法的。

然后这里有一个关键结论：点权最短路能保证每个点只被松弛一次，这个是容易理解的，于是我们把开头的都入队，然后直接线段树上找决策点就好。

### 算法分析

将每个治疗方案视为一个决策点。按时间 $T$ 从小到大排序后，方案 $u$ 能够转移到方案 $v$ 的充要条件是：
$$|T_u - T_v| \le R_u - L_v + 1$$

将该条件按 $T_u$ 与 $T_v$ 的大小关系拆开：
1. 当 $v \ge u$（即 $T_v \ge T_u$）时：
   $$T_v - T_u \le R_u - L_v + 1 \iff L_v + T_v \le R_u + T_u + 1$$
2. 当 $v < u$（即 $T_v \le T_u$）时：
   $$T_u - T_v \le R_u - L_v + 1 \iff L_v - T_v \le R_u - T_u + 1$$

转移的边权为终点的花费 $C_v$，所有 $C_i > 0$。由 Dijkstra 的贪心性质可知：
按照已确定的最短路从小到大出堆时，一个未访问的点 $v$ **第一次**被松弛时得到的一定就是其全局最短路。因此每个点至多被松弛并入堆一次。

我们可以用线段树维护未被松弛的点：
- `mn1` 维护区间内未访问点的 $\min(L_v + T_v)$；
- `mn2` 维护区间内未访问点的 $\min(L_v - T_v)$。

每次取出堆顶 $u$：
- 在区间 $[u, M]$ 中检索满足 $L_v + T_v \le R_u + T_u + 1$ 的点；
- 在区间 $[1, u - 1]$ 中检索满足 $L_v - T_v \le R_u - T_u + 1$ 的点。

在线段树上遍历到满足条件的叶子节点时，更新该点的最短路、加入优先队列，并在线段树中将该点的值置为 $\infty$（删除）。每个点只会被删除一次，因此线段树上遍历的总复杂度为严格的 $O(M \log M)$。

所有满足 $L_i = 1$ 的方案作为起点初始入堆，其最短路初值为 $C_i$。第一个出堆且满足 $R_u = N$ 的点的距离即为最小总花费。若堆空仍未到达右端点则无解输出 $-1$。

### C++ 代码

```cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <queue>

using namespace std;

const int N = 100005;
const long long INF = 2e18;

struct Node {
    long long t, l, r, c;
} a[N];

bool cmp(const Node &x, const Node &y) {
    return x.t < y.t;
}

long long n;
int m;
long long mn1[N << 2], mn2[N << 2], dis[N];
priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> q;

void pushup(int p) {
    mn1[p] = min(mn1[p << 1], mn1[p << 1 | 1]);
    mn2[p] = min(mn2[p << 1], mn2[p << 1 | 1]);
}

void build(int p, int l, int r) {
    if (l == r) {
        if (a[l].l == 1) {
            mn1[p] = mn2[p] = INF;
        } else {
            mn1[p] = a[l].l + a[l].t;
            mn2[p] = a[l].l - a[l].t;
        }
        return;
    }
    int mid = (l + r) >> 1;
    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);
    pushup(p);
}

void qry1(int p, int l, int r, int ql, int qr, long long val, int u) {
    if (l > qr || r < ql || mn1[p] > val) return;
    if (l == r) {
        dis[l] = dis[u] + a[l].c;
        q.push({dis[l], l});
        mn1[p] = mn2[p] = INF;
        return;
    }
    int mid = (l + r) >> 1;
    qry1(p << 1, l, mid, ql, qr, val, u);
    qry1(p << 1 | 1, mid + 1, r, ql, qr, val, u);
    pushup(p);
}

void qry2(int p, int l, int r, int ql, int qr, long long val, int u) {
    if (l > qr || r < ql || mn2[p] > val) return;
    if (l == r) {
        dis[l] = dis[u] + a[l].c;
        q.push({dis[l], l});
        mn1[p] = mn2[p] = INF;
        return;
    }
    int mid = (l + r) >> 1;
    qry2(p << 1, l, mid, ql, qr, val, u);
    qry2(p << 1 | 1, mid + 1, r, ql, qr, val, u);
    pushup(p);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    if (!(cin >> n >> m)) return 0;
    for (int i = 1; i <= m; i++) {
        cin >> a[i].t >> a[i].l >> a[i].r >> a[i].c;
    }
    sort(a + 1, a + 1 + m, cmp);
    for (int i = 1; i <= m; i++) {
        dis[i] = INF;
        if (a[i].l == 1) {
            dis[i] = a[i].c;
            q.push({dis[i], i});
        }
    }
    build(1, 1, m);
    long long ans = -1;
    while (!q.empty()) {
        auto cur = q.top();
        q.pop();
        long long d = cur.first;
        int u = cur.second;
        if (d > dis[u]) continue;
        if (a[u].r == n) {
            ans = d;
            break;
        }
        qry1(1, 1, m, u, m, a[u].r + a[u].t + 1, u);
        if (u > 1) qry2(1, 1, m, 1, u - 1, a[u].r - a[u].t + 1, u);
    }
    cout << ans << "\n";
    return 0;
}
```
