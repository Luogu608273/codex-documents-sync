## 原第 1 轮

### 用户

讲解一下分块中的常用技巧逐块处理

### 历史助手

在信息学竞赛中，“逐块处理”（也常被称为离线逐块处理）是分块算法中一种非常经典且实用的空间优化技巧。

## **核心思想**

常规的分块算法通常是“以询问为主体”：遍历每个询问，然后在原序列上遍历该询问涉及到的各个块以及散块，计算答案。如果在处理询问时，需要用到预先计算好的“块与块之间”或“块内前缀/后缀”等信息，这类辅助数组通常需要开到二维，空间复杂度往往会达到 *O*(*NN*​)。

“逐块处理”则是将两层循环的顺序反转，变为“以块为主体”**： 从左到右依次遍历每一个块，预处理出当前块的信息，然后遍历**所有离线下来的询问，计算当前这个块对各个询问的贡献并累加到询问的答案中。处理完当前块后，清空信息并继续处理下一个块。

## **主要优势**

> 1. **空间优化**：由于每次只处理一个块，原本需要 *O*(*NN*​) 空间的二维状态数组被降维到了 *O*(*N*) 甚至更低。这在空间限制较紧（如 128MB 甚至更小）的题目中是必不可少的。  
> 2. **缓存友好（Cache Locality）**：集中处理一个块并在该块内遍历所有询问，往往能带来更好的 CPU 缓存命中率，在实际运行中能起到不错的卡常效果。

## **适用条件**

> * **必须支持离线**：我们需要在处理第 *i* 个块时知道所有的询问，所以这种技巧只适用于可以将询问全部读入后再统一处理的题目。  
> * **贡献具有可加性/可独立计算**：各个块对某一个询问的贡献必须能够被独立计算，并与其他块的贡献进行累加或合并（例如求和、求最值等）。

## **典型应用场景**

> 1. **区间元素属性统计**：例如求区间内某元素的出现次数。如果直接维护前缀和，空间是 *O*(*NN*​)。逐块处理时，每次只需维护当前块的权值分布，配合扫描线思想，空间降至 *O*(*N*)。  
> 2. **配合二次离线莫队**：在莫队二次离线算法中，询问的移动往往会转化为前缀信息与单点信息的交互。如果相关辅助空间过大，也可以利用类似思想，将离线下来的贡献请求按块依次扫描处理，从而将空间复杂度压缩到线性。

## 原第 2 轮

### 用户

讲解一下二次离线莫队

### 历史助手

二次离线莫队是由 lxl（noip）提出的一种莫队算法的优化技巧。它主要解决的问题是：**当普通莫队算法在移动区间端点时，如果单次转移的时间复杂度不是 *O*(1) 而是 *O*(*k*)，会导致总复杂度达到 *O*(*nn*​*k*) 从而无法通过。**

二次离线莫队通过将端点移动产生的贡献进行差分，并把这些询问“二次离线”下来，最后通过一次扫描线来统一计算，将总复杂度优化至 *O*(*nn*​\+*n*×*k*)。

## **核心思想：差分与状态转化**

在普通莫队中，假设当前维护的区间是 \[*l*,*r*\]，现在要向右扩展右端点，加入元素 *a*\[*r*\+1\]，我们需要求出 *a*\[*r*\+1\] 与集合 \[*l*,*r*\] 中所有元素产生的贡献（记作 *f*(*a*\[*r*\+1\],\[*l*,*r*\])）。如果这个贡献满足**可减性**，我们可以利用前缀思想将其差分为两部分：

*f*(*a*\[*r*\+1\],\[*l*,*r*\])=*f*(*a*\[*r*\+1\],\[1,*r*\])−*f*(*a*\[*r*\+1\],\[1,*l*−1\])

> 1. **第一部分 *f*(*a*\[*r*\+1\],\[1,*r*\])**：只和当前插入的位置有关，它可以提前 *O*(*n*×*k*) 或者 *O*(*n*) 预处理出来（通常记为 pre\[r+1\]）。  
> 2. **第二部分 *f*(*a*\[*r*\+1\],\[1,*l*−1\])**：表示元素 *a*\[*r*\+1\] 与前缀 \[1,*l*−1\] 产生的贡献。

当莫队的右端点从 *R*1​ 连续向右扩展到 *R*2​ 时，累计产生的第二部分贡献实际上就是求：区间 \[*R*1​\+1,*R*2​\] 中的每一个元素，分别与前缀 \[1,*l*−1\] 产生的贡献之和。

因为莫队移动的总步数是 *O*(*nn*​) 的，但**产生前缀询问的次数**（即莫队端点连续移动的段数）只有 *O*(*nn*​) 段。我们可以把这段对前缀 *l*−1 的询问“挂载”（记录）在下标 *l*−1 处。

## **算法步骤**

> 1. **第一次离线**：像普通莫队一样，将所有询问读入、分块、排序。  
> 2. **模拟莫队（但不计算真实答案）**：模拟指针 *L*,*R* 的移动。将 *L*,*R* 移动时产生的贡献利用差分拆解：其中前缀自带的部分直接利用预处理数组累加，而涉及到跨越区间的、关于前缀的询问，则记录下来（挂载到对应的前缀位置上）。这就是**第二次离线**。  
> 3. **扫描线处理挂载询问**：从 1 到 *n* 从左向右扫描序列，动态维护当前前缀的值域状态（比如用分块、树状数组等）。到达每个位置时，遍历挂载在该位置的所有区间询问，利用 *O*(1) 或 *O*(*k*) 的代价计算出该区间的贡献和。  
> 4. **计算最终答案**：对莫队移动产生的贡献求前缀和，得到每个原始询问的真实答案。

## **端点移动的差分推导**

设 pre\[i\] 表示 *a*\[*i*\] 与 \[1,*i*−1\] 的贡献。莫队指针从当前的 \[*l*,*r*\] 移动到目标 \[*L*,*R*\] 时，四种移动情况产生的挂载区间和符号（权值）如下：

> * **右端点右移 (*r*→*R*)**：新加入 \[*r*\+1,*R*\]。对每个 *i*∈\[*r*\+1,*R*\]，其贡献为 pre\[i\] 减去与前缀 \[1,*L*−1\] 的贡献。挂载在 *L*−1，区间 \[*r*\+1,*R*\]，符号为 −1。  
> * **右端点左移 (*r*→*R*)**：需删去 \[*R*\+1,*r*\]。挂载在 *L*−1，区间 \[*R*\+1,*r*\]，符号为 1。  
> * **左端点左移 (*l*→*L*)**：新加入 \[*L*,*l*−1\]。对每个 *i*∈\[*L*,*l*−1\]，其贡献等于其与前缀 \[1,*R*\] 的贡献减去与前缀 \[1,*i*\] 的贡献。挂载在 *R*，区间 \[*L*,*l*−1\]，符号为 1。  
> * **左端点右移 (*l*→*L*)**：需删去 \[*l*,*L*−1\]。挂载在 *R*，区间 \[*l*,*L*−1\]，符号为 −1。

    sort(q \+ 1, q \+ 1 \+ m, cmp);

    // 莫队二次离线过程  
    int l \= 1, r \= 0;  
    for (int i \= 1; i \<= m; i++) {  
        int L \= q\[i\].l, R \= q\[i\].r, id \= q\[i\].id;  
        if (r \< R) add(L \- 1, r \+ 1, R, id, \-1);  
        while (r \< R) ans\[id\] \+= pre\[++r\];  
        if (r \> R) add(L \- 1, R \+ 1, r, id, 1);

        if (l \< L) add(R, l, L \- 1, id, \-1);  
        while (l \< L) ans\[id\] \+= pre\[l++\];   
    }  
    // 扫描线处理挂载的询问  
    // 记得先清空前面用过的值域结构

        insert(i); // 将 a\[i\] 加入当前前缀

            int ql \= e\[j\].l, qr \= e\[j\].r, id \= e\[j\].id, sign \= e\[j\].sign;  
            long long sum \= 0;  
            for (int k \= ql; k \<= qr; k++) {  
                sum \+= query(k);  
            }  
            ans\[id\] \+= sum \* sign;  
        }  
    }  
    // 莫队结果前缀和还原  
    for (int i \= 1; i \<= m; i++) {  
        ans\[q\[i\].id\] \+= ans\[q\[i \- 1\].id\];  
    }  
    // 最终输出答案等略  
    return 0;  
}

**关键细节补充**：二次离线莫队的难点通常在于左右端点移动时推导的式子不完全对称，这取决于题目中的贡献是否有方向性。上述代码在处理左端点移动时的 pre 数组往往需要特殊设计（如维护 *a*\[*i*\] 与前缀 \[1,*i*\] 的贡献而不是 \[1,*i*−1\]），具体推导需结合题目式子展开。
