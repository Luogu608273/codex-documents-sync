### $\texttt{Solution}$
在 dfn 序上考虑，点 $x$ 的子树补形如整个区间扣掉 $[dfn_x,dfn_x+siz_x-1]$，考虑直接分治。

一个分治区间 $[l,r]$，处理所有 $[dfn_x,dfn_x+siz_x-1]$ 完全包含于 $[l,r]$ 的询问，且已经加入了 $[1,l-1],[r+1,n]$ 的全部信息。

考虑每一层分治处理完所有跨过区间中点 $mid$ 的询问：由于子树区间只有包含关系，所有越过 $mid$ 的区间存在偏序关系，我们增量加入信息即可。

未跨过 $mid$ 的询问直接向下递归。

对于分治的每一层，显然处理跨过区间中点 $mid$ 的询问时进行的加入信息操作为 $O(n)$，则总加入次数为 $O(n\log n)$。

给出核心代码：
```cpp
void solve(vec p,int l,int r,int d){
	if(!p.size())return ;
	if(l==r){printf("=%d",rdfn[l]);return ;}
	int mid=l+((r-l)>>1);
	vec lt,rt;lt.clear();rt.clear();
	int lp=l-1,rp=r+1;
	for(auto x:p){
		if(R[x]<=mid)lt.eb(x);
		else if(x>mid)rt.eb(x);
		else{
			while(lp<x-1)trans(rdfn[++lp]);
			while(rp>R[x]+1)trans(rdfn[--rp]);
			printf("=%d",rdfn[x]);
		}
	}
	for(int i=lp;i>=l;i--)printf("-");
	for(int i=rp;i<=r;i++)printf("-");
	for(int i=mid+1;i<=r;i++)trans(rdfn[i]);
	solve(lt,l,mid,d+1);
	for(int i=mid+1;i<=r;i++)printf("-");
	for(int i=l;i<=mid;i++)trans(rdfn[i]);
	solve(rt,mid+1,r,d+1);
	for(int i=l;i<=mid;i++)printf("-");
	return ;
}
```

# P7124 [Ynoi2008] stcm

## 题目描述

给定一棵树，你可以维护一个集合，支持三种操作：

1. 当前集合中插入一个节点 $x$
2. 撤回上一次插入操作
3. 将当前点集标为第 $i$ 个点的子树补信息

一个点 $x$ 的子树补信息定义为，树的点集除去 $x$ 的子树（包括 $x$）内的点得到的集合；
需要保证每个点的子树补信息都是正确的。

## 输入格式

**本题输入含有多组测试数据。**

一组测试数据格式为：

第一行一个正整数 $n$。

之后一行 $n-1$ 个正整数，第 $i$ 个数表示 $i+1$ 节点的父亲节点 $j$，保证 $j<i+1$。

请读入至 EOF。

## 输出格式

对每一组数据，输出一个字符串，从左往右，每个"+x"形式的子串代表进行一次 1 操作，对象为编号 $x$ 的节点，每个"-"子串代表进行一次 2 操作，每个"=x"形式的子串代表进行一次 3 操作，对象为编号 $x$ 的节点，每个"!"子串代表全部操作都已结束，在其后面的任何输入会被忽略，字符串必须以"!"表示结束。

输出的字符串中不允许以任何空白字符分隔。

## 输入输出样例 #1

### 输入 #1

```
6
1 1 2 3 3
6
1 1 2 3 3
```

### 输出 #1

```
=1+1+3+5+6=2+2=4----+4+2=3+3+6=5-+5=6!
=1+1+3+5+6=2+2=4----+4+2=3+3+6=5-+5=6!
```

### 历史助手

这是一个分治做法，基本思想是在 dfn 序上进行范围分治。对于当前的分治区间 $[l, r]$，我们维护一个集合，使其包含所有在 dfn 范围 $[1, l-1]$ 和 $[r+1, n]$ 内的点。

### 解法思路
1. **分治结构**：`solve(p, l, r)` 处理所有子树区间 $[L_u, R_u]$ 完全包含在 $[l, r]$ 中的点集 $p$。
2. **跨越中点的点 (mt)**：若一个点的子树区间 $[L_u, R_u]$ 跨越了 $mid$，由于子树区间只有包含或不相交的关系，所有跨越 $mid$ 的区间必然是嵌套的。我们可以按 $L_u$ 从小到大排序，增量地将 $[l, L_u-1]$ 和 $[R_u+1, r]$ 中的点加入集合，从而得到该点的子树补集。
3. **递归处理**：
   - 递归左区间 $[l, mid]$：将 $[mid+1, r]$ 中的点加入集合。
   - 递归右区间 $[mid+1, r]$：将 $[l, mid]$ 中的点加入集合。
4. **操作限制**：通过这种分治方式，每个点被“加入”集合的次数约为 $O(\log n)$，总操作次数在 $4.5 \times 10^6$ 以内。

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>

using namespace std;

const int N = 100005;
vector<int> g[N];
int L[N], R[N], rdfn[N], timer;

void dfs(int u) {
    L[u] = ++timer;
    rdfn[timer] = u;
    for (int v : g[u]) dfs(v);
    R[u] = timer;
}

inline void write(int x) {
    static char s[12];
    int c = 0;
    while (x) s[c++] = x % 10 + '0', x /= 10;
    while (c--) putchar(s[c]);
}

inline void add(int x) { putchar('+'); write(x); }
inline void tag(int x) { putchar('='); write(x); }
inline void del() { putchar('-'); }

void solve(vector<int>& p, int l, int r) {
    if (p.empty()) return;
    if (l == r) {
        tag(rdfn[l]);
        return;
    }
    int mid = (l + r) >> 1;
    vector<int> lt, rt, mt;
    for (int x : p) {
        if (R[x] <= mid) lt.push_back(x);
        else if (L[x] > mid) rt.push_back(x);
        else mt.push_back(x);
    }
    sort(mt.begin(), mt.end(), [](int a, int b) {
        return L[a] < L[b];
    });
    int lp = l - 1, rp = r + 1, cnt = 0;
    for (int x : mt) {
        while (lp < L[x] - 1) add(rdfn[++lp]), cnt++;
        while (rp > R[x] + 1) add(rdfn[--rp]), cnt++;
        tag(x);
    }
    while (cnt--) del();
    if (!lt.empty()) {
        int c = 0;
        for (int i = mid + 1; i <= r; i++) add(rdfn[i]), c++;
        solve(lt, l, mid);
        while (c--) del();
    }
    if (!rt.empty()) {
        int c = 0;
        for (int i = l; i <= mid; i++) add(rdfn[i]), c++;
        solve(rt, mid + 1, r);
        while (c--) del();
    }
}

int main() {
    int n;
    while (scanf("%d", &n) != EOF) {
        timer = 0;
        for (int i = 1; i <= n; i++) g[i].clear();
        for (int i = 2; i <= n; i++) {
            int p; scanf("%d", &p);
            g[p].push_back(i);
        }
        dfs(1);
        vector<int> p;
        p.reserve(n);
        for (int i = 1; i <= n; i++) p.push_back(i);
        solve(p, 1, n);
        putchar('!');
    }
    return 0;
}
```

```cpp
#include "testlib.h"
#include <vector>

using namespace std;

const int N = 100005;
const int MAX_PLUS = 4500000;

vector<int> g[N];
int L[N], R[N], sz[N], timer;
bool done[N], in_set[N];
int stp[MAX_PLUS + 5], top;

void dfs(int u) {
    L[u] = ++timer;
    sz[u] = 1;
    for (int v : g[u]) {
        dfs(v);
        sz[u] += sz[v];
    }
    R[u] = timer;
}

void solve_test(int test_idx, int n) {
    for (int i = 1; i <= n; i++) {
        g[i].clear();
        done[i] = false;
        in_set[i] = false;
    }
    for (int i = 2; i <= n; i++) {
        int p = inf.readInt();
        g[p].push_back(i);
    }
    timer = 0;
    dfs(1);
    top = 0;
    int plus_cnt = 0;
    int tagged_cnt = 0;

    while (true) {
        char op = ouf.readChar();
        if (op == '!') break;
        if (op == '+') {
            int x = ouf.readInt();
            if (x < 1 || x > n) quitf(_wa, "Test %d: Node index %d out of range", test_idx, x);
            if (in_set[x]) quitf(_wa, "Test %d: Node %d already in set", test_idx, x);
            plus_cnt++;
            if (plus_cnt > MAX_PLUS) quitf(_wa, "Test %d: Too many '+' operations", test_idx);
            stp[++top] = x;
            in_set[x] = true;
        } else if (op == '-') {
            if (top == 0) quitf(_wa, "Test %d: Nothing to undo", test_idx);
            in_set[stp[top--]] = false;
        } else if (op == '=') {
            int x = ouf.readInt();
            if (x < 1 || x > n) quitf(_wa, "Test %d: Node index %d out of range", test_idx, x);
            if (done[x]) quitf(_wa, "Test %d: Node %d tagged more than once", test_idx, x);
            if (top != n - sz[x]) quitf(_wa, "Test %d: Incorrect set size for node %d", test_idx, x);
            // 验证子树补：集合中所有点 y 必须满足 L[y] < L[x] 或 L[y] > R[x]
            // 这里为了效率，可以在 size 正确的前提下抽样检查或全量检查
            // 由于 size 已经确定且点不重复，只需检查所有点不在子树内
            // 此处使用 in_set 状态在 tag 时无法高效全量检查，但可以通过 top 维护的信息验证
            // 实际上，由于我们知道 size = n - sz[x]，只需验证集合中每个 y 满足不在子树内
            for (int i = 1; i <= top; i++) {
                int y = stp[i];
                if (L[y] >= L[x] && L[y] <= R[x])
                    quitf(_wa, "Test %d: Node %d in set is in subtree of %d", test_idx, y, x);
            }
            done[x] = true;
            tagged_cnt++;
        } else {
            quitf(_wa, "Test %d: Invalid character '%c' in output", test_idx, op);
        }
    }
    if (tagged_cnt < n) quitf(_wa, "Test %d: Only %d nodes tagged, expected %d", test_idx, tagged_cnt, n);
}

int main(int argc, char* argv[]) {
    registerTestlibCmd(argc, argv);
    int test_idx = 0;
    while (!inf.seekEof()) {
        int n = inf.readInt();
        solve_test(++test_idx, n);
    }
    quitf(_ok, "All tests passed");
    return 0;
}
```
