### 历史助手

本题可以通过**贡献法**结合树上连通块统计在 $O(n)$ 时间内解决。

### 思路分析
直接统计每条路径包含的颜色数较难处理，考虑反面计算：
统计每种颜色 $c$ 在多少个点对 $(u, v)$ 的路径上**没有出现**。
将整棵树中所有颜色为 $c$ 的节点删除后，树会被分割成若干个连通块。若某个连通块的大小为 $s$，则该连通块内的任意两个点之间的路径均不包含颜色 $c$，产生 $\binom{s}{2}$ 对不包含颜色 $c$ 的点对。
因此，颜色 $c$ 对总答案的贡献为：
$$\binom{n}{2} - \sum \binom{s_i}{2}$$

用一次 DFS 统计所有颜色对应的连通块大小：
- 维护 `sum[c]` 表示当前遍历状态下，颜色为 $c$ 的节点所管辖的子树大小之和。
- 访问节点 $u$ 时，对于其子节点 $v$，在递归前后通过 `sum[c[u]]` 的差值 $\Delta$，可以求出在 $v$ 的子树中所有极浅的颜色为 $c_u$ 的子树大小之和。因此，$v$ 所在的与 $u$ 相邻的不包含颜色 $c_u$ 的连通块大小为 $sz[v] - \Delta$。
- 回溯时，子树内部的颜色 $c_u$ 均被 $u$ 遮挡，将 `sum[c[u]]` 修正为进入 $u$ 前的值加上 $sz[u]$。
- DFS 结束后，对于每种出现过的颜色 $c$，$n - sum[c]$ 即为包含树根的不含颜色 $c$ 的连通块大小。

### C++ 代码

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

typedef long long ll;

const int N = 200005;
const int M = 400005;

int n, cnt;
int head[N], to[M], nxt[M];
int c[N], sz[N], sum[N];
bool vis[N];
ll ans;

void add(int u, int v) {
    to[++cnt] = v;
    nxt[cnt] = head[u];
    head[u] = cnt;
}

ll C(int x) {
    return 1LL * x * (x - 1) / 2;
}

void dfs(int u, int p) {
    sz[u] = 1;
    int cur = sum[c[u]];
    for (int i = head[u]; i; i = nxt[i]) {
        int v = to[i];
        if (v == p) continue;
        int pre = sum[c[u]];
        dfs(v, u);
        sz[u] += sz[v];
        int delta = sum[c[u]] - pre;
        int s = sz[v] - delta;
        ans -= C(s);
    }
    sum[c[u]] = cur + sz[u];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    if (!(cin >> n)) return 0;
    int col = 0;
    for (int i = 1; i <= n; ++i) {
        cin >> c[i];
        if (!vis[c[i]]) {
            vis[c[i]] = true;
            col++;
        }
    }
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        add(u, v);
        add(v, u);
    }
    ans = 1LL * col * C(n);
    dfs(1, 0);
    for (int i = 1; i <= n; ++i) {
        if (vis[i]) {
            int s = n - sum[i];
            ans -= C(s);
        }
    }
    cout << ans << "\n";
    return 0;
}
```

#### 两题的关系与差异
* **ABC 163 F (Path Passs)**：给出一棵树，对于每一种颜色 $k \in [1, N]$，**分别输出**有多少个点对（满足 $1 \le u \le v \le n$）的路径上包含了颜色 $k$。
* **本题（树上求和）**：求所有点对（$1 \le u < v \le n$）路径上**不同颜色的数量总和**。

根据交换求和次序：
$$\sum_{1 \le u < v \le n} \operatorname{distinct\_colors}(u, v) = \sum_{c} \big(\text{路径经过颜色 } c \text{ 的点对 } (u, v) \text{ 数量}\big)$$

因此，本题就是 **ABC 163 F** 所有颜色答案的总和（减去 $u=v$ 时的平凡情况），两者的核心思想完全一致（均为“正难则反”转化为扣除不含该颜色的连通块，一次 DFS 线性求解）。
