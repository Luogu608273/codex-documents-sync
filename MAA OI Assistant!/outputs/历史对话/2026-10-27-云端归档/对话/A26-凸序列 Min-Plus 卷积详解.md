## 原第 1 轮

### 用户

两个凸序列的minplus卷积是什么

### 历史助手

两个**凸序列**（Convex Sequences）的 **Min-Plus 卷积**（也称下凸卷积或最小值卷积）具有非常优美且高效的代数与几何性质。

简而言之：**两个凸序列的 Min-Plus 卷积结果依然是一个凸序列，且其差分序列等于原两个序列差分序列的归并排序（Sorted Merge）。**

---

### 1. 基本定义

* **Min-Plus 卷积定义**：
  给定两个序列 $a = (a_0, a_1, \dots, a_n)$ 和 $b = (b_0, b_1, \dots, b_m)$，它们的 Min-Plus 卷积 $c = a \star b$ 定义为：
  $$c_k = \min_{0 \le i \le k} (a_i + b_{k-i})$$

* **凸序列定义（下凸）**：
  若序列 $a$ 满足其一阶差分单调递增，即对任意 $i$，有：
  $$\Delta a_i = a_{i+1} - a_i \le a_{i+2} - a_{i+1} = \Delta a_{i+1}$$
  则称 $a$ 为凸序列。

---

### 2. 核心结论与性质

当 $a$ 和 $b$ 均为凸序列时，它们的 Min-Plus 卷积 $c$ 满足以下性质：

1. **封闭性（保持凸性）**：
   卷积结果 $c$ **也是一个凸序列**。
2. **差分合并（归并性质）**：
   序列 $c$ 的初始项为 $c_0 = a_0 + b_0$。
   序列 $c$ 的差分序列 $\Delta c$ 正好是 $\Delta a$ 和 $\Delta b$ 两个单调递增序列**升序合并（Merge）**后的结果。
3. **计算复杂度**：
   * 普通序列的 Min-Plus 卷积需要 $O(N^2)$ 的时间（若使用更复杂的矩阵乘法算法略有优化）。
   * **凸序列的 Min-Plus 卷积只需要 $O(N + M)$ 时间**，因为只需要用双指针线性归并两个已排序的差分数组。

---

### 3. 直观理解（贪心思想）

从几何/贪心的角度来看：
* 计算 $c_k$ 相当于在 $a$ 中走 $i$ 步，在 $b$ 中走 $j$ 步（使得 $i + j = k$），并使总花费 $a_i + b_j$ 最小。
* 每多走一步，产生的增量（边权/斜率）分别是 $\Delta a_i$ 和 $\Delta b_j$。
* 由于 $a$ 和 $b$ 是凸的，$\Delta a$ 和 $\Delta b$ 数组都是**单调递增**的。
* 要用最少的代价走 $k$ 步，最优策略显然是**贪心**：每次在 $\Delta a$ 和 $\Delta b$ 中选择当前**最小**的差分值走一步。
* 这正是归并排序（Merge）的过程。

---

### 4. 算法实现步骤

1. 计算序列 $a$ 的差分数组 $\Delta a = [a_1 - a_0, a_2 - a_1, \dots]$。
2. 计算序列 $b$ 的差分数组 $\Delta b = [b_1 - b_0, b_2 - b_1, \dots]$。
3. 使用双指针算法将 $\Delta a$ 和 $\Delta b$ 升序归并为新差分数组 $\Delta c$。
4. 设定初始值 $c_0 = a_0 + b_0$，利用 $\Delta c$ 前缀和依次还原出 $c_1, c_2, \dots$。

---

### 5. 具体示例

假设：
* 凸序列 $a = (0, 1, 3, 6)$ $\implies$ 差分数组 $\Delta a = (1, 2, 3)$
* 凸序列 $b = (0, 2, 5, 9)$ $\implies$ 差分数组 $\Delta b = (2, 3, 4)$

**合并步骤**：
1. 初始项 $c_0 = a_0 + b_0 = 0 + 0 = 0$。
2. 归并差分序列：$\Delta c = \text{Merge}((1, 2, 3), (2, 3, 4)) = (1, 2, 2, 3, 3, 4)$。
3. 前缀和还原 $c$：
   * $c_0 = 0$
   * $c_1 = 0 + 1 = 1$
   * $c_2 = 1 + 2 = 3$
   * $c_3 = 3 + 2 = 5$
   * $c_4 = 5 + 3 = 8$
   * $c_5 = 8 + 3 = 11$
   * $c_6 = 11 + 4 = 15$

（验证 $c_3$：按公式计算 $\min(a_0+b_3, a_1+b_2, a_2+b_1, a_3+b_0) = \min(0+9, 1+5, 3+2, 6+0) = \min(9, 6, 5, 6) = 5$，结果完全吻合。）

---

### 6. 应用场景

在算法竞赛（如 NOI/ICPC）和组合优化中，这种性质常被用于：
* **动态规划优化**：当 DP 状态转移方程呈现为 Min-Plus 卷积形式，且代价函数具有下凸性（或 Monge 阵/四边形不等式性质）时，可将转移复杂度从 $O(N^2)$ 降低到 $O(N)$。
* **凸包/闵可夫斯基和（Minkowski Sum）**：凸多边形的闵可夫斯基和在代数上等价于其边向量的极角排序合并，本质与凸序列 Min-Plus 卷积完全一致。

## 原第 2 轮

### 用户

为什么这个是决策单调性

### 历史助手

**两个凸序列的 Min-Plus 卷积之所以体现出“决策单调性”**，是因为对于输出位置 $k$ 的最优决策点（即取到最小值时的 $i$），随着 $k$ 的增加，**最优决策点 $i$ 是单调不减的**。

我们可以从 **“四边形不等式（Monge 阵）”** 的数学推导 和 **“归并差分”** 的直观逻辑两个角度来证明。

---

### 1. 数学视角：四边形不等式与 Monge 阵

在 Min-Plus 卷积中，我们要对每个 $k$ 求解：
$$c_k = \min_{0 \le i \le k} W(k, i)$$
其中代价函数为 $W(k, i) = a_i + b_{k-i}$（定义 $i > k$ 时为 $+\infty$）。

定义 $opt(k)$ 为使得 $W(k, i)$ 取得最小值的决策点 $i$：
$$opt(k) = \arg\min_i (a_i + b_{k-i})$$

**决策单调性** 的定义是：如果 $k_1 < k_2$，则必定有 $opt(k_1) \le opt(k_2)$。

#### 证明过程：
要证明 $opt(k)$ 满足决策单调性，只需证明代价矩阵 $W(k, i)$ 满足 **四边形不等式（Monge 性质）**，即对任意 $k_1 < k_2$ 和 $i_1 < i_2$，满足：
$$W(k_1, i_1) + W(k_2, i_2) \le W(k_1, i_2) + W(k_2, i_1)$$

将 $W(k, i) = a_i + b_{k-i}$ 代入上式左右两边：
* **左边** $= a_{i_1} + b_{k_1 - i_1} + a_{i_2} + b_{k_2 - i_2}$
* **右边** $= a_{i_2} + b_{k_1 - i_2} + a_{i_1} + b_{k_2 - i_1}$

两边同时消去 $a_{i_1} + a_{i_2}$，原式等价于要证明：
$$b_{k_1 - i_1} + b_{k_2 - i_2} \le b_{k_1 - i_2} + b_{k_2 - i_1}$$

移项改写为：
$$(b_{k_1 - i_1} - b_{k_1 - i_2}) \le (b_{k_2 - i_1} - b_{k_2 - i_2})$$

令区间长度 $L = i_2 - i_1 > 0$，令 $x = k_1 - i_2$， $y = k_2 - i_2$。
因为 $k_1 < k_2$，所以 $x < y$。上式变为：
$$(b_{x + L} - b_x) \le (b_{y + L} - b_y)$$

* 左边表示序列 $b$ 在区间 $[x, x + L]$ 上的**总增量**。
* 右边表示序列 $b$ 在区间 $[y, y + L]$ 上的**总增量**。

**因为序列 $b$ 是凸序列**，它的差分 $\Delta b$ 是单调递增的（越往后走，增长越快/斜率越大）。由于区间 $[y, y+L]$ 整体位于 $[x, x+L]$ 的右侧（即 $x < y$），右侧区间的总增量必然大于等于左侧区间的总增量。

由此证明了 **$W(k, i)$ 满足四边形不等式**，因此必然存在**决策单调性**：
$$opt(k_1) \le opt(k_2)$$

---

### 2. 直观视角：从归并差分看决策点的移动

上一回答中提到了双指针归并差分算法，这里能更直观地看到决策单调性：

* 设 $c_k = a_i + b_j$（其中 $i + j = k$），那么决策点 $opt(k) = i$ 就是**在组合中选用了 $a$ 序列前 $i$ 项差分的数量**。
* 当我们要从 $c_k$ 计算 $c_{k+1}$ 时，相当于要在已选的 $k$ 个增量（$i$ 个来自 $\Delta a$，$j$ 个来自 $\Delta b$）的基础上，**再多选 1 个代价最小的增量**。
* 此时只有两种选择：
  1. 选下一个 $\Delta a$：此时 $i \to i + 1$，$opt(k+1) = opt(k) + 1$。
  2. 选下一个 $\Delta b$：此时 $i$ 不变，$opt(k+1) = opt(k)$。

因此，随着 $k \to k+1$，最优决策点 $opt(k)$ **要么保持不变，要么增加 1**（即 $0 \le opt(k+1) - opt(k) \le 1$）。

这说明：凸序列的 Min-Plus 卷积不仅满足一般的决策单调性（$opt(k) \le opt(k+1)$），而且满足**极强的连续决策单调性**（每次决策点最多移动 1 步）。

---

### 总结关系链

$$\text{序列 } b \text{ 下凸}$$ 
$$\Downarrow$$
$$\text{代价矩阵 } W(k, i) \text{ 满足四边形不等式 (Monge 性质)}$$
$$\Downarrow$$
$$\text{DP 具有决策单调性 } (opt(k) \le opt(k+1))$$
$$\Downarrow (\text{若 } a \text{ 也下凸})$$
$$opt(k+1) \in \{opt(k), opt(k)+1\} \implies \text{可用双指针 } O(N) \text{ 线性解决}$$
