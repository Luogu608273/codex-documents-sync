# P17725 大雨 / rain：分段、分层 DP 与时间戳字典树

[题目链接](https://www.luogu.com.cn/problem/P17725)。本文给出完整解法，时间复杂度为 $O(nB)$，空间复杂度为 $O(nB)$，其中 $B=30$。

## 1. 题意与约束

给定非负整数序列 $a_1,\ldots,a_n$。每次选择 $1\le p\le n$ 和正整数 $x$，令前缀 $a_1,\ldots,a_p$ 中的每个数都异或 $x$。求使整个序列单调不降的最少操作次数。

多组数据，单组 $n\le 10^6$，总长度不超过 $5\times10^6$，$0\le a_i<2^{30}$。时间限制为 2 秒，空间限制为 512 MiB。操作中的 $x$ 没有被限制为小于 $2^{30}$，后面的构造会用到这一点。

## 2. 前缀操作等价于选择每个位置的最终异或掩码

设位置 $i$ 最终累计异或的值为 $b_i$，变换后的值为

$$c_i=a_i\oplus b_i.$$

再令 $b_{n+1}=0$。所有右端点为 $p$ 的操作可以合并成一次，其异或值恰好为

$$x_p=b_p\oplus b_{p+1}.$$

反过来，在每个 $x_p\ne0$ 的位置做一次前缀操作，位置 $i$ 累计异或的值为

$$\bigoplus_{p=i}^n x_p=\bigoplus_{p=i}^n(b_p\oplus b_{p+1})=b_i.$$

所以，对于给定的 $b$，最少操作次数严格等于

$$\boxed{\sum_{i=1}^n[b_i\ne b_{i+1}]},\qquad b_{n+1}=0.$$

特别地，把 $b$ 按相同值分成 $m$ 个极大连续段，代价就是

$$m-1+[b_n\ne0].$$

因此需要研究：哪些连续段可以整体异或同一个值后单调不降？

## 3. 一段是否合法，只取决于若干个二进制位约束

考虑相邻的两个不同的数 $u,v$，令

$$k=\operatorname{msb}(u\oplus v).$$

也就是 $u,v$ 最高的不同位。整体异或 $x$ 后，更高位仍然相同，第 $k$ 位仍然不同，大小关系完全由这一位决定。

要使 $u\oplus x<v\oplus x$，左边这一位必须是 $0$，右边必须是 $1$。所以必要且充分条件为

$$\boxed{x_k=u_k}.$$

若 $u=v$，二者始终相等，不产生约束。

于是，一个连续段可以整体异或后不降，当且仅当它内部的所有相邻对，对各位提出的要求没有冲突：同一个位不能同时要求为 $0$ 和 $1$。只要没有冲突，把要求的位固定，其余位任意取值即可。

例如 $[4,5,0]$：

- $4\to5$ 的最高不同位为第 $0$ 位，要求 $x_0=0$；
- $5\to0$ 的最高不同位为第 $2$ 位，要求 $x_2=1$。

可以取 $x=4$，变成 $[0,1,4]$。但接上 $7$ 后，$0\to7$ 又要求 $x_2=0$，出现冲突，所以 $[4,5,0,7]$ 不合法。

## 4. 先求最少合法分段数 $g_i$

定义 $g_i$ 为：把 $a_1,\ldots,a_i$ 划分成若干连续段，使每段都能各自整体异或后不降，所需的最少段数。这里只要求每段内部合法，暂时不要求段与段之间有序。

求它可以贪心：从左到右尽可能延长当前段，维护已经固定的位及其值。遇到冲突时，在当前元素之前切一刀，新段从当前元素开始。

注意：导致冲突的相邻对跨越了切口，不能再把它的约束放入新段。

贪心正确的原因是合法性对取子段封闭。设当前剩余序列的最长合法前缀到 $r$，任意合法划分的第一段终点一定不超过 $r$。把它的第一刀向右推到 $r$：被完全覆盖的段删掉，被部分覆盖的段只留下后缀；后缀仍然合法，段数不会增多。因此一定存在以该最长前缀为第一段的最优划分，之后递归处理即可。

因此 $g_i$ 可以在线求出，每次只会不变或加一。

## 5. 原题答案只可能是 $g_n-1$ 或 $g_n$

记 $G=g_n$。

**下界。** 任意可行方案的掩码序列有 $m$ 个极大连续段，每段内部必然合法，故 $m\ge G$。由代价公式，操作次数至少为 $m-1\ge G-1$。

**上界。** 取任意一个有 $G$ 段的内部合法划分。对第 $j$ 段，先选一个只使用低 $30$ 位的合法掩码 $z_j$，再使用

$$b^{(j)}=z_j\oplus((j-1)\cdot2^{30}).$$

该段所有变换后的值都落在

$$[(j-1)2^{30},\ j2^{30}-1]$$

中，故段间也严格有序。掩码只有 $G$ 段，对应操作次数至多 $G$。

结合上下界：

$$\boxed{\operatorname{ans}\in\{G-1,G\}}.$$

而且，取到 $G-1$ 的充要条件是：存在一个有 $G$ 段的全局不降方案，最后一段的掩码为 $0$。

因为有 $G$ 段时，段间已经需要 $G-1$ 次操作；只有最后掩码为 $0$，才能省掉右端点为 $n$ 的那次操作。

## 6. 判断能否省一次：先把值域限制到 $[0,2^{30})$

令 $U=2^{30}$。如果最后一段掩码为 $0$，那么

$$c_n=a_n<U.$$

由于整个序列不降，所有 $c_i$ 都小于 $U$，于是所有 $b_i=a_i\oplus c_i$ 也都小于 $U$。

因此，判断答案是否为 $G-1$ 时，只考虑低 $30$ 位的掩码就足够了。更大的值仍然允许出现在前面的上界构造里，但不会出现在需要判断的省操作方案中。

## 7. DP 状态：最优分段前缀的最小结尾

定义 $S_i$ 为所有满足以下条件的最后一段掩码 $x$ 的集合：

1. 前 $i$ 个元素恰好划成 $g_i$ 段，每段使用一个固定掩码；
2. 变换后的整个前缀单调不降；
3. 所有变换后的值都小于 $U$。

再定义

$$D_i=\min_{x\in S_i}(a_i\oplus x).$$

若集合为空，记 $D_i=U$，表示在这个受限值域内不存在方案。

为什么只记最小结尾就能连接新段？假设在 $i$ 处开启新段，使用掩码 $x$。它的第一个值是 $a_i\oplus x$。前面某个方案能接上它，当且仅当

$$\boxed{a_i\oplus x\ge D_{i-1}}.$$

前一段如何划分、使用什么掩码，都不再影响这条边界；只需选结尾最小的前缀方案。

但延长已有段时，仍然必须保存整个掩码集合，不能只保留实现最小结尾的一个掩码。因为相邻元素变化后，原来不是最优的掩码可能变成最优。

## 8. 为什么只维护相邻两层

先证明一个关键性质：考虑前 $i$ 个元素任意一个有 $g_i$ 段的合法划分，设最后一段之前的前缀为 $[1,j]$。那么

$$\boxed{g_j=g_i-1}.$$

这个划分已经说明 $g_j\le g_i-1$。若 $g_j\le g_i-2$，把前 $j$ 个元素换成内部合法的最优划分，再接上原来的最后一段，就得到不超过 $g_i-1$ 段的内部合法划分，与 $g_i$ 的定义矛盾。这里使用的是内部合法分段数，不要求替换后段间有序，所以该证明不依赖 DP 结尾值。

这说明，一个最终要成为最优分段方案的最后一段，只需要从“前缀最优段数恰好少一”的位置开始。

当前 $g_i=h$ 时，维护两个集合：

- `s`：当前第 $h$ 层的候选，即 $S_i$；
- `q`：未来第 $h+1$ 层的候选。它们均由某个最优段数为 $h$ 的前缀，再接一个新段产生，并且已保证到当前位置全局有序。

`q` 不声称包含当前所有使用 $h+1$ 段的方案，只保存将来可能成为最优方案的那些候选。

更高层的有用候选还没有出现：第 $h+2$ 层的最后一段，需要从最优段数为 $h+1$ 的前缀后开始，而此前所有前缀的最优段数都不超过 $h$。

每读入一个新数 $a_i$，按下面顺序处理：

1. **延长旧段。** 若 $a_{i-1}\ne a_i$，求最高不同位 $k$，在 `s`、`q` 中都只保留 $x_k=(a_{i-1})_k$ 的掩码。
2. **处理升层。** 若 $g_i=g_{i-1}+1$，旧 `s` 已经不可能有效，把 `q` 变成新的 `s`，重新清空 `q`。
3. **开启新段。** 从前缀 $i-1$ 的最优方案转移，加入所有 $x$ 满足 $a_i\oplus x\ge D_{i-1}$。这类方案有 $g_{i-1}+1$ 段：若本次升层，加入 `s`；否则加入 `q`。若 $D_{i-1}=U$，不加入。
4. 查询 `s` 中 $a_i\oplus x$ 的最小值，得到 $D_i$。

初始化时 $g_1=1$，单点可以变成任意 $[0,U)$ 中的值，所以 `s` 为所有掩码，`q` 为空，$D_1=0$。

处理完全部元素后，只需判断

$$\boxed{0\in S_n}.$$

若成立，最后一段可以不异或，答案为 $g_n-1$；否则答案为 $g_n$。

## 9. 时间戳字典树：需要支持什么

上述 DP 对掩码集合只需要三种操作：

1. 仅保留第 $k$ 位为 $v$ 的掩码；
2. 加入所有 $x$ 满足 $x\oplus a\ge d$；
3. 查询 $\min(x\oplus a)$。

直接在普通字典树上执行第一种操作，可能要访问同一层的大量结点，不能未经分析就认为是 $O(B)$。

下面给出一种可以证明总复杂度为 $O(nB)$ 的实现：每次筛选只记录发生时间，查询或插入时才检查旧状态是否已经失效。

### 9.1 筛选历史

两棵树分别维护

$$f[k][v]=\text{最近一次要求第 }k\text{ 位为 }v\text{ 的时间}.$$

处理位置 $i$ 时，先筛选旧候选，之后加入新候选；二者都使用时间 $i$。这样，新插入状态不需要满足发生在它之前、针对旧段的筛选。

若一个掩码最后在时间 $t$ 被加入，那么它在第 $k$ 位上取 $v$ 时，只有

$$t\ge f[k][v\oplus1]$$

才能存活。判断失效时使用严格小于，时间相等表示先筛选、后重新插入，允许存活。

### 9.2 用负数句柄表示整棵满子树

树按第 $29$ 位到第 $0$ 位保存掩码。句柄含义如下：

- $0$：空集；
- $-t$：当前固定前缀下，所有低位组合都曾在时间 $t$ 加入，之后再接受筛选；
- 正数：实际分配的分叉结点编号，保存两个孩子，以及子树插入时间的一个上界。

因此，“所有低位组合”不需要展开成指数多个叶子。初始全集直接使用句柄 $-1$。

只在插入操作需要部分覆盖一个负数句柄时，才新建一个实际结点，两个孩子继承原来的负数句柄。负数句柄没有实际子结点，也不占结点池空间。

### 9.3 怎样快速判断失效

进入一棵子树时，设剩余位为 $k,\ldots,0$。

已经确定的高位都可能受到后来的反向筛选。沿路径维护

$$\mathrm{lim}=\max(\text{所有与该路径高位取值相反的筛选时间}).$$

如果某批状态的插入时间 $t<\mathrm{lim}$，它们全部失效。

再看还没确定的低位。如果某一位在 $t$ 之后先后被要求为 $0$ 和 $1$，那么这批状态也全部失效。维护

$$\mathrm{bad}[k]=\max_{0\le j\le k}\min(f[j][0],f[j][1]).$$

若 $t<\mathrm{bad}[k]$，就存在这样的冲突位。

于是，一个满子树句柄 $-t$ 存活的充要条件是

$$t\ge\max(\mathrm{lim},\mathrm{bad}[k]).$$

实际结点保存的时间是子树插入时间的上界。如果连这个上界都小于上述门槛，就可以直接删除整棵子树；否则暂时保留，进入孩子时继续检查。查询删除孩子后，这个上界不必下调，偏大的上界只影响提前删除的机会，不影响正确性。

每次新增一条筛选记录，线性重算 $30$ 个 `bad` 值，复杂度是 $O(B)$。

### 9.4 加入 $x\oplus a\ge d$

令 $y=x\oplus a$，从高到低比较 $y$ 与 $d$。

- 若 $d$ 当前位为 $0$，选择 $y$ 当前位为 $1$ 的整棵子树都满足条件，可以直接赋为当前时间的负数句柄；选择 $0$ 的分支继续比较低位。
- 若 $d$ 当前位为 $1$，只能在 $y$ 当前位也为 $1$ 的分支继续比较。

由于 $x_k=y_k\oplus a_k$，可以直接确定对应的掩码分支。

每层至多递归进入一个孩子，另一个孩子整体覆盖，所以一次插入只走 $B$ 层，最多新建 $B$ 个实际结点。

### 9.5 查询最小异或值

普通实际结点优先走 $x_k=a_k$ 的分支，使当前异或位为 $0$。若这一分支确实为空，再走另一边。

进入负数句柄 $-t$ 时，不必展开：逐位查看筛选历史即可。

- 若 $f[j][0]>t$，该位被固定为 $0$；
- 否则若 $f[j][1]>t$，该位被固定为 $1$；
- 否则该位自由，取 $x_j=a_j$，使异或结果为 $0$。

如果两个方向都在 $t$ 后出现过，前面的 `bad` 检查已经将这棵满子树判空。因此这些逐位选择相互独立，并且能同时满足。

查询中发现一棵实际子树已经完全无解，就把它的句柄清成 $0$。一次查询可能清理许多旧结点，不能说每次查询严格最坏 $O(B)$；但每个被清理的结点之后都不可达，只能被清理一次。所有清理访问总计不超过创建结点数。

每次成功查询的有效路径、满子树上的逐位计算共 $O(B)$；额外的失败分支访问摊还到被删除结点上。因此所有查询的总复杂度为 $O(nB)$。

最后用 $a=0$ 查询最小掩码，其结果为 $0$ 当且仅当集合包含 $0$。

## 10. 正确性证明汇总

**引理一。** 一个区间能整体异或后不降，当且仅当所有相邻不同元素在最高不同位上提出的掩码要求没有冲突。证明见第 3 节，且相邻均不降等价于整个区间不降。

**引理二。** 最长合法前缀贪心得到最少内部合法分段数 $g_i$。证明见第 4 节的切口右移交换论证。

**引理三。** 任意操作方案代价为掩码相邻变化次数加最后掩码非零的贡献，故最优答案为 $g_n-1$ 或 $g_n$；取到前者，当且仅当存在有 $g_n$ 段且末段掩码为 $0$ 的全局有序方案。证明见第 2、5 节。

**引理四。** 在判断省操作方案时，限制所有掩码、结果小于 $U$ 不会漏解。因为末项保持为 $a_n<U$，所有前项又都不大于末项。

**引理五。** `s` 精确维护集合 $S_i$。对 $i$ 归纳：初始单点全集正确。任意最优分段方案的最后一段，要么从当前元素开始，对应加入 $a_i\oplus x\ge D_{i-1}$；要么从更早位置开始，对应旧候选延长，并接受最高不同位约束。最后一段之前的前缀最优段数必须少一，故两层维护不会漏掉可成为最优方案的起点。每种加入与保留又都对应合法方案，所以也不会加入错误状态。

**引理六。** 时间戳字典树准确实现上述集合操作。每个掩码只需检查最后插入之后是否出现反向筛选；路径门槛、低位冲突检查及满子树逐位查询恰好落实此条件。区间插入按二进制大小比较完整覆盖且仅覆盖 $x\oplus a\ge d$。

由以上引理，最终检查 $0\in S_n$，成立输出 $g_n-1$，否则输出 $g_n$，得到原题最优答案。

## 11. 复杂度与实现边界

每个元素最多向一棵树加入一次状态，每次加入最多创建 $B$ 个实际结点。负数句柄不占结点空间，两棵树共享结点池，每组数据重新从头使用结点池。

因此：

$$\boxed{\text{时间 }O(nB),\quad\text{空间 }O(nB),\quad B=30.}$$

结点只有三个 `int`，最大结点池为 $30\times10^6+5$ 个，约 343.3 MiB，加上读入缓冲等仍低于 512 MiB。代码不保存原序列。多组数据的时间复杂度为 $O(NB)$，空间取单组最大 $n$。

具体注意：

- 相邻相等时不调用最高位函数，也不产生筛选；
- 贪心切段后，跨段的那条约束不能计入新段；
- 同一位置先筛选再插入，因此判过期用 `<`；
- $U$ 是“无方案”的哨兵，实际合法值都小于它；
- 升层时不仅交换根，还要交换两棵树的全部筛选历史；被清空的下一层必须重新初始化历史。

## 12. 样例中的两种答案

对于 $[4,5,0,7,3]$，最少内部合法段数为 $2$，例如 $[4,5,0]\mid[7,3]$。

若只用一次操作，末段必须保持不变。由于末尾 $7>3$，不变后缀只能是最后的单点 $[3]$；但前缀 $[4,5,0,7]$ 不能整体异或后不降。因此不能省一次，答案为 $2$。

对于 $[7,4,6,0,4]$，最少内部合法段数为 $3$，可以划为

$$[7,4]\mid[6,0]\mid[4].$$

三个掩码分别取 $6,4,0$，结果是 $[1,2,2,4,4]$。最后掩码为 $0$，所以只需 $3-1=2$ 次操作。

## 14. C++17 实现

以下代码直接使用标准输入输出，第一行先读取并忽略测试点编号 $c$。

```cpp
#include <bits/stdc++.h>
#define endl '\n'
using namespace std;
using ll = long long;

const int B = 30, V = 1 << B, N = 30000005;
struct Node {
    int ch[2], t;
} tr[N];
int tot;

int read() {
    static char buf[1 << 20];
    static int p, len;
    int x = 0;
    char c;
    do {
        if (p == len) len = fread(buf, 1, sizeof(buf), stdin), p = 0;
        c = buf[p++];
    } while (c < '0' || c > '9');
    do {
        x = x * 10 + c - '0';
        if (p == len) {
            len = fread(buf, 1, sizeof(buf), stdin), p = 0;
            if (!len) break;
        }
        c = buf[p++];
    } while (c >= '0' && c <= '9');
    return x;
}

struct Trie {
    int rt, f[B][2], bad[B];
    void init() {
        rt = 0;
        memset(f, 0, sizeof(f));
        memset(bad, 0, sizeof(bad));
    }
    void modify(int k, int v, int t) {
        f[k][v] = t;
        for (int j = 0; j < B; ++j)
            bad[j] = max(j ? bad[j - 1] : 0, min(f[j][0], f[j][1]));
    }
    void clear(int &u, int k, int lim) {
        if (!u) return;
        int t = u < 0 ? -u : tr[u].t;
        if (t < lim || (k >= 0 && t < bad[k])) u = 0;
    }
    void add(int &u, int k, int lim, int a, int d, int t) {
        clear(u, k, lim);
        if (k < 0) {
            u = -t;
            return;
        }
        if (u <= 0) {
            int v = ++tot;
            tr[v].ch[0] = tr[v].ch[1] = u;
            u = v;
        }
        tr[u].t = t;
        int v = (a >> k) & 1;
        if (!((d >> k) & 1)) {
            tr[u].ch[v ^ 1] = -t;
            add(tr[u].ch[v], k - 1, max(lim, f[k][v ^ 1]), a, d, t);
        } else {
            v ^= 1;
            add(tr[u].ch[v], k - 1, max(lim, f[k][v ^ 1]), a, d, t);
        }
    }
    int query(int &u, int k, int lim, int a) {
        clear(u, k, lim);
        if (!u) return V;
        if (u < 0) {
            int t = -u, res = 0;
            for (int j = k; j >= 0; --j) {
                if (f[j][0] > t) res |= a & (1 << j);
                else if (f[j][1] > t) res |= (a ^ (V - 1)) & (1 << j);
            }
            return res;
        }
        int v = (a >> k) & 1;
        int res = query(tr[u].ch[v], k - 1, max(lim, f[k][v ^ 1]), a);
        if (res != V) return res;
        v ^= 1;
        res = query(tr[u].ch[v], k - 1, max(lim, f[k][v ^ 1]), a);
        if (res != V) return res | (1 << k);
        u = 0;
        return V;
    }
} s, q;

void solve() {
    int n = read(), a = read(), g = 1, d = 0;
    int mask = 0, val = 0;
    tot = 0;
    s.init();
    q.init();
    s.rt = -1;
    for (int i = 2; i <= n; ++i) {
        int b = read(), z = a ^ b;
        bool inc = false;
        if (z) {
            int k = 31 - __builtin_clz((unsigned) z);
            int v = (a >> k) & 1, bit = 1 << k;
            if ((mask & bit) && (((val >> k) & 1) != v)) {
                ++g;
                mask = val = 0;
                inc = true;
            } else {
                mask |= bit;
                if (v) val |= bit;
            }
            s.modify(k, v, i);
            q.modify(k, v, i);
        }
        if (inc) {
            swap(s, q);
            q.init();
        }
        if (d < V) {
            if (inc) s.add(s.rt, B - 1, 0, b, d, i);
            else q.add(q.rt, B - 1, 0, b, d, i);
        }
        d = s.query(s.rt, B - 1, 0, b);
        a = b;
    }
    printf("%d\n", g - (s.query(s.rt, B - 1, 0, 0) == 0));
}

int main() {
    int c = read(), _ = read();
    (void) c;
    while (_--) solve();
    return 0;
}
```
