# 消噪（noise）

## 题意

给定 N 个非零整数 a1,...,aN，统计连续区间 [l,r] 的个数，使其长度为 2m，且对每个 0<=j<m 都有：

    a[l+j] = -a[l+m+j]。

T<=3，每组 N<=500000，1<=|ai|<=N。文件输入输出：`noise.in`、`noise.out`。

注意是前后两半按相同方向对应，不是回文。答案用 `long long`。

## 1. 枚举半长，在等距锚点处合并计数

固定半长 m，定义某个比较位置 j 匹配，当且仅当 a[j]=-a[j+m]。一个消噪区间对应这些比较位置中长度至少为 m 的连续匹配段内的一段长度 m 的窗口。

直接检查每个 j 是 O(N^2) 的部分分做法。满分算法只检查锚点：

    i = 1, 1+m, 1+2m, ...，并满足 i+m<=N。

每个候选区间的前半段 [l,l+m-1] 恰好包含一个锚点 i。于是可以按这个锚点分配区间，保证不重不漏。

在锚点 i 计算：

- R：从 i、i+m 向右，有多少对连续元素互为相反数；只保留最多 m 对。
- L：从 i-1、i+m-1 向左，有多少对连续元素互为相反数；只保留最多 m-1 对。

限制 L<=m-1 是为了确保统计的前半段只分配给当前锚点。若锚点本身不匹配，即 R=0，贡献一定为 0。

包含锚点、长度为 m 的匹配窗口起点 l 必须满足：

    i-L <= l <= i+R-m。

因此该锚点的贡献为：

    max(0, L+R-m+1)。

R<=m 保证 l<=i，L<=m-1 保证 l>=i-m+1；实际左右最长匹配长度又保证整个原区间不越界。

所有 m 对应的锚点数之和为

    sum_{m=1}^{floor(N/2)} floor((N-1)/m) = O(N log N)。

接下来只需 O(1) 精确求一次最长相反数匹配。

## 2. 将“互为相反数”变成普通后缀 LCP

直接把 a 与 -a 拼接也能做后缀数组，但还要支持向左比较，规模会更大。这里利用所有 ai 非零，将长度压到原数组级别。

定义 sgn(x) 为 x 的正负号，并令

    b[i] = sgn(a[i]) * a[i+1]，1<=i<N；
    b[N] = 0。

b 是相邻元素的相对符号和后一个元素的绝对值编码。整体取反不会改变 b。

设 p<q。若 a[p] != -a[q]，最长相反数匹配长度显然为 0。否则第一对已经匹配，且 sgn(a[p])=-sgn(a[q])。此时：

    b[p]=b[q]  <=>  a[p+1]=-a[q+1]。

只要下一对也匹配，就能对其后位置重复同样的推理。因此，普通 b 后缀的最长公共前缀长度记为 LCP_b(p,q)，便有：

    Right(p,q) = min(N-q+1, 1+LCP_b(p,q))。

外面的上界保证不超过原序列剩余长度。b[N]=0 是非零编码之外的终止标记，绝不会与正常 b[i] 混淆。

反转原序列，使用同样定义建立第二套后缀结构。对原数组 p<q 的向左比较，若 p=0 或 a[p]!=-a[q]，返回 0；否则：

    Left(p,q) = min(p, 1+LCP_rev(N-p+1,N-q+1))。

特别注意：第二套结构来自“反转后的原数组再编码”，不是简单反转第一套 b。两者的相邻元素编码方向不同。

## 3. 后缀数组与 RMQ

两套结构各自按如下方式建立：

1. 倍增法建立后缀数组 SA，使用计数排序，每轮 O(N)，共 O(log N) 轮。
2. Kasai 算法得到相邻后缀的最长公共前缀 height，O(N)。
3. 对 height 建最小值稀疏表，O(N log N) 时间与空间。

设两个后缀的排名为 u<v，则它们的 LCP 等于 height[u+1..v] 的最小值，用稀疏表 O(1) 查询。查询前先比较首元素能否互为相反数，不满足时不需要访问 RMQ。

SA、计数桶、倍增临时数组在两次建立之间复用；两套排名和 RMQ 保留。代码没有使用随机哈希，比较结果是确定性的。

## 4. 正确性证明

**引理一：最长匹配查询正确。** 首元素不互为相反数时答案为 0；首元素匹配时，b 中每多匹配一个编码，就由第二节等价关系推出原数组下一对匹配，反向也成立。对匹配长度归纳并截断数组边界，即得到正确的 Right。反转后同理得到 Left。

**引理二：一个锚点的贡献正确。** 从 i 向两侧扩展得到连续匹配区间 [i-L,i+R-1]。其内部长度为 m 且包含 i 的窗口，恰好对应 i-L<=l<=i+R-m，因此数量就是给出的公式。每个窗口都对应一段合法的长度 2m 的原区间。

**引理三：不同锚点不重复。** 相邻锚点相距 m，任何长度 m 的前半段恰好包含一个锚点。L 的 m-1 上限及 R 的 m 上限使当前锚点仅统计包含它的这些窗口。

所有偶数长度区间都有唯一半长 m。算法枚举全部 m，再按唯一锚点精确计数，由三个引理得知结果不重不漏。

## 复杂度与边界

每组预处理 O(N log N)，全部锚点查询 O(N log N)，总时间 O(N log N)，空间 O(N log N)。T 组分别求和。代码静态数组合计约 91.6 MiB，满足 256 MB 限制。

- N=1 时没有合法区间，答案为 0。
- ai 不能是 0，这是相邻编码推理成立的必要前提，题目已保证。
- 半长 m 不限于偶数或奇数，都要枚举。
- 例如 N=2M 的交替序列 `1,-1,1,-1,...`，恰好半长为奇数时匹配。令 k=ceil(M/2)，答案是 k(N+1)-2k^2，可用来检查大答案和高度重复数据。
- height 建立时，排名为 1 的后缀必须把复用长度清零；多组数据需要按当前 N 重建。

## 部分分程序

`partial.cpp` 支持 N<=2000，对应测试点 1~8，共 40%。枚举 m，对 j=1,...,N-m 顺序扫描，维护连续满足 a[j]=-a[j+m] 的长度 cnt。若 cnt>=m，恰好新增一个以当前比较位置结尾的长度 m 的匹配窗口，答案加一。

每个窗口都有唯一末尾，所以扫描计数正确。时间 O(N^2)，空间 O(N)。超出支持范围返回非零退出码。40% 是题面子任务覆盖范围，不是正式得分。
