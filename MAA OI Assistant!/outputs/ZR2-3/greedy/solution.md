# 贪心（greedy）

## 题意

有 N 件商品，每件价格为 Ci，Alice、Bob 购买它分别获得 Ui、Vi。两人的初始余额为 A、B。选择一个所有商品的公共排列，两人独立扫描；遇到买得起的商品就必须买一件。最大化两人的满意度总和。

N、A、B、Ci <= 150，1 <= Ui、Vi <= 10^9。文件输入输出：`greedy.in`、`greedy.out`。

## 1. 可以只考虑怎样的排列

固定某个实际可行排列及其购买结果，将商品分为：两人都买、仅 Alice 买、仅 Bob 买、两人都不买。

**先把两人都买的商品移到开头。** 对任意一位顾客，其全部计划购买商品的总价格不超过预算。因此，提前支付某件原本也要购买的商品，不会使其余计划购买的商品变得无法购买。原本跳过的商品在被查看时，余额只可能更少，仍会跳过。

**再把两人都不买的商品移到末尾。** 这类商品原本被两人跳过，价格大于当时的余额，也就大于最终余额，移动之后仍然跳过。

剩下只被一人购买的商品可以按价格从大到小排列。证明考虑相邻两件商品，前一件价格 c、后一件价格 d，且 c<d：

- 如果由同一人购买，交换它们不改变购买结果：购买者买得起两件的总价，另一人在这两件之间不花钱，且两件都买不起。
- 如果由不同的人购买，这种逆序根本不可能出现。后一件的购买者跳过了前一件，说明其余额小于 c；其余额不会增加，却又要买价格 d>c 的后一件，矛盾。

不断交换同一购买者的逆序对，就得到价格降序。于是存在最优排列形如：

1. 两人都购买的商品。
2. 仅一人购买的商品，按价格降序。
3. 剩余商品。

第一段内部的顺序任意。

## 2. 预留共同消费金额

设第一段价格总和为 L，先预留它，两人在第二段的初始可用余额就是 A-L、B-L。

将全部商品按价格降序处理，逐个决定归入哪一类。对于尚未处理、以后要归入第一段的商品，还需要分配总价格 r。状态为：

> f[r][x][y]：已经处理若干商品，尚未分配的共同消费预留金额为 r，第二段扫描过程中的两人余额分别为 x、y 时，可获得的最大满意度。

共同消费已经从初始预算中一次性扣除，所以在处理“两人都买”的商品时，只减少 r，不能再次减少 x、y。

L 不出现在任何转移条件里，可以把所有可能的初态合并到同一张表：

    f[L][A-L][B-L] = 0，0 <= L <= min(A,B)。

其他状态初始化为负无穷。

## 3. 转移

处理价格 c、满意度 u、v 的商品，设当前状态值为 z：

| 分配类别 | 条件 | 新状态 | 增加满意度 |
|---|---|---|---|
| 暂不计入 | 无 | (r,x,y) | 0 |
| 两人都买 | r >= c | (r-c,x,y) | u+v |
| 仅 Alice 买 | x >= c 且 y < c | (r,x-c,y) | u |
| 仅 Bob 买 | y >= c 且 x < c | (r,x,y-c) | v |

最后只能接受 r=0 的状态，否则还有一部分共同消费没有落实到真实商品上。答案是所有 f[0][x][y] 的最大值。

### 为什么允许无条件“暂不计入”

DP 不要求这些商品最后一定被两人跳过。把所有计入“两人都买”的商品放在开头，计入“仅一人买”的商品降序放在之后，暂不计入的商品全部放到末尾。

前两段严格按照状态条件执行，至少获得 DP 记录的满意度。末尾即使又有商品被购买，因为 Ui、Vi 都为正，也只会增加得分，不影响之前的购买。

因此任意 r=0 的 DP 结果都不超过某个真实排列的得分，不会把答案算大。另一方面，第一节给出的最优排列会被 DP 完整枚举，所以不会算小。这两方面共同证明答案恰好等于最优值。

## 4. 原地更新和复杂度

任何有效转移都使 (r,x,y) 的字典序严格减小。按 r、x、y 全部递增扫描，写入的位置已在本轮被扫描过，因此同一商品不会重复使用，可以原地更新。

可达状态满足 r+x<=A、r+y<=B，只扫描这个范围。令 M=min(A,B)，时间为

    O(N * sum_{r=0}^M (A-r+1)(B-r+1))，

上界是 O(N(M+1)(A+1)(B+1))。A=B=150 时每件商品扫描 1159076 个状态，150 件约 1.74 亿个状态。

代码使用固定三维数组，空间 O((M+1)(A+1)(B+1)) 的量级，实际数组约 28.5 MiB。满意度总和最多 3*10^11，状态和答案必须使用 `long long`。

## 部分分程序

`partial.cpp` 支持以下两类输入：

- N<=8：枚举全部排列，并逐件模拟两人的强制购买。递归枚举共享排列前缀；节点数为 sum_{k=0}^N N!/(N-k)!，每个非叶节点还要扫描 N 个商品标记，总时间 O(N*N!)，空间 O(N)。
- A=B：两人始终拥有相同余额，所以每件商品要么都买，要么都不买。把价值设为 Ui+Vi，做容量 A 的 0/1 背包，时间 O(NA)，空间 O(A)。任意可行购买集合可放在排列开头；若末尾又买了商品，它仍构成背包可行集合，不会超过背包最优值，故背包答案等于原问题答案。

按题面测试点编号，覆盖 1~4 和 11~13，共 35%。这只是支持范围，不是正式得分。超出两类范围时程序返回非零退出码。
