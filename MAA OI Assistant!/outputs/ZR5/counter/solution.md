# 计数器（counter）

## 文件与范围

- `std.cpp`：完整算法，处理全部数据。
- `partial.cpp`：枚举量程，覆盖子任务 1、2、3，共 78 分。
- 默认读写 `counter.in`、`counter.out`；定义 `LOCAL` 后改为标准输入输出。使用 C++17。

原题：`n ≤ 2×10^5`，`B ≤ 10^12`，`0 ≤ t_i,v_i ≤ 10^12`，时刻严格递增。

## 1. 可行量程的充要条件

设时刻 0 的读数为 `c`。量程为 `K` 时，应有

\[
v_i\equiv c+t_i\pmod K,\qquad 0\le v_i<K.
\]

令 `m = max v_i`。读数合法当且仅当 `K > m`。

用第 1 条记录消去 `c`，得到

\[
K\mid (t_i-v_i)-(t_1-v_1)\quad (2\le i\le n).
\]

这是必要条件，也是充分条件：取 `c` 为 `v_1-t_1` 模 `K` 的非负剩余，即可同时满足全部记录。

因此，令

\[
g=\gcd_{i=2}^n\left|(t_i-v_i)-(t_1-v_1)\right|,
\]

问题就是统计满足 `m < K ≤ B` 且 `K | g` 的正整数。

## 2. 标准解

边读入边计算 `m` 和 `g`，不必保存记录。

- `g = 0`：所有差值均为 0，对量程没有整除限制，答案为 `max(0, B-m)`。只有一条记录也属于这种情况。
- `g > 0`：枚举 `i = 1..floor(sqrt(g))`。当 `i | g` 时，检查约数 `i` 和 `g/i` 是否落在 `(m,B]` 内。

平方根处的约数只统计一次。

由充要条件，算法统计的每个量程都可行，每个可行量程也必然被枚举到，故答案正确。

## 3. 复杂度与整数范围

记差值绝对值的上界为 `V = 2×10^12`。按欧几里得算法逐次调用的保守上界计，时间为 `O(n log V + sqrt(g))`，额外空间为 `O(1)`；`g=0` 时没有约数枚举。

`g ≤ 2×10^12`，所以枚举次数不超过约 142 万。时刻、差值、最大读数和答案都使用 `long long`。此范围内 `i*i` 不会溢出。

## 4. 部分分

| 子任务 | 限制 | 分值 | 方法 |
|---|---|---:|---|
| 1 | `n≤8, B≤30` | 33 | 枚举 `K`，逐条验证记录也可通过 |
| 2 | `n≤100, B≤5×10^5` | 28 | 枚举 `K`，或先求 gcd 再枚举 |
| 3 | `n≤2×10^5, B≤2×10^6` | 17 | 先求 gcd，枚举 `K∈(m,B]` 检查 `g%K==0` |
| 4 | `B≤10^12` | 22 | 枚举 `g` 的约数 |

提供的 `partial.cpp` 实现第三种方法，时间为 `O(n log V+B)`，空间 `O(1)`，可覆盖前三个子任务，共 78 分。`g=0` 时仍直接使用区间长度公式。对于第四个子任务，枚举量程可能超时。

## 5. 验证

样例答案分别为 3、7。另使用枚举全部候选量程的独立暴力检查小数据，并检查单条记录、`g=0`、无可行量程、平方约数、`10^12` 边界。完整测试记录见上级目录 `验证记录.md`。
