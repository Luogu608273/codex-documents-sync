# B. 矿车

题目：[G123912](https://www.mxoj.net/problem/G123912)。

## 题意与范围

按原始左右顺序给出 N 辆矿车的宝石数。侧线在右端，按栈使用，最终要求主轨道从左到右非递减。只能向初始为 0 的矿车添加宝石，总数不超过 K，最小化侧线容量。N≤3×10^5，K≤10^12，初始 a_i≤10^6。tramcar.in / tramcar.out，1.5 秒，512 MiB。

## 固定序列的容量

矿车从右端接受操作，因此可以按下标从大到小处理，输出时要求数值非递增。固定最终宝石数后，定义

\[
c_i=\#\{j>i:a_j<a_i\}.
\]

最小容量恰为 max c_i。

下界：输出 a_i 前，它右边严格更小的矿车都已经被读到，又不能先于 a_i 输出，因此必须全部暂存在侧线里，至少 c_i 个。相等的矿车可先输出，不能把条件改成≤。

上界用归纳构造：选当前序列中**最靠右的最大值**，设其位置为 p。它右侧的所有值都严格更小，恰有 c_p 个。将它们依次入栈，直接输出该最大值，再将栈中所有车依次退回左侧主轨道。退回后，其余车恰好恢复成“原序列删除位置 p”后的相对顺序。被删的是最大值，不会被任何剩余元素计入“右侧严格更小”的集合，因此剩余序列的所有 c_i 均不增加。归纳可知，容量 max c_i 足够输出全部矿车。相等值取最靠右的一个，保证入栈数量正好等于 c_p。

注意：若仅按“一次入栈、一次出栈”的普通栈排序理解题面，会错误地把某些序列判成不可排序。

## 二分容量并求最少花费

先把初始 0 也当作普通最小值，计算 R_i=#右侧初始值<a_i。对非零位置 i，若容量限制为 M，至少要把

\[
r_i=\max(R_i-M,0)
\]

个右侧 0 填到**至少** a_i，才能把它们从“小于 a_i”的计数中移除。若右侧原本非零且<a_i 的数已经超过 M，则无论如何填都无解。

将所有初始空车按位置编号 1..z。在满足容量上界的前提下，可选最小花费的填法为：空车填值从左到右非递减，且不超过其左侧原始非零值的最大值（没有这样的值则为 0）。

交换依据分两步：若两个空车 i<j 的填值 u>v，交换它们。两位置之间的其他车，其右侧元素由 v 换成 u，小值数不增加；区间外的其他车不受影响。新的 i、j 的右侧小值数都不超过交换前 i 的右侧小值数（新 i 的阈值下降，新 j 只看更短后缀）。所以交换不增加所需容量，花费不变。反复交换，空车填值变成非递减。

再把每个填值截断到它左侧的原始非零最大值。这个上界本身也是非递减的，因此截断后空车仍非递减。对任意原始非零车 a_i，它右侧被截断的空车，其截断上界至少为 a_i，所以不会从“≥a_i”变成“<a_i”，该车的小值数不增加。每辆空车的新填值又不大于左侧某个原始非零最大值，它右侧更小的车形成该非零车右侧小值集合的子集；若没有左侧非零车，填值为 0，也没有更小元素。故空车自身也不会超限。得到所需规范形，且花费只会下降。

在非递减填法中，满足“至少 r_i 个空车填值≥a_i”的最省位置就是最后 r_i 辆空车。设 i 左边已有 now 辆空车：

- 若 r_i>z-now，无解，因为右侧空车不足；
- 否则给下标区间 [z-r_i+1,z] 施加下界 a_i；r_i=0 时无约束。

每个约束都是后缀取最大值。令 nd[z-r_i+1]=max(nd[z-r_i+1],a_i)，最后对 nd 做前缀最大值，即得到各空车必须填的最小宝石数。求和≤K 当且仅当容量 M 可行。

这些下界也满足前缀最大值限制：一个空车的下界只能来自它左侧的某辆非零车。非零车的右侧小值数被压到≤M；每辆空车的填值由左侧某个非零车取到，故它右侧更小的车是该非零车右侧小值集合的子集，也≤M。这证明构造的可行性。

可行性随 M 单调，二分 [0,N-1]。

R_i 用离散化和树状数组从右向左预处理一次，时间 O(N log N)。一次 check 线性，二分 O(log N) 次，总时间 O(N log N)，空间 O(N)。R_i 不需要在每次二分中重算。K 和花费之和用 long long。

## 部分分

`partial.cpp` 仅处理 K=0：双循环计算 max c_i，O(N²) 时间、O(N) 空间，目标 N≤5000、K=0 的 12 分子任务。K>0 时该程序没有实现填宝石，不能视为完整解。
