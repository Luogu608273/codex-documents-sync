# A. 中位数

题目：[G123911](https://www.mxoj.net/problem/G123911)。

## 题意与范围

长度为偶数 n 的整数序列，判断能否划分成若干个连续奇数长度段，使所有段中位数相同。n≤2×10^5，a_i≤10^9。median.in / median.out，1 秒，512 MiB。

## 为什么只需两个段

若三个奇数长度序列的中位数均为 x，设长度为 2k₁+1、2k₂+1、2k₃+1。每段严格小于 x、严格大于 x 的个数都分别≤k_i。拼接后长度为 2(k₁+k₂+k₃+1)+1，小于 x、大于 x 的个数均≤k₁+k₂+k₃，因此中位数仍为 x。重复元素也满足此证明。

原序列长度为偶数，每段长度为奇数，所以段数必为偶数。若段数大于 2，就合并前三段，段数减少 2，中位数不变。反复合并可得到恰好两个段。

因此，有解当且仅当存在奇数 i，1≤i<n，使前缀 a[1..i] 与后缀 a[i+1..n] 的中位数相同。

## 维护前后缀中位数

用大根堆 L 存较小的一半，小根堆 R 存较大的一半，始终保证：

1. |L|=|R| 或 |L|=|R|+1；
2. L 中每个元素≤R 中每个元素。

插入时先按 L 堆顶分类，再移动堆顶调整大小。奇数长度下 L 堆顶就是中位数。

从左向右得到奇数前缀中位数 pre[i]；清空两堆，从右向左得到奇数后缀中位数 suf[i]。枚举所有奇数切分点，判断 pre[i]=suf[i+1]。

时间 O(n log n)，空间 O(n)。中位数仅比较原始整数，不涉及平均值或加法，不会因为 a_i≤10^9 而溢出。

## 部分分

`partial.cpp` 对每个奇数切分点复制两边并排序，直接取中位数。最坏 O(n² log n) 时间，O(n) 空间，适用于 n≤2000 的普通数据。题面按独立测试组给分；不能据此声称覆盖所有“值域小”等大规模子任务。
