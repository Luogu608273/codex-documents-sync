# C. 连通图

题目：[G123913](https://www.mxoj.net/problem/G123913)。

## 题意与范围

输入连通无向图，可以有自环、无重边。构造另一张同顶点集的图，使从 1 到每个点“能否走恰好 b 条边”的所有答案不变，最小化新图边数。可以添加原图没有的边。多测，ΣN≤10^5，ΣM≤2×10^5。connected.in / connected.out，1 秒，256 MiB。

## 压缩无限个条件

对每个点 v，求偶数、奇数长度的最短游走 d₀(v)、d₁(v)。存在长度为 d 的游走后，可在一条边上往返，增加任意偶数长度。因此全部可达长度由这两个最短值决定。对顶点 1 的偶数最短值为 0，长度 2 及以上可利用任意邻边往返；N≥2 且图连通保证存在邻边。

把点拆成 (v,0)、(v,1)，每条无向边连接两个方向的异奇偶状态，BFS 即可求出。若 1 无法以奇数长度回到自身，原图二分；任意 BFS 树保持所有距离和唯一可达奇偶性，答案 N-1。

以下考虑非二分图，所有奇偶最短值均有限。令

\[
(x_v,y_v)=(\min(d_0(v),d_1(v)),\max(d_0(v),d_1(v))).
\]

x、y 奇偶相反，x<y；哪一个是偶数距离由数值奇偶性直接确定，没有丢信息。

## 一条边能完成什么

每个非根点需要最短 x 的前驱，每个点（包括根点）还需要最短 y 的前驱。边不能让距离变短。

对类型 (x,y) 的点，有三种有效的前驱方式：

1. 连到 (x-1,y-1)：一条边同时满足两个前驱要求，称为“对角前驱”。
2. 连到 (x-1,y+1)：满足 x 的前驱；同时可满足对方的 y 前驱。
3. 连到 (x+1,y-1)：满足 y 的前驱；同时可满足对方的 x 前驱。

当 y=x+1 时，同类型两点之间的边也可满足二者的 y 前驱；单点允许用自环满足。根点类型为 (0,y)，其 x=0 不需要前驱。

为何只有这些形式：沿边将奇偶翻转，两个端点相应距离差至多 1；奇偶性不同使差不能为 0。若一条边确实作为最短路前驱，至少一个距离差必须取 -1，列出组合即为上述形式。反过来，这些连接都满足距离不缩短的限制。只要每个正距离状态都有距离减 1 的前驱，反复回溯即可到 (1,0)，所以要求也是充分的。

## 按 x+y 分组的贪心

对角前驱属于更小的 x+y；另两种前驱的 x+y 相同。所以把类型按 (x+y,x) 排序，同一条链依次为

\[
(x,y),(x+1,y-1),(x+2,y-2),\ldots
\]

类型不存在时链断开。对角前驱只需知道其类型是否存在，可以让多个点连接同一个前驱，不消耗前驱的容量。

扫描一条链，维护 t：上一类型尚未满足 y 前驱的点数。设当前类型有 c 个点，且 ok 表示 (x-1,y-1) 类型是否存在。

- 当前层要满足 c 个 x 要求，上一层有 t 个 y 要求。一条跨层边最多各满足一个，因此至少需要 max(c,t) 条；除全局第一个根类型外，增加 max(c,t)。
- 若有对角前驱，尽量使当前层中 t 个（不超过 c）点负责上一层，再让剩余点使用对角前驱。已使用对角前驱的点两个要求都完成，因此新的未满足量为 min(c,t)。
- 若无对角前驱，当前层全部 c 个点都还需要 y 前驱，新的 t=c。

跨层边可在两层中按需要覆盖各点，达到上述下界；额外使用对角边也恰好填补未被跨层边覆盖的当前点。用未满足量 t 作为唯一接口，贪心既达到了当前必须付出的边数下界，也使传给下一层的要求数最少，不会损害后续最优性。

链末尾剩下 t 个 y 要求：

- 若 y>x+1，不能用同类型边，每个要求再花一条边连向更小和的适合类型，增加 t。
- 若 y=x+1，同类型边可两两配对；若奇数个，最后一个用自环或与已满足点连接，增加 ⌈t/2⌉。

最先出现的是唯一根类型，只免除其 x 前驱边；根点的 y 前驱仍必须处理，不能直接跳过整个根类型。代码利用 set 查找对角类型，以链末判断结算 t。

BFS O(N+M)，类型排序和集合查询 O(N log N)，总时间 O(M+N log N)，空间 O(N+M)。答案≤原图 M，代码使用 long long 计数。

## 部分分

`partial.cpp` 对 N≤5，枚举所有 N(N+1)/2 个可能边（含自环）的子集，BFS 比较所有点的奇偶距离，取最小边数。枚举的是全部候选图，**不是原图的子图**。

时间上界 O(2^{N(N+1)/2}N²)，空间 O(N²)，覆盖题面 N≤5 的 15 分子任务。范围外既不保证效率，也不保证数组大小满足要求。
