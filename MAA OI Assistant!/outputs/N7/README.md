# CKK / N7

对应用户提供的 U1667、U1668、U1669、U1670 四份题面。每题一个目录，均包含：

- `solution.md`：中文完整题解、正确性证明、复杂度、实现说明及部分分适用范围。
- `std.cpp`：适用全部题面数据范围的 C++17 程序。
- `partial.cpp`：真正的部分分程序，不能在其适用范围外使用。

## 文件索引

| 目录 | 题目 | 标准算法时间复杂度 | 部分程序覆盖范围 | 默认输入 / 输出 |
| --- | --- | --- | --- | --- |
| U1667 | 中位数 | 预处理 O(10^6)，每组 O(log(n+1)) | n,m<=4，测试点 1 | median.in / median.out |
| U1668 | 三色园 | O(P+36(n+q))，P=1000003 | n<=2000，测试点 1~5 | three.in / three.out |
| U1669 | 嵌套函数 | O(n+q log n) | n,q<=5000，测试点 1~4 | func.in / func.out |
| U1670 | 不是深搜 | O(n3^(n-1)+n²2^n) | n<=6，测试点 1~4 | ndfs.in / ndfs.out |

表中“覆盖测试点”依据题面约束，不假定各测试点分值。U1668 中维数为 6，使用有限域线性基，算法确定性且无哈希误判。U1670 的标准程序是利用 n<=18 的指数算法。

## 使用

默认按题面文件输入输出。示例：

```text
g++ -std=c++17 -O2 std.cpp -o std
```

需要从控制台或本地对拍器输入时，增加 `-DLOCAL`：

```text
g++ -std=c++17 -O2 -DLOCAL std.cpp -o std
```

四题分别独立运行。U1667 的第一项是测试组数 T；U1668/U1669 首行 c 是测试点编号，各只有一组序列；U1670 首行只有 n,m。
