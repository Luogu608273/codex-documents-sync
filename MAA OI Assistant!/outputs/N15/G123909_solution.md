# G123909 子序列（subseq）

## 题意与范围

序列长度 n≤50000，值域 [1,k]，k≤20。有 q≤200000 个区间询问，求区间内不下降子序列的数量，包含空子序列，答案模 10⁹+7。

子序列按照选取的下标区分，相同数值但下标不同的子序列要分别计数。

## 部分分

`G123909_partial_24.cpp` 覆盖测试点 1～3，即 n≤1000，题面分值共 24。

固定左端点 l，依次扩展右端点 r。令 `f[v]` 为目前以数值 v 结尾的非空不下降子序列数。加入 x 时，新增序列数为：

\[
1+\sum_{v=1}^{x}f[v].
\]

把它加到 `f[x]` 和区间总答案中。总答案从 1 开始，以包含空子序列。预处理所有区间后 O(1) 回答询问。

预处理 O(n²k)，询问 O(q)，空间 O(n²+k)。此程序数组只按 n≤1000 配置，不应提交到超出该范围的测试。

## 满分算法

### 1. 把单个元素写成线性变换

用列向量 F 表示状态，维数为 k+1：

- `F[0]=1`，表示空子序列。
- `F[v]` 表示以值 v 结尾的非空不下降子序列数。

读入 x 时，只有第 x 项变化：

\[
F'[x]=F[x]+\sum_{v=0}^{x}F[v],
\]

其他项不变。记这个变换矩阵为 Tₓ。它等于单位矩阵，再把第 0～x 行各加一次到第 x 行上。因此第 x 个对角元为 2，而不是 1。

模数 P=10⁹+7 为奇数，2 可逆，所以 Tₓ 可逆。

### 2. 区间答案只需要两个向量

令

\[
H_i=T_{a_i}T_{a_{i-1}}\cdots T_{a_1},\qquad H_0=I.
\]

矩阵乘法次序不能交换。区间 [l,r] 的变换恰好是：

\[
H_rH_{l-1}^{-1}.
\]

初始状态为单位列向量 e₀；把最终各项相加，就包含了全部非空序列与空序列。记全 1 列向量为 1，则答案为：

\[
\mathbf1^{\mathsf T}H_rH_{l-1}^{-1}e_0.
\]

预处理两个向量：

\[
U_i=\mathbf1^{\mathsf T}H_i,\qquad V_i=H_i^{-1}e_0.
\]

每次询问只计算 Uᵣ 与 Vₗ₋₁ 的点积，O(k) 即可。不需要存储每个前缀的完整矩阵。

### 3. O(k²) 更新前缀矩阵

程序中的 `f` 表示当前 H，`g` 表示当前 H⁻¹。

加入 x 时，计算旧 H 的第 0～x 行之和 D，执行：

\[
H[x,*]\leftarrow H[x,*]+D.
\]

只有这一行变化，因此各列之和组成的 U 也只需加上 D。计算 D 和更新共 O(k²)。注意 D 必须包含旧第 x 行。

### 4. O(k²) 更新逆矩阵

由上面的状态变换可以反解：

\[
F[x]=\frac{F'[x]-\sum_{v=0}^{x-1}F'[v]}{2}.
\]

因此 Tₓ⁻¹ 的第 x 行，在第 0～x-1 列为 -1/2，在第 x 列为 1/2，其余部分与单位矩阵相同。

\[
H'^{-1}=H^{-1}T_x^{-1}.
\]

右乘这个矩阵时，对 g 的每一行 i，先保存 `s=g[i][x]/2`，这里除以 2 指模意义下的除法，然后执行：

- 对 j<x，`g[i][j]-=s`。
- `g[i][x]=s`。
- j>x 的列不变。

模意义下的一半可直接算成 `(v+(v为奇数 ? P : 0))/2`，不需要每次做快速幂。更新后取 g 的第 0 列保存为 V。

初值 U₀ 全为 1，V₀=e₀。

## 正确性证明

加入一个值 x 时，每个新增不下降子序列都唯一地来自一个旧的、末尾数值不超过 x 的子序列，再追加当前位置。空子序列对应单独选择当前位置。故上述状态转移恰好计数全部方案，无重无漏。

连续处理一个区间，等价于按位置顺序复合对应的线性变换，得到 HᵣHₗ₋₁⁻¹。由初始 e₀ 出发，所得状态各项之和就是所求答案，所以点积公式正确。

前缀矩阵的行更新直接实现左乘 Tₓ，逆矩阵的列更新直接实现右乘 Tₓ⁻¹，因而归纳可知所有保存的 U、V 都与定义相符。查询结果因此正确。

## 复杂度与实现

预处理 O(nk²)，每个询问 O(k)，总时间 O(nk²+qk)，空间 O(nk+k²)。实际两个前缀向量表约占 8.4 MB。

加减法每次都归约到 [0,P)，乘法使用 `long long`，点积逐项取模，避免累加多个乘积时溢出。

标准程序默认使用 `subseq.in`、`subseq.out`；定义 `LOCAL` 时使用标准输入输出。
