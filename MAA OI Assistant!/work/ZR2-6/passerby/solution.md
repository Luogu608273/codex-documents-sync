# D. 窗内窗外

题目：<https://www.zhengruioi.com/problem/3724?cid=2225>  
官方简要题解：<https://www.zhengruioi.com/problem/3724/tutorial?cid=2225>

## 题意与范围

给定 n 个左下角和 n 个右上角，需要将它们一一配对，且每对满足 x_left<x_right、y_left<y_right。形成的任意两个矩形必须内部面积不相交，或者一个完全包含另一个。输出 Yes 和配对排列，否则输出 No。

1≤n≤2×10^5，坐标绝对值≤10^9，2n 个点的位置两两不同。不同点的横坐标或纵坐标仍然可以相等。矩形可边界接触，公共面积为 0 仍合法；包含按四条边界的非严格大小关系检查，子任务 3 也要求允许共用上下边界的嵌套矩形。

时限 2 秒，空间 512 MB。使用 passerby.in / passerby.out。

## 1. 从右向左，确定唯一可能的匹配

把全部点按 x 从大到小处理，同 x 时先处理左下角，再将这一组右上角加入候选集合，保证严格要求 x_left<x_right。同 x 的多个左下角按 y 从大到小处理。

使用有序集合保存已经遇到、尚未匹配的右上角，键为 (y,x,id)。处理左下角 L=(x,y) 时，在所有 y_right>y 的候选中，选 y 最小、相同时 x 最小的右上角 R。找不到则无解。

### 为什么这个选择是被迫的

假设存在合法完整匹配，而当前 L 没有选上述最小候选 Q，选了字典序更大的 R。Q 在该完整匹配中只能分给一个尚未处理的左下角 L'：已经处理的点的匹配由此前相同的论证固定，不会再占用候选。

由处理顺序，L' 的横坐标≤L 的横坐标；横坐标相同时，L' 的纵坐标<L 的纵坐标（两个左下角不能位置完全相同）。

矩形 L-R 与 L'-Q 必有正面积交集：Q 在 L 的右上方，而 Q 的纵坐标≤R 的纵坐标。它们又不能包含：

- L-R 包含 L'-Q，要么被 L' 更小的横坐标阻止，要么在横坐标相同的情况下被 L' 更小的纵坐标阻止。
- L'-Q 包含 L-R，要求 Q 的纵坐标≥R 的纵坐标，且横坐标≥R 的横坐标；这与 Q 的 (y,x) 字典序严格更小矛盾。

故不按该规则选择必无合法完整匹配。归纳可得所有配对均被强制确定。注意：贪心找到了完整配对，只说明每对右上关系正确，仍必须检查矩形之间是否交叉。

匹配阶段 O(n log n)。代码中对 y 使用 upper_bound，不能误用允许相等的 lower_bound。

## 2. 扫描线验证矩形层次

按 x 从小到大扫描每个矩形的左边界和右边界。只维护在当前竖直切片上有正宽度交集的矩形。

离散化全部 y 边界，以相邻边界之间的开区间为基本单元。矩形纵区间 [y1,y2] 对应单元编号 [rank(y1),rank(y2)-1]。这样，上下边界相接的两个矩形不会被误判为正面积重叠。

维护每个单元当前最内层的活动矩形编号，空位置为 0。使用支持区间赋值、区间最小值和最大值的线段树。若查询区间的最小值等于最大值，则这一整段有同一个最内层覆盖者。

### 左边界事件

设新矩形为 R：

1. 查询它覆盖的全部 y 单元。若覆盖者不统一，说明它跨过了已有矩形的边界，与已有矩形发生不能包含的交叉，输出 No。
2. 若统一覆盖者为 P，则 P 是 R 的父矩形；P=0 表示外界。除纵区间已包含外，还必须有 x2[P]≥x2[R]，否则 R 将从 P 的右边界伸出，仍然交叉。
3. 保存父亲 P，把整段覆盖者赋为 R。

扫描到新左边界时，先前活动的矩形左边界都不大于新矩形；因此一个新矩形若想反过来包住先前矩形，只可能是左边界相等的情况。下面的同坐标事件排序保证此时先插入外层。

### 右边界事件

查询整段，要求最内层覆盖者统一为 R，随后把它恢复为保存的父亲 P。若不是 R，表示退出层次不合法，输出 No。

### 同 x 的事件顺序

- 先退出，再进入，允许两个矩形仅左右边界接触。
- 同 x 的进入事件，按 y1 递增、y2 递减，使可能的外层先进入。
- 同 x 的退出事件，按 y1 递减、y2 递增，使可能的内层先退出。

对于无法嵌套的同 x 矩形，线段树的统一性检查或右端点检查仍然会拒绝。

### 验证的充分性与必要性

在一个合法层次中，新矩形覆盖的每个内部高度单元原本都属于同一个最内层父矩形，且新矩形的右端点不会超过父矩形；同边界事件也按外进内出的顺序处理，所以合法配对一定通过。

反过来，每次插入都把新矩形完全放进一个父矩形，或者放到所有已有矩形内部之外；赋值只会建立新的包含层。右端点限制防止它后来从父亲右侧穿出，退出又恢复恰好相反的层次。因此通过所有事件检查后，所有矩形必定两两内部不交或包含。

## 复杂度与边界

共有 2n 个事件、至多 2n 个 y 边界。排序、有序集合匹配和线段树操作均为 O(n log n)，总空间 O(n)。

不需要计算矩形面积，也不进行坐标乘法；直接比较 int 坐标即可。所有严格右上约束、横纵坐标相等、边界相接和相同边界的事件顺序都显式处理。

## 部分分程序：保证 57 分

`partial.cpp` 对一般数据使用相同的强制贪心，但每次线性扫描所有未匹配右上角，配完后对所有矩形两两检查四条边界。

时间 O(n²)，空间 O(n)，覆盖子任务 1（n≤10，11 分）和子任务 2（n≤1000，24 分）。其检查规则直接是“无正面积交集，或一方四条边界包含另一方”。

对 y_left=0、y_right=1 的特殊性质，则按 x 递增，把左括号入栈，遇到右括号弹出最近左括号。同 x 时先处理右括号，保证严格的横坐标关系。栈匹配的横区间只会不交或嵌套，而纵区间全部相同，因此构造合法；遇到右括号却栈空时不存在合法匹配。这一分支时间 O(n log n)、空间 O(n)，覆盖子任务 3 的 22 分。

合计保证覆盖 57 分。一般大数据上的 O(n²) 分支可能超时。

## 验证方式

小数据独立枚举所有可用右上配对，逐对检查矩形兼容性，以确定 Yes/No 是否正确；程序输出 Yes 时还单独验证排列、严格右上关系与所有矩形对。专门穷举小网格以覆盖大量横纵坐标相等的情形。公开大样例还与其唯一匹配核对，具体记录见 README.md。
