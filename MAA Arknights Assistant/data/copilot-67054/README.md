# SL-EX-7：Mon3tr原位一技能

导入 **`SL-EX-7-Mon3tr-S1.json`**。基于[原作业67054](https://prts.plus/?op=67054)，保留普通/突袭标记3，两种难度均未实测。按用户后续要求，Mon3tr保持遥的原位。

| 部署顺序 | 单位 | MAA坐标、朝向 | 配置 |
| --- | --- | --- | --- |
| 1 | Mon3tr | **(2,5)，上** | 医疗；一技能专三，精二60，X模组三级 |
| 2 | 歌蕾蒂娅 | (2,3)，右 | 原一技能 |
| 3 | 乌尔比安 | (9,1)，左 | 原二技能 |
| 4 | 斩业星熊 | (3,4)，上 | 原一技能 |
| 5 | 第一瓶汽水 | (3,3)，右 | 原动作保留 |
| 6 | **重构体** | **(2,4)，上** | 第一瓶之后追加，不加入自动编队名单 |

随后保留原15杀、24杀在(8,1)朝右放汽水瓶的动作，最后进入技能守护。一技能由游戏自动触发，`skill_usage=0`表示不让MAA点击技能，仍会正常自动触发；没有额外`Skill`/`SkillUsage`动作。

Mon3tr朝上，直接范围包含自身、歌蕾蒂娅、斩业星熊和重构体。重构体位于三人的周围八格内，可给三人增益并参与治疗链。没有改变其他干员位置及相对顺序。

按[Mon3tr资料](https://prts.wiki/w/Mon3tr)及[链愈师机制](https://prts.wiki/w/分支特性信息/data)，每跳选择周围八格的最低血比目标，同血比选择最后部署者，一条链不重复选择已经治疗的目标。以下示例只假设起点确定后，其余候选同血比：

- 重构体起链：**重构体 → 斩业星熊 → 歌蕾蒂娅**。重构体之后优先两名地面，末端歌蕾蒂娅与Mon3tr距离两格，无法继续跳向Mon3tr。
- 歌蕾蒂娅起链：**歌蕾蒂娅 → 重构体 → 斩业星熊 → Mon3tr**。
- 斩业星熊起链：**斩业星熊 → 重构体 → 歌蕾蒂娅**。

一技能没有二技能固定优先治疗重构体的效果，不应把以上重构体起链示例当成每次必经路线。一技能额外跳跃、重构体额外不衰减跳跃也不能消除地理断链。脚本保守按四个治疗落点检查，不将其表述为每次必定治疗四人。

低血比优先级高于部署顺序。例如以斩业星熊为起点，血比为斩业星熊0.2、重构体0.3、Mon3tr0.4、歌蕾蒂娅1.0时，路径为“斩业星熊→重构体→Mon3tr”，会遗漏歌蕾蒂娅。因此不能保证每条链同时覆盖左侧两名地面。

乌尔比安在(9,1)，与左侧治疗链断开，本版不保证治疗他。为保持原位且不增加其他干员，没有添加连接右侧的治疗跳板。不要额外部署其他单位或随意改变顺序后套用这些示例。

[水汽汽水瓶](https://prts.wiki/w/水汽汽水瓶)属于敌方装置，不作为友方治疗跳板。三次瓶子的位置、朝向、15/24杀条件及第一瓶先于重构体部署均已保留。关卡普通与突袭地块一致；突袭的敌方属性与超新星术师攻速强化保留在原始关卡数据中。汽水瓶与喷泉的已有地块均未被重构体占用。

练度依据**2026-11-19快照**，本次没有重新请求一图流。Mon3tr满足精二60、一技能专三、X模组三级；MAA配置只能指定模组类型，等级应手动核对。快照未持有斩业星熊，仍需准备/借用**一技能**版本。歌蕾蒂娅自有一技能7级，原作业未写专精门槛，不代表已确认该练度可通关。

Mon3tr的部署费用高于遥，后续到场时间可能变化；用纯治疗替换遥也会失去遥的攻击与原技能支援，不能从治疗范围检查推断战斗结果。

`build_adapted.py`可复现修改；`validation.json`记录合法地块、原位、阵容与瓶子动作保留、容量、自动技能类型，以及四种指定起点×81个固定血比场景（324例）。这些检查不模拟治疗量、血量随时间变化、敌方伤害、召唤物存活、费用时轴及战斗。**未加载MAA核心、未连接设备、未实战验证。**
