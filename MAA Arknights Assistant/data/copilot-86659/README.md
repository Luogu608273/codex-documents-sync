# BB-EX-6：追加Mon3tr一技能

导入 `BB-EX-6-Mon3tr-S1.json`。这是[作业86659](https://prts.plus/?op=86659)的本地修改版，未修改线上原作业。原作业的三名干员、技能与模组要求、位置、朝向、部署顺序以及普通／突袭标记均保持。

**Mon3tr放在MAA坐标(10,5)，朝上，带一技能专三、X模组三级，精二60。** 她在原三人部署并切换二倍速之后再落地，然后进入挂机；一技能由游戏自动触发，无须MAA点击。

该位置是普通高台 `tile_wall`，不是接驳地块，不需要铁链才能部署，也不在突袭封锁的8个位置中。直接治疗范围包含歌蕾蒂娅(10,3)和乌尔比安(9,4)。逻各斯(10,2)不在直接治疗范围内，但与歌蕾蒂娅相邻，可经治疗跳跃获得支援；实际跳跃目标受血量与优先级影响，不能保证每次都跳到他。

## 铁索处理

按本次查证的[稳固锁链机制](https://prts.wiki/w/巴别塔)，支援范围为5×5去掉四角，每名干员最多维持两条链，新部署时选择范围内最后部署且未满连接数的合格端点。普通地块上的新干员只向接驳地块上的合格干员连链；新干员自己位于接驳地块时，才需要先有可用端点。

保留原顺序后，静态连接结果为：

1. 歌蕾蒂娅(10,3)先站普通地面。
2. 乌尔比安(9,4)站接驳地块，连接歌蕾蒂娅，形成第一条链。
3. 逻各斯(10,2)站普通高台，连接范围内的乌尔比安，形成第二条链。
4. Mon3tr(10,5)最后站普通高台；此时乌尔比安两条连接已满，Mon3tr不另建连接，原两条链不改选。

不要把Mon3tr插到原三人之前部署，也不要随意撤掉原链端点。此次没有额外添加重构体，避免扩大用户指定的新增干员范围。静态模型假定原干员始终在场；若实战有人被击倒，链条仍会受影响。
