重构体就位后启用Mon3tr二技能“好了就用”，然后二倍速挂机。干员列表中的初始`skill_usage=0`只用于阻止她在重构体尚未落地时提前开技能；重构体后的`SkillUsage`动作改成`1`，后续不限制次数。无需手动开技能。原另外四名干员的坐标、朝向、技能与相对部署顺序保持。

不要临时额外部署其他单位，也不要随意改变上述部署顺序；这些变化会影响同血比选人，不能套用本说明的满血路径。

Mon3tr朝下的直接范围涵盖右侧三人，以及重构体。四名干员和重构体都位于普通地块，本次没有使用上方接驳地块或流沙，也没有额外加治疗跳板。部署单位总数6，不超过上限8。

## 血量与部署优先级

按[链愈师机制](https://prts.wiki/w/分支特性信息)，跳跃范围为以当前接收者为中心的3×3，跳到生命比例最低的合格单位；同血比时选择最后部署者，一条链不重复选择已跳过的目标。Mon3tr二技能期间优先治疗重构体，并产生延迟追加的治疗链。[Mon3tr技能与天赋](https://prts.wiki/w/Mon3tr)

本布局特意保留**歌蕾蒂娅先下、初雪后下**。当其他单位血比相同时，以重构体起始的四次治疗落点为：

**重构体(9,7) → 初雪(8,6) → Mon3tr(9,5) → 乌尔比安(9,4)**

初雪比歌蕾蒂娅后部署，故先被选中；初雪把链传给Mon3tr本人，再传至乌尔比安。Mon3tr作为施法源没有因此被当作已接受过治疗的主目标，可以在后续链中成为接收者。如果倒过来让歌蕾蒂娅比初雪晚部署，满血时会走“重构体→歌蕾蒂娅”，随后因附近没有未经过的目标而断链。

**歌蕾蒂娅掉血且血比低于初雪时，会优先走“重构体→歌蕾蒂娅”。** 这条短链优先支援当下受伤的地面干员。重构体周围八格同时涵盖歌蕾蒂娅和初雪，可给她们攻击力增益；Mon3tr与乌尔比安不在该增益范围内。

这里的“四次”明确指上列四个治疗落点（重构体加三个后续目标），不是重构体之外再无条件治疗四名干员。即便放宽为四个后续目标，上述两个示例也不会多跳，因为末端已没有合法的未经过目标。

## 不能保证的覆盖

歌蕾蒂娅在当前布局中是只连接重构体的末端。单条链一旦先跳向她，就不能再从她继续走向乌尔比安；因此**不能保证每一条链同时覆盖两名地面干员**。尤其歌蕾蒂娅轻伤、乌尔比安重伤时，重构体只能比较自己的相邻候选，可能仍先跳向歌蕾蒂娅。HP优先级无法靠部署顺序覆盖，部署顺序只处理同血比。

二技能期间的正常治疗与延迟追加治疗会各自选目标，第一条链的治疗可能改变第二条链的优先级。技能空档时也不再保证以重构体起链。静态结果不包括治疗量、实际血量变化、敌方攻击、技能回转、召唤物存活或治疗链动画。

斩业星熊保留原位，仅按用户要求忽略其治疗覆盖；没有擅自把她从队伍删掉或挪位。
