## 以重构体起链的覆盖

Mon3tr直接治疗范围包含左侧五名干员和重构体。重构体周围八格覆盖**圣聆初雪、Mon3tr、歌蕾蒂娅、凛御银灰**，不包含斩业星熊。

按[Mon3tr技能与天赋](https://prts.wiki/w/Mon3tr)，一技能强化治疗增加目标数，重构体额外提供不衰减的跳跃。每跳优先低血比，血比相同时优先最后部署者，不重复治疗本链已经经过的目标。以重构体为起点、后续候选同血比且触发一技能时：

**重构体 → Mon3tr → 歌蕾蒂娅 → 斩业星熊 → 凛御银灰**

这里共五个落点，其中重构体是天赋提供的额外目标，普通目标为Mon3tr和三名地面干员。一技能未触发的普通治疗，同条件路径为“重构体→Mon3tr→歌蕾蒂娅→斩业星熊”，目标数不足以继续抵达凛御银灰。不能把强化治疗的覆盖套用到每次普攻。

Mon3tr比歌蕾蒂娅、初雪及凛御银灰后部署，所以从重构体起链时，同血比会先跳Mon3tr本人；她再将链传给歌蕾蒂娅，随后抵达另外两名地面干员。将重构体放在斩业星熊之前，也能改善部分非重构体起点的同血比路径。脚本比较四个可插入时机，选择Mon3tr之后立即部署。

治疗后的血量变化、重构体失血、敌人伤害都会改变路径；本检查不模拟这些过程。初雪的血比更低时可能提前吸引跳跃，某些起点/血比下也可能遗漏地面目标，**不能保证每次优先起链重构体或每条链治疗全部左侧干员**。

在保留全部原站位、汽水瓶(3,3)占位，以及重构体必须在Mon3tr直接范围内的条件下，**(1,3)是唯一空闲合法地面格**；没有占用瓶子位置来冒险等待瓶子被打碎。右侧乌尔比安(9,1)与左侧链路断开，本版不保证治疗他。

## 练度与验证边界

使用**2026-11-20重新获取的一图流快照，共250条记录**。Mon3tr满足精二60、一技能专三、X模组三级；MAA只能指定模组类型，等级应手动核对。

新快照中**凛御银灰二、三技能均已专三**，原S3专三缺口已消除。现在仍缺**斩业星熊**；按作业已写要求，可用单助战补齐其一技能7级及X模组配置。初雪、歌蕾蒂娅、乌尔比安的指定技能和模组类型与快照相符，原练度门槛均保留；这不构成实战可通关证明。

纯治疗替换遥会失去其原有攻击和支援效果；费用增加及提前部署重构体会改变乌尔比安、斩业星熊与汽水瓶的实际到场时间。
