# TW-EX-7：凛御银灰、塞雷娅与小车补强版

将 `TW-EX-7-silverash-robot.json` 导入MAA，进入TW-EX-7编队选择界面使用。此为[原作业104914](https://prts.plus/?op=104914)的本地修改版，未修改线上作业。保留原普通／突袭两种难度标记，均尚未实测。

上一版用户反馈突袭未通过。本次加入塞雷娅，按用户要求严格避开对结城理的治疗；新增版本尚未实战验证。

## 修改逻辑

前三个障碍物的操作与费用条件保持原样。第三箱落地后，将凛御银灰放在(7,3)朝右，等待并显式释放首次3技能，再用`SkillUsage:1`开启后续自动技能。初始`skill_usage:0`用来避免自动技能提前消耗首次开技，导致紧随的显式技能动作等待第二轮。

第一次开启时，圣聆初雪、结城理、Lancet-2、塞雷娅都还在待部署区。按当前自有数据，最高费用仍为圣聆初雪24费，最低仍为Lancet-2的3费；新增塞雷娅22费不改变这两个对象。预计交换为初雪3费、小车24费。紧接着部署初雪，让其接收本次3技能的协同攻击；小车留在手中，不占战场位置，也不会消耗这次首个落地的协同效果。障碍物卡为5费，不是预计的最高或最低费用对象。

凛御银灰的3技能范围覆盖(10,3)、(8,4)、(9,4)，支援右侧纵向通路与临时绕行区域。(7,3)的下方(7,4)已经放箱，左方(6,3)不可供地面敌人通行，是避开主要路径的支路位置，降低他直接阻挡巫术巨像的风险。他在场时还为谢拉格干员初雪提供防御、生命回复与免冻效果。静态路径检查仅用于位置判断，不代表游戏实际路径或生存已验证。

凛御银灰三技能会额外回费，原费用增长条件不再等同于相同时间。因此首次开技能之后的三处费用增长等待改为固定延时：初雪后放临时箱的`+5费`改2500毫秒，结城理子弹时间前的`+3费`改1500毫秒，结城理开技后的撤箱`+5费`改2500毫秒。这在全程二倍速下近似对应原5／3／5游戏秒等待，避免直接因额外回费提前撤箱。实际识别与操作耗时仍会影响时间，需实测。

保留障碍物顺序：先放(1,3)、(5,3)、(7,4)，再放临时箱(10,5)；结城理开技能后撤掉(10,5)，补到(8,6)。之后再部署塞雷娅，不推迟前面的换箱或结城理开技；最后保留`SkillDaemon`，凛御银灰后续技能好了就开。初雪和结城理的技能用法不改为循环。

塞雷娅放在(8,4)朝上，带2技能“药物配置”。该技能范围包含相对位置(-1,-1)的凛御银灰(7,3)，以及(0,-2)的初雪(8,2)，但不包含右上角(+2,-2)的结城理(10,2)。技能范围上下左右对称，朝向不影响这项排除。静态校验已明确断言“不包含结城理”；不要将她改带3技能，3技能范围会包含结城理。当前数据中塞雷娅是1技能专三、2技能7级，本版按2技能7级配置，没有把她误写成2技能专三。

最终箱(8,6)放好后，(8,4)处于主通路旁支，静态最短路径不经过此格；因此等换箱完成再部署，避免提前阻挡临时绕行的敌人。此判断不能代替实际战斗验证。

## 验证范围

- 使用2026-10-23已获取的一图流快照，共229条。已逐项核对四名自有干员的等级、技能、模组及唯一助战缺口。
- 已检查JSON、干员引用、合法部署地块、部署重叠、箱子顺序、最终箱子位置、普通与突袭地块一致、三技能范围以及静态路线可达性。证据在`adaptation.json`和`validation.json`。
- 新增检查：塞雷娅2技能覆盖初雪、凛御银灰，不覆盖结城理；部署安排在最终换箱后；22费不影响初次费用交换对象。
- 原作业两名核心要求90级，本版将其门槛改为当前60级，再借助凛御银灰补强。这是个人配置，不能当作已验证的最低练度。
- 未连接游戏、未执行战斗、未消耗理智，未做本机MAA核心加载验证，不能宣称已通关。
- 突袭另有敌人攻击、生命1.2倍及我方防御降至30%的条件；保留难度标记不等于已验证突袭稳定。
