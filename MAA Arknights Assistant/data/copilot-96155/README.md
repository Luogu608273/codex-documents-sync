Mon3tr一技能是游戏内自动触发技能，`skill=1`、`skill_usage=0`表示MAA无需点击，不阻止游戏自动触发。已清除遥的原技能与Y模组适配，替换为医疗Mon3tr和X模组。重构体只写部署动作，不加入自动编队名单。其余三名干员的要求、位置、朝向、相对部署顺序和技能设置不变。

## 尽可能先治疗重构体

重构体在Mon3tr落地后立即部署，利用自身持续失血，尽可能成为主治疗目标。一技能仍遵循低血比优先，无法像二技能那样强制优先选择重构体；其他干员血比更低时会先治疗其他干员。部署顺序只解决后续跳跃的同血比优先级，不能覆盖血比差异。

从重构体起链、其余候选同血比时：

**重构体(4,1) → 丰川祥子(3,1) → Mon3tr(4,2) → 凛御银灰(5,1)**

祥子最后部署，所以重构体同血比时先跳祥子；祥子经Mon3tr传给另一名地面干员银灰。四个落点包括天赋额外不衰减目标重构体，普通治疗与一技能强化治疗都有足够容量完成这条路线。[Mon3tr技能与天赋](https://prts.wiki/w/Mon3tr)

重构体周围八格包含**祥子、银灰、Mon3tr**，可同时提供增益。比较原站位、原Mon3tr朝向下6个合法召唤物地面位置，选择(4,1)，优先起链覆盖两名地面，再考虑周围增益覆盖。

初雪仍在Mon3tr直接治疗范围内，但与上述四个单位均不邻接，**不会进入这条跳跃链**；初雪血比更低时，可由Mon3tr直接选为主治疗目标。没有为了把初雪串入链路而牺牲以重构体起链时的地面覆盖。

不能保证每条链都同时覆盖两名地面。例如从重构体起链，但Mon3tr血比0.3、其余单位满血时，会先跳Mon3tr，再跳较晚部署的祥子后断链，遗漏银灰。各次实际治疗、血量变化、目标状态与敌方伤害都会改变路线。不要额外部署其他单位或随意改变顺序。

## 费用与关卡机制

[SL-MO-1资料](https://prts.wiki/w/SL-MO-1)及本次关卡原始数据确认：初始50费，上限999，每999秒才自然恢复1费，部署上限9。本版5个单位不超过上限。**持续产费依赖凛御银灰三技能，保留其好了就开设置。**

Mon3tr比遥贵，并新增3费重构体，会改变后续到场时间。按精二基础费用、暂不计潜能减费：原银灰13+遥13后剩24费，足以立即部署24费初雪；新版银灰13+Mon3tr18+重构体3后剩16费，需要等待产费。因此**银灰首次换费时，初雪和祥子是否仍在待部署区可能改变**，不能沿用原作业的精确费用时间轴。脚本只作基础费用核对，没有模拟实际潜能减费、施法、换费、每次产费和部署耗时。

原作业没有部署汽水瓶，本版也不另加瓶；地图喷泉、蒸汽机制及原三人站位保留。将遥换成纯治疗还会失去遥原本的攻击、支援与技能效果，治疗链几何正确不能证明原打法仍可通关。
