# 缓冲（buffer）

## 文件与范围

- `std.cpp`：`O(n²)` 标准解。
- `partial.cpp`：`O(n³)` 区间转移，覆盖子任务 1、2、3，共 78 分。
- 默认读写 `buffer.in`、`buffer.out`；定义 `LOCAL` 后使用标准输入输出。使用 C++17。

原题：`1 ≤ n ≤ 6000`，两个字符串长度均为 `n`，只含小写字母。

## 1. 一次暂存的形式

一次暂存从输入位置 `l` 开始，暂存非空区间 `S[l..m]`；随后直接输出 `S[m+1..r]`，最后倒序输出暂存区。

这次操作读入、输出的字符数相同，处理的整个区间为 `[l,r]`，输出为

\[
S[m+1..r]+\operatorname{rev}(S[l..m]),\qquad l\le m\le r.
\]

`m=r` 对应存完立即倒序输出。两次暂存不能交叠，所以任意合法过程都能拆成若干直接输出的单个字符和上述操作块；反过来，这样拼接也一定是合法过程。

## 2. 前缀 DP

`f[i]` 表示已经读入 `S[1..i]`、恰好输出 `T[1..i]`、缓冲区为空时的最少暂存次数。

初始化 `f[0]=0`，其他状态为无穷大。对每个可达的起点 `l`：

- 若 `S[l]=T[l]`，可直接输出，转移 `f[l] ← min(f[l], f[l-1])`。
- 若某个 `m∈[l,r]` 使上述操作块的输出恰好为 `T[l..r]`，转移 `f[r] ← min(f[r], f[l-1]+1)`。

按 `l` 递增处理即可，因为所有转移都从较短的前缀指向较长的前缀。

## 3. 常数时间判断一个切分点

预处理两个匹配长度：

- `a[i][j]`：从 `S[i]`、`T[j]` 开始向右的最长公共前缀长度。
- `b[i][j]`：`S[i],S[i+1],…` 与 `T[j],T[j-1],…` 的最长匹配长度。

转移为

\[
a[i][j]=[S_i=T_j]\,(1+a[i+1][j+1]),
\]

\[
b[i][j]=[S_i=T_j]\,(1+b[i+1][j-1]).
\]

越过边界时长度为 0。`i` 从大到小计算。

对固定的 `l,r,m`，暂存长度为 `m-l+1`，直接输出长度为 `r-m`。合法条件恰好为

\[
b[l][r]\ge m-l+1,\qquad a[m+1][l]\ge r-m.
\]

前者验证倒序输出的部分，后者验证直接输出的部分。逐个枚举 `l,r,m` 就得到 `O(n³)` 部分分。

## 4. 消去切分点枚举

固定 `l`，定义

\[
h[k]=\max_{l\le m\le k}\{m+a[m+1][l]\}.
\]

令 `h[l-1]=0`，从左到右取前缀最大值，`O(n)` 即可计算这一整行。

对终点 `r`，倒序匹配条件限制

\[
m\le k=\min(r,l+b[l][r]-1).
\]

直接输出条件等价于 `m+a[m+1][l] ≥ r`。所以存在合法切分点，当且仅当

\[
k\ge l\quad\text{且}\quad h[k]\ge r.
\]

这里的最大值只需见证“存在一个切分点”，不需要记录具体位置。

因此，对每个 `l`，先 `O(n)` 求 `h`，再 `O(n)` 枚举 `r` 并转移，整个 DP 为 `O(n²)`。

## 5. 正确性证明

操作块的两个匹配条件分别验证输出串的两个连续部分，长度之和恰好为 `r-l+1`，所以它们与操作块合法等价。

前缀最大值判定精确表达了合法切分点的存在性，未增加或删除任何可行操作。

考虑任意合法过程的最后一步：若它是直接输出一个字符，就对应 DP 的第一类转移；若它是最后一次完整暂存操作，就对应第二类转移。其前面必处于较短前缀、缓冲区为空的状态。反过来，两类 DP 转移都可以实际执行。

由前缀长度归纳，`f[i]` 恰为状态定义中的最小值。最终 `f[n]` 不可达时输出 `-1`，否则输出 `f[n]`。

## 6. 复杂度与实现

预处理和 DP 均为 `O(n²)` 时间，空间为 `O(n²)`。

匹配长度最大为 6000，两个矩阵使用 `unsigned short`，实际预分配约 138 MiB，低于 512 MB 限制。`a[n+1][l]=0` 可自然处理“没有直接输出部分”的情形。

| 子任务 | `n≤` | 分值 | 方法 |
|---|---:|---:|---|
| 1 | 8 | 31 | 枚举合法操作过程 |
| 2 | 60 | 33 | 区间 DP 枚举切分点 |
| 3 | 600 | 14 | 预处理匹配长度，`O(n³)` 转移 |
| 4 | 6000 | 22 | 前缀最大值优化至 `O(n²)` |

`partial.cpp` 采用同一状态定义，直接枚举切分点，覆盖前三个子任务，共 78 分；大数据可能超时。

## 7. 验证

样例答案为 1、0。独立暴力枚举每种合法操作块与后续过程，记录每种输出串的最小代价；覆盖长度不超过 4 的全部二进制字符串对，以及随机的三字母字符串、重复字符、不可达输出。另检查 `n=6000` 的全同字符和整串倒序。完整测试记录见上级目录 `验证记录.md`。
