# P9067 [Ynoi Easy Round 2022] 虚空处刑 TEST_105

## 题目描述

给定一棵 $n$ 个节点的树，第 $i$ 个点有点权 $a_i$。

定义一个点 $x$ 所在的极大同色连通块为一个**极大的**点集 $S$，满足 $x\in S$，且对任意点集中的元素 $i,j$，可以找到一个节点序列 $p_1,p_2,...p_t$，满足 $p_1=i$，$p_t=j$，且对任意 $k$ 为 $[1,t)$ 中的整数，满足 $p_k$ 与 $p_{k+1}$ 在树上相邻，且 $a_{p_k}=a_{p_{k+1}}$，且 $p_k\in S$。

有 $m$ 次操作：

`1 x y`：给出一个点 $x$ ，将其所在的极大同色连通块中每个点的点权修改为 $y$。

`2 x`：给出一个点 $x$，查询其所在的极大同色连通块的大小。

## 输入格式

第一行两个数 $n,m$。

第二行 $n-1$ 个数，第 $i$ 个数表示树上第 $i+1$ 的节点的父亲节点的编号，保证父亲节点的编号比该节点小。

第三行 $n$ 个数，第 $i$ 个数表示 $a_i$。

之后 $m$ 行，每行形如 `1 x y` 或 `2 x`，意义如上述。

## 输出格式

对每个 $2$ 操作，输出一行一个数表示答案。

## 输入输出样例 #1

```
4 5
1 1 2
3 1 1 1
2 4
1 1 1
1 4 3
2 4

```

### 输出 #1

```cpp
#include <cstdio>
#include <vector>
#include <map>
#include <algorithm>

using namespace std;

const int MAXN = 1000005;

int n, m;
int p[MAXN], depth[MAXN], col[MAXN];
int f[MAXN], sz[MAXN], top_node[MAXN];
map<int, vector<int>> adj[MAXN];

inline int read() {
    int x = 0; char ch = getchar();
    while (ch < '0' || ch > '9') {
        if (ch == EOF) return -1;
        ch = getchar();
    }
    while (ch >= '0' && ch <= '9') {
        x = (x << 3) + (x << 1) + (ch ^ 48);
        ch = getchar();
    }
    return x;
}

int find(int x) {
    while (x != f[x]) x = f[x] = f[f[x]];
    return x;
}

int merge(int u, int v) {
    u = find(u); v = find(v);
    if (u == v) return u;

    // 按 map 大小启发式合并，优化 map 合并复杂度
    if (adj[u].size() < adj[v].size()) swap(u, v);

    f[v] = u;
    sz[u] += sz[v];
    if (depth[top_node[v]] < depth[top_node[u]]) {
        top_node[u] = top_node[v];
    }

    for (auto &it : adj[v]) {
        int c = it.first;
        vector<int> &src = it.second;
        vector<int> &dest = adj[u][c];
        // 向量启发式合并
        if (dest.size() < src.size()) swap(dest, src);
        dest.insert(dest.end(), src.begin(), src.end());
    }
    adj[v].clear();
    return u;
}

void process_merges(int r, int y) {
    while (true) {
        r = find(r);
        auto it = adj[r].find(y);
        if (it == adj[r].end() || it->second.empty()) break;

        int node_v = it->second.back();
        it->second.pop_back();

        int child_root = find(node_v);
        // 只有当该子树根节点颜色正确且其父节点属于当前连通块时才合并
        if (child_root != r && col[child_root] == y && find(p[top_node[child_root]]) == r) {
            r = merge(r, child_root);
        }
    }
}

int main() {
    n = read(); m = read();
    if (n == -1) return 0;

    depth[1] = 1;
    for (int i = 2; i <= n; ++i) {
        p[i] = read();
        depth[i] = depth[p[i]] + 1;
    }

    for (int i = 1; i <= n; ++i) {
        col[i] = read();
        f[i] = i;
        sz[i] = 1;
        top_node[i] = i;
    }

    // 初始化：合并相邻同色节点
    for (int i = 2; i <= n; ++i) {
        if (col[i] == col[p[i]]) {
            merge(i, p[i]);
        }
    }

    // 建立颜色索引 map：记录每个连通块下方相邻的不同色子连通块
    for (int i = 2; i <= n; ++i) {
        int r = find(i);
        if (top_node[r] == i) {
            int pr = find(p[i]);
            adj[pr][col[r]].push_back(r);
        }
    }

    while (m--) {
        int op = read();
        if (op == 1) {
            int x = read(), y = read();
            int r = find(x);
            if (col[r] == y) continue;

            int t = top_node[r];
            int pr = p[t];
            col[r] = y;

            // 向上合并
            if (pr) {
                int pf = find(pr);
                if (col[pf] == y) {
                    r = merge(r, pf);
                } else {
                    // 若不能向上合并，则更新父块对其的颜色索引
                    adj[pf][y].push_back(r);
                }
            }

            // 向下合并所有颜色变为 y 的子块
            process_merges(r, y);
        } else {
            int x = read();
            printf("%d\n", sz[find(x)]);
        }
    }

    return 0;
}
```

## 原第 2 轮

### 用户

解释一下adj

### 历史助手

在提供的代码实现中，`adj` 是整个算法的核心数据结构，其定义为：
`map<int, vector<int>> adj[MAXN];`

### 1. 核心定义
`adj[u]` 维护的是：**以 $u$ 为代表元（Root）的连通块，其下方紧邻的所有“子连通块”的索引。**

*   **下标 `u`**：某个极大同色连通块在并查集（DSU）中的根节点。
*   **Map 的 Key (color)**：代表某种颜色。
*   **Map 的 Value (vector)**：一个列表，存储了所有颜色为 `color` 且**父亲节点属于连通块 `u`** 的子连通块根节点。

---

### 2. 为什么要设计 adj？
题目要求执行“修改一个连通块的所有点色”。当连通块 $A$ 的颜色变成 $y$ 时，它可能会和两种邻居合并：
1.  **上方邻居**：它的父亲节点所在的连通块。
2.  **下方邻居**：它的所有子节点所在的连通块中，颜色原本就是 $y$ 的那些。

**难点在于下方邻居：** 一个连通块可能有成千上万个子节点，如果每次修改颜色都遍历所有子节点去检查颜色，时间复杂度会爆炸。
`adj` 的作用就是**空间换时间**：它直接告诉你，当前块下面有哪些颜色为 $y$ 的块等着被合并。

---

### 3. adj 的具体运作流程

#### A. 初始化
在预处理阶段，如果节点 $i$ 的颜色与父亲 $p[i]$ 不同，那么 $i$ 所在的连通块就是 $p[i]$ 所在连通块的一个“异色子邻居”。此时执行：
`adj[find(p[i])][col[i]].push_back(find(i))`

#### B. 操作 1：颜色修改（合并）
当把连通块 $r$ 的颜色改为 $y$ 时：
1.  **向下合并**：程序直接访问 `adj[r][y]`。这个 vector 里存的全是“原本颜色就是 $y$ 且挂在 $r$ 下面”的块。
2.  程序遍历这个 vector，把这些块通过 `merge` 函数合并到 $r$ 中。
3.  **向上合并**：检查 $r$ 的父亲块颜色是否也是 $y$，如果是，则合并。

#### C. 启发式合并（Heuristic Merging）
由于我们使用了并查集，当两个连通块 $u$ 和 $v$ 合并时，它们各自维护的 `adj` 映射表也需要合并。
为了保证复杂度，代码采用了**启发式合并**：
*   比较 `adj[u]` 和 `adj[v]` 的大小（包含的颜色种类数量）。
*   将小的 map 里的 vector 逐一插入到大的 map 中。
*   这样可以保证每个元素被移动的次数是 $O(\log n)$ 级别的。

---

### 4. 总结
`adj` 相当于一个**分类寄存器**。它让每一个连通块都能“秒找”周围哪些邻居在颜色改变后会与自己合并，从而避开了暴力遍历树边的开销，是处理这类动态连通块问题的常用 Ynoi 技巧（通常配合并查集和启发式合并使用）。

### 历史助手

针对该题解的思路，使用 **01-Trie 合并**（Segment Tree Merging 的 Trie 版本）替代 `std::map` 启发式合并，可以将复杂度从 $O(M \log^2 N)$ 优化至 $O(M \log V)$，其中 $V$ 是颜色范围。

在实现中，每个连通块维护一棵 Trie。Trie 的叶子节点维护一个链表，存储所有“颜色为该叶子路径、且父亲节点属于当前连通块”的子连通块根节点。

```cpp
#include <cstdio>
#include <algorithm>

using namespace std;

const int MAXN = 1000005;
const int MAX_NODES = 21000005; // 节点池大小，适配 512MB
const int MAX_L = 2000005;      // 链表节点池

int n, m;
int p[MAXN], col[MAXN], f[MAXN], sz[MAXN], top_node[MAXN];
int rt[MAXN];

// 链表节点池，用于处理 Trie 叶子节点的 ID 列表
struct ListNode {
    int id, nxt;
} lnodes[MAX_L];
int lcnt = 0, lbin[MAX_L], lbtop = 0;

inline int new_l(int id, int nxt) {
    int u = lbtop ? lbin[lbtop--] : ++lcnt;
    lnodes[u].id = id; lnodes[u].nxt = nxt;
    return u;
}

// 01-Trie 节点
struct Node {
    int ch[2];
    int head, tail;
} t[MAX_NODES];

int node_cnt = 0;
int recycle_bin[MAX_NODES], bin_top = 0;

inline int new_node() {
    int u = bin_top ? recycle_bin[bin_top--] : ++node_cnt;
    t[u].ch[0] = t[u].ch[1] = t[u].head = t[u].tail = 0;
    return u;
}

inline void delete_node(int u) {
    if (u) recycle_bin[++bin_top] = u;
}

// 向 Trie 中插入一个子连通块 ID
void insert(int &u, int c, int id, int bit) {
    if (!u) u = new_node();
    if (bit < 0) {
        if (!t[u].head) {
            t[u].head = t[u].tail = new_l(id, 0);
        } else {
            t[u].head = new_l(id, t[u].head);
        }
        return;
    }
    insert(t[u].ch[(c >> bit) & 1], c, id, bit - 1);
}

// 合并两棵 Trie
int merge_trie(int u, int v, int bit) {
    if (!u || !v) return u | v;
    if (bit < 0) {
        if (t[v].head) {
            if (!t[u].head) {
                t[u].head = t[v].head; t[u].tail = t[v].tail;
            } else {
                lnodes[t[v].tail].nxt = t[u].head;
                t[u].head = t[v].head;
            }
        }
        delete_node(v);
        return u;
    }
    t[u].ch[0] = merge_trie(t[u].ch[0], t[v].ch[0], bit - 1);
    t[u].ch[1] = merge_trie(t[u].ch[1], t[v].ch[1], bit - 1);
    delete_node(v);
    return u;
}

// 提取指定颜色的子块链表并清空
int extract_list(int &u, int c, int bit) {
    if (!u) return 0;
    if (bit < 0) {
        int res = t[u].head;
        t[u].head = t[u].tail = 0;
        return res;
    }
    return extract_list(t[u].ch[(c >> bit) & 1], c, bit - 1);
}

int find(int x) {
    return f[x] == x ? x : f[x] = find(f[x]);
}

// 连通块合并：将 v 合并进 u
int component_merge(int u, int v) {
    u = find(u); v = find(v);
    if (u == v) return u;
    f[v] = u;
    sz[u] += sz[v];
    rt[u] = merge_trie(rt[u], rt[v], 19);
    return u;
}

// 向下递归合并颜色匹配的子块
void process_down(int &r, int y) {
    while (true) {
        int lhead = extract_list(rt[r], y, 19);
        if (!lhead) break;
        int cur = lhead;
        while (cur) {
            int vid = lnodes[cur].id;
            int next_l = lnodes[cur].nxt;
            lbin[++lbtop] = cur; // 回收链表节点
            int vr = find(vid);
            // 只有当子块当前颜色仍为 y 且确实挂在 r 下方时才合并（懒处理）
            if (vr != r && col[vr] == y && find(p[top_node[vr]]) == r) {
                r = component_merge(r, vr);
            }
            cur = next_l;
        }
    }
}

inline int read() {
    int x = 0; char ch = getchar();
    while (ch < '0' || ch > '9') { if (ch == EOF) return -1; ch = getchar(); }
    while (ch >= '0' && ch <= '9') { x = x * 10 + (ch - '48'); ch = getchar(); }
    return x;
}

int main() {
    n = read(); m = read();
    if (n <= 0) return 0;
    for (int i = 2; i <= n; i++) p[i] = read();
    for (int i = 1; i <= n; i++) {
        col[i] = read(); f[i] = i; sz[i] = 1; top_node[i] = i;
    }

    // 初始化：合并树上相邻同色点
    for (int i = 2; i <= n; i++) {
        int r1 = find(i), r2 = find(p[i]);
        if (col[r1] == col[r2] && r1 != r2) {
            f[r1] = r2; sz[r2] += sz[r1];
        }
    }

    // 构建初始 Trie 索引
    for (int i = 2; i <= n; i++) {
        int r = find(i);
        if (top_node[r] == i) {
            int pr = find(p[i]);
            insert(rt[pr], col[r], r, 19);
        }
    }

    while (m--) {
        int op = read();
        if (op == 1) {
            int x = read(), y = read();
            int r = find(x);
            if (col[r] == y) continue;
            col[r] = y;

            process_down(r, y); // 向下合并
            r = find(r);

            int top_idx = top_node[r];
            if (top_idx > 1) {
                int pr = find(p[top_idx]);
                if (col[pr] == y) component_merge(pr, r); // 向上合并
                else insert(rt[pr], y, r, 19); // 否则更新父块索引
            }
        } else {
            printf("%d\n", sz[find(read())]);
        }
    }
    return 0;
}
```
