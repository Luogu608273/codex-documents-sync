# U1668 三色园

## 题意

序列元素属于 `{1,2,3}`。一个区间合法，当且仅当三种数的出现次数两两不同，未出现的次数也算 0。每次给出 `[l,r]`，求其中最长合法子区间长度，不存在则为 0。

`n <= 10^6, q <= 2*10^5`。第一行 c 是测试点编号，不是测试组数。文件名为 `three.in / three.out`。

下面给出一个确定性的六维线性代数算法，不依赖随机数据性质。

## 1. 把区间合法性写成线性函数

记 `s[i][c]` 为前 i 个位置中颜色 c 的出现次数，包含空前缀 i=0。定义前缀点

\[
x_i=s[i][1]-s[i][2],\qquad
y_i=s[i][2]-s[i][3].
\]

区间 `[i+1,j]` 的三组次数之差分别是

\[
x_j-x_i,\quad y_j-y_i,\quad x_j+y_j-x_i-y_i.
\]

因此它合法等价于这三个差都非零。

对每个前缀 i 定义二元多项式

\[
F_i(X,Y)=(X-x_i)(Y-y_i)(X+Y-x_i-y_i).
\]

合法性等价于 `F_i(x_j,y_j) != 0`。展开得到

\[
\begin{aligned}
F_i(X,Y)={}&X^2Y+XY^2-y_iX^2-x_iY^2-2(x_i+y_i)XY\\
&+y_i(2x_i+y_i)X+x_i(x_i+2y_i)Y-x_iy_i(x_i+y_i).
\end{aligned}
\]

所以只需要保存六维向量

\[
v_i=(1,x_i,y_i,\ y_i(2x_i+y_i),\ x_i(x_i+2y_i),\ x_iy_i(x_i+y_i)).
\]

对固定的右前缀点 j，求 `F_i(x_j,y_j)` 是对向量 v_i 施加一个固定的线性函数。具体地，六个坐标的系数为

\[
(X^2Y+XY^2,\ -Y^2-2XY,\ -X^2-2XY,\ X,\ Y,\ -1),
\]

其中 `X=x_j, Y=y_j`。

这一步的作用是：用至多六个向量，就能保留整个点集对任意另一个点的“是否存在合法配对”信息。

## 2. 模运算为何完全准确

在线性基中使用素数 `P=1000003`。

任意两个前缀间，每种次数之差的绝对值不超过 `n <= 10^6 < P`。因此，一个差模 P 为 0，当且仅当它在整数中为 0。域中乘积为 0 当且仅当至少一个因子为 0，于是

\[
F_i(x_j,y_j)\not\equiv0\pmod P
\iff [i+1,j]\text{ 合法}.
\]

此处没有哈希碰撞概率，也不需要要求乘积本身小于 P。实际检查候选区间时，代码直接比较三种颜色的整数出现次数。

## 3. 最早基与最晚基

对一段按下标递增的向量，依次扫描，只在当前向量不能由此前保留向量表示时保留它。这得到一个**最早基**，大小至多 6。

它满足：对任何线性函数 L，如果某个位置 i 的向量满足 `L(v_i)!=0`，那么最早基中一定存在 `i'<=i`，且 `L(v_i')!=0`。

证明：如果 i 被选入基，直接取它；否则它是此前入基向量的线性组合。如果这些向量的 L 值全部为 0，那么 i 的 L 值也为 0，矛盾。

同理，按下标递减扫描得到的**最晚基**满足：存在 `j'>=j` 保留相同的非零检测能力。

## 4. 一次询问只需检查 36 对前缀

原询问 `[l,r]` 对应前缀集合 `[L,R]=[l-1,r]`。取这个集合的最早基 E 与最晚基 D。

假设一个最优合法区间对应前缀 i<j。

1. 固定 j，把合法性看成作用于 v_i 的线性函数。最早基性质给出 `i'<=i`，使 `(i',j)` 仍合法。
2. 固定 i'，现在把合法性看成作用于 v_j 的线性函数。因为交换两个点只改变三个差乘积的符号，这仍然是同一类六维线性函数。最晚基性质给出 `j'>=j`，使 `(i',j')` 合法。

此时 `j'-i' >= j-i`。候选对本身也对应询问内的区间，所以在 E×D 中取最大合法距离，恰好就是答案。

注意必须先替换左端，再替换右端；不能声称分别对原来的两个端点找替代后，替代端点之间就一定合法。

## 5. 在线性时间内预处理所有询问需要的基

预处理两类至多六个原始下标：

- `suf[L]`：后缀 `[L,n]` 的最早基；
- `pre[R]`：前缀 `[0,R]` 的最晚基。

最早基的贪心选择只依赖此前元素，所以把 `suf[L]` 中大于 R 的下标去掉，便是 `[L,R]` 的最早基。类似地，把 `pre[R]` 中小于 L 的下标去掉，便是所需最晚基。

无需为每个后缀重建。使用**带下标优先级的高斯消元基**：每个主元记录一个原始下标和消元后的行。插入向量时，若当前下标优先于该主元下标，先交换行及下标，再继续消元。

- 从左向右扫描，较大的下标优先，得到每个前缀的最晚基。
- 从右向左扫描，较小的下标优先，得到每个后缀的最早基。

这是有序线性基的交换过程：优先级较高的向量进入基，被替换的旧向量只在还能增加剩余维度时保留。消元行代表其记录的原向量加上优先级更高的基向量的线性组合，因此被淘汰的原向量始终可由不晚于它（或不早于它）的保留原向量表示。保存的原始下标集合与按优先顺序贪心选基一致。

实现中提前预处理 `1..P-1` 的模逆元，主元无需每次快速幂求逆。每次插入至多消去 6 个主元，每个主元更新至多 6 个坐标。

询问先检查整个 `[l,r]` 是否合法，合法时直接输出区间长度；否则枚举至多 6×6 对候选。此项提前返回只改善常数，不影响最坏复杂度。

## 6. 复杂度

设维数 `K=6`。

- 逆元预处理 O(P)。
- 两趟建基 `O(K^2 n)`。
- 每次询问 `O(K^2)`。
- 总时间 `O(P+K^2(n+q))`，空间 `O(Kn+P)`。

代码的三个前缀计数数组、两份六下标数组和逆元表共约 64 MB 十进制空间，低于题目 1024 MiB 限制。

## 7. 部分分

`partial.cpp` 适用 `n<=2000`，覆盖题面测试点 1~5。

定义 `f[l][r]` 为 `[l,r]` 内最长合法子区间长度。按 l 从大到小、r 从小到大枚举，并维护 `[l,r]` 三种数的出现次数：

- 若整个区间合法，`f[l][r]=r-l+1`。
- 否则最优区间不可能同时碰到 l 与 r，故 `f[l][r]=max(f[l+1][r],f[l][r-1])`。

预处理 O(n²) 时间、O(n²) 空间，每次询问 O(1)。它不能用于 n=10^6。

两份程序默认使用 `three.in / three.out`；添加 `-DLOCAL` 使用标准输入输出。详细本地验证见上级目录，不将其等同于官方 AC。
