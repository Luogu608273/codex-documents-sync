# U1667 中位数

## 题意与约定

把 `1..nm` 划分为 n 个互不相交的无序集合，每个集合大小为 m。先取每个集合的中位数，再取这 n 个数的中位数，求最大值及达到最大值的划分数，模 998244353。

题目采用**上中位数**：从大到小第 `ceil(k/2)` 个；等价于从小到大第 `floor(k/2)+1` 个。集合内部无序，集合之间也无序。

`n,m <= 10^6, nm <= 10^6, T <= 10^5`，没有所有测试数据 nm 之和的全局限制。文件名为 `median.in / median.out`。

## 1. 最大值

记

- `N=nm`：元素总数；
- `k=ceil(n/2)`：外层中位数达到某个值时，至少需要这么多个集合的中位数达到该值；
- `h=ceil(m/2)`：一个集合的中位数达到某个值时，至少需要这么多个元素达到该值；
- `s=kh, t=N-s`。

若最终中位数至少为 X，那么至少 k 个集合各有至少 h 个不小于 X 的数，因此全体至少需要 s 个不小于 X 的数。

`1..N` 中不小于 X 的数有 `N-X+1` 个，所以

\[
X\le N-kh+1=t+1.
\]

反过来，把最大的 s 个数称为“大数”，其余 t 个数称为“小数”。安排 k 个集合各放 h 个大数，其余集合不放大数，再用小数补足每个集合的大小。此时至少 k 个集合的中位数不小于 `t+1`，达到上述上界。

因此第一问答案为

\[
\boxed{nm-\lceil n/2\rceil\lceil m/2\rceil+1}.
\]

## 2. 达到最大值的方案数

大数恰好 s 个。如果最终中位数达到 `t+1`，需要至少 k 个集合各含至少 h 个大数。总数恰好用尽，所以条件等价于：

- 恰有 k 个“大集合”，每个含恰好 h 个大数和 `m-h` 个小数；
- 其余 `n-k` 个集合全由小数组成。

先把 s 个大数划分为 k 个大小为 h 的无序集合，方案数为

\[
\frac{s!}{(h!)^k k!}.
\]

这些大数集合各自不同，因此已经区分了 k 个大集合。把小数分配给它们，并将剩余小数划分成 `n-k` 个大小为 m 的无序集合，方案数为

\[
\frac{t!}{((m-h)!)^k (m!)^{n-k}(n-k)!}.
\]

故总答案为

\[
\boxed{
\frac{s!t!}
{(h!)^k((m-h)!)^k(m!)^{n-k}k!(n-k)!}
}.
\]

这里 k! 只除一次：第二步分配小数时，已有的大数集合能区分这 k 个位置，不能再除 k!。

预处理 `fac[i]=i!` 与 `inv[i]=(i!)^{-1}`，将公式写成

\[
fac[s]fac[t]inv[k]inv[n-k]
\big(inv[h]inv[m-h]\big)^k
inv[m]^{n-k}.
\]

所有阶乘下标均不超过 `nm <= 10^6 < 998244353`，逆元存在。规定 `0!=1`，公式也覆盖 n=1、m=1 等边界。

## 3. 正确性总结

第一步证明任何方案的中位数都不超过 `t+1`，并构造达到上界的方案。第二步证明最优划分与“大数只分布在 k 个集合、每个恰好 h 个”一一对应。计数公式分别除去组内排列和未标号集合的排列，每种最优划分恰好计数一次。

## 4. 复杂度

令 `L=10^6+4` 为实现的预处理上界。预处理 O(L) 时间、O(L) 空间；每组数据两次快速幂，O(log(n+1)) 时间，额外 O(1) 空间。总时间 `O(L+T log(n+1))`，不需要枚举每组数据的 nm 个元素。

## 5. 文件与部分分

- `std.cpp`：上述完整算法。
- `partial.cpp`：仅适用 `n,m <= 4`，对应题面测试点 1。按数值从小到大，把当前元素放入已有未满的集合，或创建一个新集合。每个集合按其最小元素出现的顺序创建，消除集合之间的重复；组内元素自动递增。叶子处直接计算两层上中位数并统计。

部分程序枚举的划分数为 `(nm)! / ((m!)^n n!)`；每个叶子需要 O(n log n) 时间计算外层中位数，搜索额外空间 O(nm)。`n=m=4` 时共有 2,627,625 种划分。它不能运行题面样例中超出 n,m<=4 的三组数据。
