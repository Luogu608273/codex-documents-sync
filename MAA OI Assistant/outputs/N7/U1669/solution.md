# U1669 嵌套函数

## 题意

有 `f_i(x)=min(x+a_i,b_i)`。支持单点修改 a 或 b，以及询问

\[
\max_{l\le p\le r+1}g(p,r,x),
\]

其中 g 是从 p 到 r 依次应用函数的结果，`g(r+1,r,x)=x`。

`n,q<=5*10^5, 0<=a_i<=10^9, 0<=b_i,x<=10^15`。a 非负是下述单调性的必要条件。首行 c 是测试点编号。文件名为 `func.in / func.out`。

## 1. 函数复合只需两个数

一段函数复合后仍能写成

\[
F(x)=\min(x+A,B).
\]

若左段是 `(A_1,B_1)`、右段是 `(A_2,B_2)`，依次应用左段再应用右段：

\[
F_2(F_1(x))
=\min(x+A_1+A_2,B_1+A_2,B_2).
\]

所以线段树的合并为

\[
(A_1,B_1)\circ(A_2,B_2)
=(A_1+A_2,\min(B_1+A_2,B_2)).
\]

这里记号表示按下标顺序应用，不能交换左右。空段为 `(0,+infinity)`。叶子为 `(a_i,b_i)`，因此两种修改均可 O(log n) 完成。

## 2. 所有后缀中只需比较相邻两个

固定询问 `[l,r],x`。对每个起点 p 定义后缀参数

\[
A_p=\sum_{i=p}^r a_i,\qquad
B_p=\min_{p\le j\le r}\left(b_j+\sum_{i=j+1}^r a_i\right).
\]

于是 `g(p,r,x)=min(x+A_p,B_p)`。空后缀 p=r+1 的参数为 `A=0,B=+infinity`。

当 p 从左往右增加时：

- 因为 a 非负，A_p 单调不增；
- B_p 是在逐步删掉元素的同一组数上取最小值，因此单调不减。

称 `x+A_p >= B_p` 的后缀为“触及上限”。触及上限的起点构成一个前缀。若存在，设最大的这种起点为 k。

- 当 `p<=k`，`g(p,r,x)<=B_p<=B_k`，而起点 k 的值恰为 B_k。
- 当 `p>=k+1`，`g(p,r,x)<=x+A_p<=x+A_{k+1}`，而起点 k+1 的值恰为 `x+A_{k+1}`。

所以

\[
\boxed{ans=\max(B_k,x+A_{k+1})}.
\]

如果没有起点触及上限，则整个询问区间应用后的值 `x+A_l` 最大。

空后缀始终属于未触及上限的一边。特别地，k=r 时第二个候选是 x，不能漏掉题目允许的“不应用任何函数”。等号划到触及上限的一边不会影响结论。

## 3. 在线段树上 O(log n) 找分界

不必二分 p 再反复求区间复合。

从右向左访问询问范围内的线段树节点，维护 `cur`，表示已经接受的右侧后缀的复合参数。它满足：从 cur 所代表区间的左端开始，仍未触及上限。

考虑把一个完整节点放到 cur 左边，得到参数 v：

- 若 `x+v.A < v.B`，这个节点的最左起点也未触及上限。由单调性，其中所有起点都不触及上限，整段接受，更新 cur=v。
- 否则分界在这个节点里，先进入右儿子，再考虑左儿子。
- 到达触及上限的叶子 k 时，v 表示 `[k,r]`，cur 表示 `[k+1,r]`，立刻返回 `max(v.B,x+cur.A)`。

若遍历完询问范围仍未找到这样的叶子，则返回 `x+cur.A`。

代码中 `query` 返回布尔值，表示是否已经找到分界，找到后立即停止，不会继续遍历其左边部分。

### 为何是 O(log n)

询问区间可分成 O(log n) 个完整线段树节点。右侧未触及上限的节点被整块接受；第一个可能含分界的完整节点只沿一条根到叶子的路径下降，每层至多整块接受一个右侧兄弟。加上原询问两侧边界路径，总共访问 O(log n) 个节点。

这与“二分位置，每次再做一次区间查询”的 O(log²n) 实现不同。

## 4. 整数范围与复杂度

`sum a_i <= 5*10^14`，后缀的 B 不超过 `1.5*10^15`，`x+A` 也不超过 `1.5*10^15`。全部参数及运算使用 `long long`；空段的 INF 取 `4*10^18`，合并时即使加上整段 A 也不会溢出。

建树 O(n)，每次修改或询问 O(log n)，总时间 `O(n+q log n)`，空间 O(n)。

## 5. 部分分

`partial.cpp` 适用 `n,q<=5000`，覆盖题面测试点 1~4。

询问时从 r 往 l 扫描，直接维护后缀参数 `(A,B)`，枚举每个起点的 `min(x+A,B)`，并将初始答案设为 x。修改直接改数组。

总时间 O(nq)，空间 O(n)。它也能算出大数据的正确值，但不保证大数据的运行时间，因此不作为完整程序使用。

两份程序默认使用 `func.in / func.out`，编译添加 `-DLOCAL` 改为标准输入输出。本地对拍采用“枚举每个起点，再从左到右逐个应用原始函数”的独立暴力，避免只比较两个使用相同复合公式的实现。
