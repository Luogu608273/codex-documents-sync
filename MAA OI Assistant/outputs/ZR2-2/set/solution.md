# set

## 题意

维护 n 个初始为空的集合，支持向一段下标对应的所有集合加入或删除同一个元素，以及查询两个集合的关系：前者严格包含后者、后者严格包含前者、相等或互不包含。增删保证合法；查询保证集合大小之差的绝对值不超过 k。n,m≤2×10^6，k≤30，元素可达 10^12。

`std.cpp` 使用随机指纹，是 Monte Carlo 算法：包含关系成立时对应代数检验一定通过；不成立时存在极小的误判概率。以下先说明代数判据，再说明怎样动态维护。

## 将大小差很小的包含关系转成低阶系数

给每个不同元素 x 独立分配有限域上的随机值 h(x)。相同元素无论插入、删除多少次，都复用同一个 h(x)。采用素数 P=2^61-1，全部运算在模 P 下进行。

一次查询中，将较大集合记为 A，较小集合记为 B，d=|A|-|B|，因此 0≤d≤k。考虑常数项为 1 的形式幂级数

\[
F(t)=\frac{\prod_{x\in A}(1+h(x)t)}{\prod_{x\in B}(1+h(x)t)}
=\sum_{i\ge0}e_i t^i.
\]

分母常数项为 1，所以在形式幂级数中总能求逆，不涉及选择具体 t 后可能出现的除零问题。

如果 A 包含 B，约去公共元素后只剩 d 个一次因子的乘积，所以 F(t) 是次数不超过 d 的多项式，必有 e[d+1]=0。

如果 A 不包含 B，e[d+1] 不一定每次都非零，但它作为各个随机指纹变量的多项式并非恒为零。取 B\A 中一个元素 z，将其他所有指纹变量设为 0，则

\[
F(t)=\frac1{1+h(z)t}
=\sum_{i\ge0}(-h(z))^i t^i.
\]

此时 e[d+1]=(-h(z))^(d+1)，不是零多项式，因此原来的 e[d+1] 也不是零多项式。这个检验可以高概率区分包含与不包含。

## 从幂和求出所需系数

定义差分幂和

\[
p_j=\sum_{x\in A}h(x)^j-\sum_{x\in B}h(x)^j.
\]

对 F 求形式导数并除以自身，得到

\[
\frac{F'(t)}{F(t)}
=\sum_{j\ge1}(-1)^{j-1}p_jt^{j-1}.
\]

比较等式 F'=F·(F'/F) 两侧 t^(i-1) 的系数：

\[
e_0=1,\qquad
e_i=\frac1i\sum_{j=1}^{i}(-1)^{j-1}e_{i-j}p_j.
\]

这就是适用于当前形式幂级数的 Newton 恒等式。所有 i≤k+1≤31<P，逆元都存在。为了得到 e[d+1]，只需 p1,…,p(d+1)，耗时 O((d+1)²)。因此只需要动态维护前 k+1 阶幂和，无须存储整个集合多项式。

程序中 `s[j-1]` 对应这里的 p_j，`e[i]` 对应 e_i。

## 区间增删与树状数组

对每个位置维护集合大小，以及每一阶幂和 Hj。加入元素 x 时，区间内所有集合大小加 1，第 j 阶幂和加 h(x)^j；删除时取相反数。题目保证增删合法，因此不需要再检查各个集合是否含有 x。

对位置下标做差分：区间 [l,r] 加一个量，变成差分位置 l 加该量、r+1 减该量。每个通道用树状数组维护差分，单个集合的值就是对应前缀和。一个大小通道与 k+1 个幂和通道，便足以完成全部更新和查询。

程序先读入操作并离散化所有出现的元素，再分配指纹。幂和通道按树状数组节点连续存储，一次更新节点时连续处理全部阶数。求两个集合的幂和之差时，两条树状数组前缀路径的公共后段可直接抵消。

## 如何确定输出编号

先查出两个集合的精确大小。

- 大小不同：将较大集合放在 A，检验 e[d+1]。非零则输出 4；为零则认为 A 包含 B，并按照原来的参数顺序输出 1 或 2。
- 大小相同：d=0，只需检验 e1=p1。非零则输出 4；为零则认为两集合相等，输出 3。

大小不同时包含一定是严格包含；大小相同时，只要一方包含另一方就必然相等。

## 误判概率

系数 e[d+1] 作为指纹变量的多项式，总次数至多 d+1。在理想的独立均匀有限域随机模型下，非零多项式取值恰好为 0 的概率至多为 (d+1)/P。因此单次不成立的包含关系被误判的概率至多 31/(2^61-1)。对最多 2×10^6 次查询取并集上界，概率不超过约 2.7×10^-11。

这是随机模型下的概率界，不是确定性正确性保证。实现使用运行时种子的 `mt19937_64` 生成伪随机指纹。A 包含 B 时 e[d+1] 恒为 0，不会因随机值而被误判为不包含。

## 复杂度与模乘

设更新数为 U、查询数为 Q，第 i 次查询的大小差为 d_i。

- 离散化时间 O(m log m)。
- 更新总时间 O(U(k+1) log(n+1))。
- 查询总时间 O(Σ((d_i+1) log(n+1)+(d_i+1)²))。
- 空间 O(n(k+1)+m+k)。

题面大规模子任务限制 k≤2；k≤30 的子任务中 n,m≤200000。程序也额外测试了总约束同时达到 n=m=2000000、k=30 的一组构造，详情见验证记录。

模乘先用无符号 128 位整数保存乘积 z。由于 2^61≡1 (mod P)，可以把 z 的低 61 位与其余高位相加，再减去至多一个 P，得到规范余数。不能直接使用 64 位整数乘法，否则会在取模前溢出。树状数组本体约需 8(n+1)(k+1) 字节，此外还需操作序列、离散化表及大小数组，总内存在题目的 1024 MB 范围内。

## partial.cpp

适用范围：n,m≤2000，覆盖子任务 1、2，按题面合计 25 分；并非实际评测得分。元素使用 `long long`，支持题面完整元素范围，不依赖 x≤10^5。

为每个位置使用一个显式 `set<long long>`。区间更新就枚举每个集合分别插入或删除；查询用有序集合的线性包含检查，分别判断 Su 是否包含 Sv、Sv 是否包含 Su，再输出四种关系。这个实现是确定性的。

每次更新 O((r-l+1) log(m+1))，每次查询 O(|Su|+|Sv|)。粗略总上界 O(nm log(m+1)+m²)，最多存储 O(nm) 个元素出现次数。该做法不适用于百万规模数据。
