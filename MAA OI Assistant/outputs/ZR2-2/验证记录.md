## 正确性与复杂度核对

### bracket

在数字序列两端补 0。固定数字后，最少括号数为相邻数字差的绝对值之和：每个间隙至少需要改变相应层数，直接补入所需左右括号可同时达到所有下界。

只修改一个数字时，仅影响两侧的差。该数字改成左右相邻数字之间的任意值即可使局部代价最小。枚举每个位置的最大节省量，最后线性构造括号串。

时间 O(|S|)，空间 O(|S|)；输出长度最多为 10|S|+9。字符串总长度上限为 2,000,000。

### poly

整数多项式保持模 p 的同余关系，因此每一步都可立即取模。状态同时记录当前余数与下一次使用的多项式编号，共 2p 个状态。先用模快速幂求每个状态的一步转移，再进行 30 层倍增；这样同时覆盖两种起始模式，且不要求 p 为质数。

设 L=m0+m1、B 为最大指数、Y 为最大询问步数。时间 O(p L log(B+1) + p log Y + q log Y)，空间 O(p log Y)。指数为 0 时快速幂返回 1，包含 0^0 在该题常数项定义下的情况。

### transform

将函数图分成环及挂在各环点上的反向树。正权保证到一个状态的最短耗时就是首次到达的耗时。反向树的 DFS 区间判断祖先关系，带权深度处理树上距离；入环点、环前缀和与环总长处理环上距离。因此任意两个状态之间的最短耗时可以 O(1) 查询。

给定时间上限 T，按位置顺序贪心选择不小于上一个选值、且在 T 内可达的最小状态。较小的选值只会放宽后续限制，故该贪心判定充要。候选状态指针全程只从 1 增加到 m，整次判定仅需 O(n+m) 次距离检查。

任意可达状态的首次到达路径不会重复点，耗时不超过 sum(c)。先检查该上界，失败则无解；否则在 [0,sum(c)] 中二分。时间 O((n+m) log(sum(c)+1))，空间 O(n+m)。全部时间和环前缀和使用 64 位整数，sum(c) 最大为 10^15。图遍历使用显式栈。

### set

将出现过的元素离散化，为每个不同元素独立分配模 P=2^61-1 的随机指纹 h(x)，相同元素始终复用同一个指纹。维护集合大小与第 1 至 k+1 次幂和，通过位置差分和树状数组支持区间增删、单点查询。

一次查询中，将较大集合记为 A、较小集合记为 B，d=|A|-|B|<=k。其幂和之差对应形式幂级数

    F(t) = product(1+h(x)t, x in A) / product(1+h(x)t, x in B)。

用 Newton 恒等式求出 t^(d+1) 的系数。若 A 包含 B，约去交集后 F 是 d 次多项式，该系数必为 0。若不包含，取 B\A 中某个元素的指纹变量，系数中存在该变量的 (d+1) 次单项式且系数为 ±1，因此待判表达式是一个非零、总次数至多 d+1 的多项式。理想独立均匀指纹模型下，单次误判概率不超过 (d+1)/P；全部至多 2,000,000 次查询的联合上界不超过约 2.7×10^-11。实际随机数由运行时种子的 mt19937_64 生成。

包含时不会误判为不包含；可能的随机错误是将不包含误判为包含，或将不同集合误判为相同。程序使用 128 位乘积和梅森素数约减，避免 64 位乘法溢出。

设更新次数 U、查询次数 Q，每次查询的大小差为 d_i。离散化 O(m log m)，更新总计 O(U k log n)，查询总计 O(sum((d_i+1) log n + (d_i+1)^2))，空间 O(n k + m)。题面子任务中的大规模组为 k<=2，k<=30 的组为 n,m<=200,000；另额外测试了总约束 n=m=2,000,000、k=30。
