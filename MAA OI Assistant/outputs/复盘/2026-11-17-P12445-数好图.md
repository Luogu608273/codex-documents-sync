# P12445 [COTS 2025] 数好图 / Promet

2026-11-17 用户反馈 AC。提示后完成，含代码调试。用时未记录，尚无独立重做记录。[洛谷原题](https://www.luogu.com.cn/problem/P12445)

## 原状态为什么推不动

最初按前缀记录从 1 可达、能到当前末点、同时满足两者的点数。前四个点中，令点 4 孤立。边集为 `{1→2, 1→3}` 或 `{1→2, 2→3}` 时，三个计数都是 (3,1,0)。同样只加边 3→5，两图中同时满足条件的点数分别变为 3 和 4。新边可以从任意旧点接出，只记到点 4 的信息无法计算经点 3 新增的贡献。

## 三层各自数哪些边

设 R 是从 1 可达的点集，S 是 R 中能到 n 的点集。讨论 S 非空时，1 和 n 都在 S 中。分层和钦定零出度的容斥由提示给出。用户随后写出了三个普通前缀转移，并提出按集合大小合并、用总图数补出答案第 0 项。

1. **R 外的边。** 之前有 i 个点，其中 j 个属于 R。新点属于 R 时，来自 R 内的边留给下一层；新点在 R 外时，来自 R 内的边必须全不选。两种情况下，从 R 外接入的边都有 2^(i−j) 种选法。
2. **R 内、S 外的边。** 在 R 的编号顺序中，若已有 i 个点，新点在 R 去掉 S 后的集合中，则必须从之前的 R 点选非空入边集，有 2^i−1 种选法。新点属于 S 时，S 外的点不能连向它，S 内部的边留到第三层，本层系数为 1。
3. **S 内的边。** 编号严格递增，因此每个非首点有入边、每个非末点有出边，就能沿边反向追到 1、正向走到 n。若前 i 点钦定了 b 个零出度点，新点选入边有 2^(i−b)−1 种方式。钦定新点零出度时贡献取反，否则保留符号。任一实际零出度的非末点都能使两支抵消。首点免除入边要求，初始化 h[1][0]=1、h[1][1]=−1；末点免除出边要求，只选入边。

每张图唯一确定 R、S。固定这两个集合后，三层选边互不重叠。合并时要强制 n 进入 R 和 S，故从两张普通前缀表分别只取末点加入的那一支。枚举 |R| 对外部方案求和，再乘只依赖 |S| 的内部方案数。每层有 O(n²) 个状态，每个状态常数次转移；合并只枚举一对集合大小，总时间、空间均为 O(n²)。

## 实现回看

- h 的循环从 j=1 开始，漏推 h[i][0]，同时漏掉它对 t[i+1] 的贡献。n=2 时内层循环为空，原程序输出 `2 0 0`，正确答案为 `1 0 1`。下次可先手推 t[2]，它应当恰好数到边 1→2。
- 最后合并时三个模 P 的因子直接用 long long 连乘可能溢出。前两项相乘取模后再乘第三项。
