## 本次推导要点

- 记 R_i 为从 i 开始的长度为 n 的循环移位串，比较字符时使用循环下标，候选起点本身不取模。
- 若 R_i、R_j 前 l 个字符相同，下一字符满足 R_i[l+1] > R_j[l+1]，则对任意 0 ≤ t ≤ l，R_{i+t}、R_{j+t} 的前 l-t 个字符仍相同，下一字符保留同一严格大小关系。因此 i 到 i+l 中的合法起点均不能是答案，落败指针可跳至 i+l+1；另一方落败时对称处理。
- 指针跳跃后重置 l=0；重合时只保留一份候选；连续相同 n 个字符时停止比较。起点超过 n 时退出候选扫描。最小表示相同时取最小起点；P13270 则输出该起点对应的整个循环移位串。
- 对每个以失配结束的阶段，l 次相等比较加一次失配，共 l+1 次比较；相应指针更新使 i+j 恰增加 l+1，重合修正只会使其进一步增加。即使交换两个指针的角色，和的增量仍成立。
- 循环开始时 i、j 均不超过 n，所以 i+j ≤ 2n；最后一次跳跃可能超过 2n，但增量至多 n，故所有失配阶段的比较次数之和为 O(n)。若最后一轮始终相等，额外比较至多 n 次。每轮其余操作 O(1)，输出原题字符串再花 O(n)，总时间 O(n)。保存输入 O(n) 空间，算法辅助空间 O(1)，不必实际复制字符串。
- 本次逐步讨论了局部成段淘汰与线性时间计数；完整的全局候选覆盖不变量未单独展开，不以 AC 反馈替代该部分证明或最终实现核验。
