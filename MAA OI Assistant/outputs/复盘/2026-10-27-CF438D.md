## 实际卡点

- 已能说明：维护区间最大值，最大值小于模数时跳过；真正改变的数取模后小于原值的一半。
- 卡点在于单点赋值会把数值重新增大，不能再说一个下标在整个过程中只改变 O(log V) 次。未发现或记录具体实现错误；最终代码未读取。
- 补充的观察：每次单点赋值只给一个位置重新补充 O(log V) 次有效取模的额度；赋值次数本身也计入操作总数。

## 方法与复杂度依据

- 线段树维护区间和及最大值。区间取模时，最大值小于 x 的节点直接跳过，否则递归到需要修改的叶子并更新信息。区间和、最大值均由子节点合并，单点赋值沿路径更新。
- 有效取模满足 a >= x。若 x <= a/2，则 a mod x < x <= a/2；若 x > a/2，则 a mod x = a-x < a/2。
- 把每个位置按单点赋值分段。每段起始值不超过 V，随后只会被取模减小，因此每段有效取模至多 floor(log2 V)+1 次；起始为 0 时没有有效取模。
- 设单点赋值有 u 次，共有 n+u 段，有效修改元素总次数 K = O((n+u) log V)。等价势能为各元素二进制位数之和，规定 0 的位数为 0；每次有效取模至少消耗 1，每次赋值最多补充 floor(log2 V)+1。
- 单次区间取模若实际修改 k 个元素，访问节点可归入这 k 个叶子的祖先、区间边界路径及其相邻剪枝节点，总代价 O((k+1) log n)。因此总时间 O(n+(q+K) log n) = O((n+q) log n log V)，空间 O(n)。
