# C. 暖色

题目：<https://www.zhengruioi.com/problem/3723?cid=2225>  
官方简要题解：<https://www.zhengruioi.com/problem/3723/tutorial?cid=2225>

## 题意与范围

给树的 n-1 条边染色，不允许出现一条恰好有 k 条边、且边的颜色两两不同的简单路径。求最多能使用多少种颜色。注意限制的是边数，不是点数；重复颜色的路径仍然允许存在。

2≤k≤n≤10^5，k≤30。时限 1 秒，空间 512 MB。使用 moment.in / moment.out。

下面给出 O(nk) 的实现；官方简要题解给出的总体上界是 O(nk²)。两者都以“可令每种颜色连通”为基础，下面补齐该性质和具体转移。

## 1. 同一种颜色可以只占据一个连通边块

在所有使用最多颜色的合法方案中，选取“所有颜色的连通分块总数”最小的一种。若颜色 c 仍有多个连通块，将每个 c 连通块收缩成一个点，考虑连接这些点的最小子树，选其中一个位于末端的 c 块 C。所有其他 c 块都从 C 的同一个出口方向到达。

设该出口紧邻 C 的第一条边的颜色为 d，必有 d≠c。把整个 C 改为 d：c 在别处仍存在，d 本来就存在，所以颜色总数不变；C 并入出口的 d 块，连通块总数减少。

这个修改不会新造出一条 k 色各异路径。若某条路径在修改后才变成两两不同，那么它原来必须因 c 重复而不合法。若重复的 c 都在 C 内，修改后仍有重复的 d；若还经过 C 外的 c 块，该路径必经过上述出口 d 边，修改后同样有重复的 d。矛盾。

因此总能找到每种颜色连通的最优方案。此后，不同子树中的颜色均可重新编号，仅在它们经当前点相接、且被指定为同一组时共享颜色。

在这种方案中，路径上同一颜色的边连续出现；“颜色两两不同的路径”就是沿途没有相邻同色边的路径。不能把一般含重复边色的长路径简单缩短成同样存在的彩虹路径。

## 2. 带一条真实父边的状态

任选树的一个叶子 z，以它的邻点 rt 为根，并把 z 视为 rt 的父亲。这样，除了 z 以外，每个处理的点 u 都有一条**真实存在**的父边 (fa_u,u)。程序按遍历序逆序处理，避免深链递归。

定义 f[u][j]：在 u 的子树连同父边中，满足内部所有彩虹路径长度都小于 k，且从 fa_u 沿父边进入子树的最长彩虹路径长度不超过 j 时，最多使用的颜色数。父边颜色也计数。

j∈[1,k-1]，没有孩子时 f[u][j]=1。该状态关于 j 单调不减。最终答案是 f[rt][k-1]；由于父边是真实边，无需减去一个虚构颜色。

将父边颜色记为 c。对每个孩子 v，t_v 表示从 u 经过边 (u,v) 向下的最长彩虹链长度。其最优内部贡献由 f[v][t_v] 给出。

若两条孩子边的颜色不同，经过 u 将两侧最长链拼接后仍是彩虹路径，必须满足 t_v+t_w≤k-1。若它们同色，则路径在 u 处已经重复，不能这样拼成彩虹路径。

## 3. 固定“非父边颜色”的最大链长 R

令 R 为所有颜色不等于 c 的孩子分支的最大 t_v；不存在这样的孩子时 R=0。状态上界要求 1+R≤j。令

H=k-1-R，B=min(R,H)。

所有孩子可按根边颜色分为三类：

- **A 类：根边颜色就是 c**。其链长至多 H，贡献至多 f[v][H]-1。减 1 是因为父边颜色 c 已经计数。
- **B 类：独立的新颜色**。其链长至多 B，每个这样的孩子单独使用一个新的根边颜色，贡献 f[v][B]。
- **C 类：共享另一个根边颜色 d≠c**。其链长至多 R，单个贡献 f[v][R]-1；整个非空 C 组再统一加回一种颜色 d。

R=0 时 B、C 两类不可选。

### 为什么只需要这三类

若 R≤H，则任意两个非 c 分支的链长和≤2R≤k-1，可以让它们的根边颜色全部不同，所以 B 类足够；C 类保留在统一写法中，不会增加可用的颜色数。

若 R>H，取达到最大值 R 的非 c 分支所在颜色组 d。任何其他颜色组的链长都必须≤k-1-R=H，否则与该最长分支拼接就违规。因此只有这个 d 组可能超过 H，其余分支均可放进 B 类。与 c 相同的分支也必须≤H。

反过来，按三类构造一定合法：不同组之间的最长链长度之和分别不超过 H+R=k-1 或 2B≤k-1；父边只会把非 c 分支延长 1，得到长度≤R+1≤j。同组之间经 u 的路径立即出现重复颜色。

实际选择出来的最大链长可能小于所枚举的 R，但不会造成错误：所有上述约束仍然充分；枚举实际最大值时又一定能覆盖最优方案。

## 4. O(1) 合并一个孩子

固定 R，维护 g0、g1，分别表示已经合并的孩子中 C 组尚未出现、已经出现时的最多颜色数。初始 g0=1（父边），g1=-∞。

对孩子 v，令

A=f[v][H]-1，Bv=f[v][min(R,H)]，C=f[v][R]-1。

R=0 时令 Bv=C=-∞。转移为

g0' = g0 + max(A,Bv)，

g1' = max(g1+max(A,Bv,C), g0+C+1)。

第二项表示首次建立 C 组，因此加回 d 的一种颜色。以后再次加入该组时，不重复加回。

合并所有孩子后，记当前候选为 q[R]=max(g0,g1)。状态是

f[u][j] = max(q[0],q[1],…,q[j-1])。

`std.cpp` 只计算新加入的 R=j-1，再与 f[u][j-1] 取最大值；f[v] 已经是“长度不超过”的前缀最优值，三类贡献均直接查询。每个 u、j、孩子组合只做常数次操作。

## 5. 复杂度

每个点有 k-1 个状态，扫描邻接表总长度为 2(n-1)，因此时间 O(nk)，空间 O(nk+n)。f 为 int 数组，颜色数至多 n-1；大约 1280 万字节，连同图和遍历数组远低于 512 MB。

## 部分分程序：保证 47 分

`partial.cpp` 保留同一个严格状态，但直接枚举每个 j 的全部 R∈[0,j-1]，并在每个孩子处扫描全部 t∈[1,k-1]，分别取三类的最优值，不使用直接查询和跨 j 的前缀复用。

复杂度 O(nk³)，空间 O(nk+n)。保证覆盖子任务 1（n≤10，7 分）、子任务 2（n≤30,k≤10，18 分）、子任务 3（n≤100，22 分），合计 47 分。算法本身在所有范围仍然正确，但一般大数据可能超时；不保证覆盖度数≤3或 n≤5×10^4 的完整子任务。

## 验证方式

小树暴力枚举任意的边颜色等价类划分，允许一个颜色不连通，再直接检查每条 k 边路径。这项暴力与上述连通化定理和三类 DP 独立，可用于检验它们的结果。另比较 std 与直接枚举版 partial，并测试长链、星形和最大规模。验证不能代替以上证明，结果见 README.md。
