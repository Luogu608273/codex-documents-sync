A 后缀自动机
把 26 个字母各自的前缀计数写出来就够了。设 prec(i) 为 S[1..i] 中字母 c 的出现次数，
则 ans(l, r) = maxc
(
prec(r) − prec(l − 1)
)
，也就是“区间里出现次数最多的那个单字母
的出现次数” 。
对每种字母分别建立前缀和数组，询问的时候枚举 26 个字母即可。复杂度 (26(n + q))。

B 最长上升子序列
设 dj 为以位置 j 结尾的 LIS 长度，posv 为值 v 所在的位置，则全部答案就是 ansi =
maxv≤i dposv 。
对整个排列求一遍 LIS 的 DP 数组 d，再按值从小到大做一遍前缀 max 即可。复杂度

C 狼人杀
对于狼人，你什么都无法知道，因此考虑去找村民的子序列；每个人的话也可以转化为
其左边和右边有多少村民。设村民位置 p1 < · · · < p k，狼总数 q = n − k。第 j 个村民
左边恰有 j − 1 个村民、pj − j 只狼。
如果确定了村民的总数 q，我们就可以把不同人的话“统一”为：我左边有多少个村民。
那你选出的子序列应该恰好为 {0, 1, 2, · · · , q − 1}，我们只需要对这样的子序列计数。
这时候的方法是： 我们只需要固定首尾分别为0 和 (q − 1)； 除第一个元素外， 每个元素
左边的元素应该恰好比他小 1。直接 DP 可以做到 O(n2)。
满分解：扫描 q + 线段树维护转移矩阵。把 p = 3 · · · n 的转移写成矩阵
Mp =
(
c1(p) c2(p)
1 0
)
,
c1(p) = [ pin(p) = pin(p−1)],
c2(p) = [ pin(p) = pin(p−2)+1],
其中 pin(x) = bx（L）或 q − bx（R） 。关键观察：每个0/1 判定按两端 d 是否同方向分
类——
1. 同方向（L, L 或 R, R） ：条件与q 无关，恒真或恒假；
2. 不同方向：条件恰为 q = bi + bj（隔 1 个位置）或 bi + bj ± 1（隔 2 个位置，方
向决定符号）——对恰一个 q 为真。
不同方向只对单个 q 成立。对于每个 q，我们找到所有可能的“不同方向”的转移，均
摊后一共只有 O(n) 个。特殊处理这些间断点，其他的转移都是“本质相同”的。
（用人话说就是，每次你需要求出 ∏n
i=3 Mi，但是对于不同的 q 来说，一共只有 O(n) 个
不一样的 Mi，所以可以用线段树维护矩阵）
复杂度 O(n log n)。另外，此题可以做到线性（扩展一下“差分” ） ，留给读者自行思考。

拆分引理：设 k = ⌊log2 n⌋。把拆分的元素从大到小逐层累加，部分和 σc 是 2c 的倍数
